# ホームの新着・更新した学習記事

ホームの絞り込み一覧は `_data/home_updates.yml` から表示する。学習記事は主に `pages/` にあり、`_posts/` は制作記録・お知らせに使う。

## 掲載する記事

- 新規公開した学習記事、または説明・例・判断基準・学習導線を実質的に改善した記事を選ぶ。
- 誤字、メタデータ、日付、リンクの軽微な修正だけで追加しない。
- 分野は `G検定`、`DS検定`、`SG試験`、`FE試験` の4種類。掲載中は各分野から少なくとも1件を保つ。
- 全体は8〜12件を目安に、日付の新しい順に手動で並べる。記事数だけをそろえるために古い記事を「新着」として追加しない。
- 同じ主題が連続する場合は、読者が異なる内容を選べるように候補を見直す。

## 1件に書く情報

- `date` は記事に表示される公開日または内容を大きく更新した日付。ホーム掲載日やビルド日を代用しない。
- `category` は上記4種類のどれかにする。
- `kind` は `新規` または `更新`。
- `title` はリンク先の内容が分かる簡潔な名前にする。
- `url` は公開記事の `permalink` を使い、リンク先と一致させる。
- `summary` は、その記事で何を判断・理解できるかを短い一文で書く。

## 更新時の確認

1. 対象記事の公開URL、記事内容、公開日・更新日を確認する。
2. 既存の掲載記事を必要に応じて外し、8〜12件に収める。
3. すべて、G検定、DS検定、SG試験、FE試験の各ボタンで結果が出ることを確認する。
4. 表示順、日付、リンク名、リンク先を確認する。GitHub Pagesのビルドも確認する。

学習記事の更新すべてにホーム掲載を義務付けない。読者が次に読む価値がある記事を選ぶ。
