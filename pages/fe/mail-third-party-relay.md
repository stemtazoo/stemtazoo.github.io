## まず結論

**メールの第三者中継**とは、自社とは無関係な外部の送信者から、別の外部の受信者へのメールを、自社のメールサーバが中継してしまうことです。

FEでは、次の3か所を**社内か社外か**に分類すると判断しやすくなります。

```text
① 接続元IP
② 送信者ドメイン
③ 受信者ドメイン
```

第三者中継を疑う基本形は、

```text
接続元 → 社外
送信者 → 社外
受信者 → 社外
```

です。

覚え方は、**「他社A → 自社メールサーバ → 他社B」**です。

## 直感的な説明

自社のメールサーバを宅配センターだと考えてみます。

通常なら、

```text
自社の人 → 他社
→ 自社から外へ送る

他社 → 自社の人
→ 外から自社宛てを受け取る
```

のは自然です。

ところが、

```text
他社A
  ↓
【自社メールサーバ】
  ↓
他社B
```

となっていたらどうでしょう。

自社とは関係のないA社からB社へのメールを、自社サーバがわざわざ運んでいます。

これが第三者中継を考える基本イメージです。

## 定義・仕組み

メールを外部へ送るときにはSMTPが使われ、メールサーバは必要に応じてメールを別のメールサーバへ転送します。

問題なのは、**誰にでも無制限に中継を許してしまうこと**です。

```text
正当な利用者
↓
自社メールサーバ
↓
外部宛て
→ 必要な中継

無関係な外部利用者
↓
自社メールサーバ
↓
別の外部宛て
→ 第三者中継を疑う
```

このように外部から外部への中継を広く許してしまう状態は、**オープンリレー**として迷惑メール送信などに悪用されるおそれがあります。

### なぜ接続元IPを見るのか

送信者メールアドレスだけでは、「誰が実際にそのメールサーバへ接続してきたか」は分かりません。

そこでログでは、

- 接続元IPアドレス
- 送信者メールアドレスのドメイン
- 受信者メールアドレスのドメイン

を分けて確認します。

FEでは、問題文で自社IPと自社ドメインが与えられたら、まず表に**社内／社外**を書き込むと整理しやすくなります。

## 科目Aでどう出る？

典型的な判断は次のようになります。

| 接続元 | 送信者 | 受信者 | 判断 |
|---|---|---|---|
| 社内 | 自社 | 他社 | 通常の外向きメール |
| 社内 | 自社 | 自社 | 社内のメール |
| **社外** | **他社** | **他社** | **第三者中継を疑う** |
| 社外 | 他社 | 自社 | 通常の受信メール |

特に間違えやすいのが、

```text
社外 → 自社
```

です。

外部から接続されていても、**受信者が自社ドメインなら、自社宛てのメールを受信しているだけ**です。

一方、

```text
他社A → 自社メールサーバ → 他社B
```

なら、自社メールサーバが外部同士の通信を仲介しています。

問題を見たら、アドレスを一つずつ読むより先に、

```text
IP     → 社内？社外？
送信者 → 自社？他社？
受信者 → 自社？他社？
```

と分類します。

## どんな場面で使う？

メールサーバでは、迷惑メール送信などへの悪用を防ぐため、誰にメール中継を許可するかを適切に制御する必要があります。

例えば、自社ネットワーク内や認証済み利用者からの外部宛てメールは許可しつつ、無関係な外部利用者から別の外部宛てへの中継は拒否する、といった考え方です。

試験ではメールサーバ製品ごとの設定方法を覚えるより、

**「自社サーバが誰から誰へのメールを中継しているか」**

を読み取れることが重要です。

## よくある誤解・混同

### 外部IPから接続されたら第三者中継？

違います。

```text
他社 → 自社
```

は、自社宛てメールの通常の受信でも発生します。

接続元だけで判断せず、**受信者ドメインまで確認**します。

### 他社宛てメールなら第三者中継？

これも違います。

```text
自社 → 他社
```

は、自社利用者が外部へメールを送信している通常のケースです。

第三者中継では、**自社と無関係な外部から、さらに別の外部へ中継しているか**を見ます。

### メールの中継そのものが危険？

中継そのものが問題なのではありません。

メール配送ではサーバ間の転送が必要です。問題なのは、**中継を許可すべきでない第三者にも利用させてしまうこと**です。

### 送信者ドメインだけを見ればよい？

不十分です。

FEのログ問題では、

```text
接続元IP
送信者ドメイン
受信者ドメイン
```

の3点をセットで確認します。

送信者が他社でも、受信者が自社なら通常の受信である可能性があります。

## まとめ（試験直前用）

- 第三者中継は、**無関係な外部から別の外部へのメールを自社サーバが中継する状態**
- **他社A → 自社メールサーバ → 他社B** と考える
- 接続元IP・送信者ドメイン・受信者ドメインを社内／社外に分類する
- **社外・他社・他社 → 第三者中継を疑う**
- **他社 → 自社**は通常の受信なので、外部接続だけで判断しない
- **自社 → 他社**は通常の外向き送信
- オープンリレーは迷惑メール送信などに悪用されるおそれがある

試験直前は、次の形を思い出してください。

```text
他社A
  ↓
自社メールサーバ
  ↓
他社B

→ なぜ自社が外部同士を中継している？
→ 第三者中継を疑う
```
