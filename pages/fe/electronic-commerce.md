## まず結論

EC（Electronic Commerce：電子商取引）とは、**インターネットなどの電子的なネットワークを利用して、商品やサービスの取引を行うこと**です。

基本情報技術者試験では、次のように判断すると選択肢を切りやすくなります。

```text
ネットワークを利用する
＋
商品・サービスを取引する
→ EC
```

代表的な取引形態は、次の3つです。

| 分類 | 取引する当事者 | 代表例 |
|---|---|---|
| BtoB | 企業と企業 | 部品の電子発注、Web-EDI |
| BtoC | 企業と消費者 | ネットショップ、バーチャルモール |
| CtoC | 消費者と消費者 | フリマアプリ、ネットオークション |

単にITを利用するだけではなく、**商取引そのものを電子的に行っているか**を見るのがポイントです。

## 直感的な説明

ECは、店舗や紙の注文書だけに頼らず、ネットワーク上で売買を行う仕組みです。

例えば、次のような取引がECに当たります。

```text
企業がWebサイトで商品を販売する
企業同士がネットワーク経由で部品を発注する
個人同士がフリマアプリで商品を売買する
```

一方、会社のWebサイトで商品情報を閲覧しただけでは、必ずしもECとはいえません。

```text
情報を見るだけ
→ ECとは限らない

注文・契約・決済などを行う
→ EC
```

ECでは、誰と誰が取引するかによって、BtoB・BtoC・CtoCなどに分類されます。

## 定義・仕組み

ECは、Electronic Commerce の略です。

```text
Electronic
→ 電子的な

Commerce
→ 商取引
```

### BtoB

BtoBは、Business to Business の略で、企業同士の取引です。

```text
企業
↓
企業
```

例えば、メーカーが部品会社へ材料を発注する取引などが当てはまります。

Web-EDIのように、企業間で注文書や請求書などの取引データを交換する仕組みも、BtoBと関係します。

### BtoC

BtoCは、Business to Consumer の略で、企業と消費者の取引です。

```text
企業
↓
消費者
```

企業が運営するネットショップや動画配信サービス、複数の電子店舗が集まる**バーチャルモール**などが代表例です。

### CtoC

CtoCは、Consumer to Consumer の略で、消費者同士の取引です。

```text
消費者
↓
消費者
```

フリマアプリやネットオークションなどが代表例です。

CtoCでは取引相手を直接よく知らない場合があるため、代金の受渡しを第三者が仲介する**エスクローサービス**が使われることがあります。

[エスクローサービスとは？第三者が代金を預かる決済の仕組み]({{ '/fe/escrow-service/' | relative_url }})


### eマーケットプレイスとバーチャルモールの関係

**eマーケットプレイス（electronic marketplace）は、インターネット上で複数の売り手と買い手が出会い、商品・サービスなどを取引するための電子的な市場**です。

例えば、複数の部品メーカーと購入企業が参加する企業間の取引サイトを考えます。

~~~text
売り手：部品メーカーA・B・C
             ↓ 出品・条件提示
    eマーケットプレイス
             ↑ 検索・発注
買い手：製造会社X・Y
~~~

市場の運営者が売り手と買い手を結び付け、商品検索や発注、決済などの仕組みを提供する場合があります。**「直接取引」は、必ずしもプラットフォーム運営者の支援が一切ないという意味ではありません。**

**バーチャルモール（ECモール）**は、複数の電子店舗が集まったオンライン上の商業施設をイメージすると分かりやすい用語です。eマーケットプレイスと重なる仕組みですが、FEでは次の点を区別します。

| 観点 | eマーケットプレイス | バーチャルモール |
|---|---|---|
| 着目点 | 多くの売り手・買い手が取引する**市場** | 複数のオンライン店舗が集まる**商業施設** |
| 取引形態の例 | BtoB・BtoC・CtoCなど | 消費者向けBtoCの例が多い |
| 具体例 | 部品の企業間取引市場 | 複数の小売店が出店するECモール |

ここで重要なのは、**BtoB・BtoC・CtoCは「誰と誰が取引するか」の分類で、eマーケットプレイスは「どのような場所・仕組みで取引するか」の説明**だということです。eマーケットプレイス＝必ずBtoB、と決め付けないようにしましょう。

このテーマは、基本情報技術者試験の「ビジネスインダストリ」や「経営戦略」と関係します。公式の出題範囲やシラバスは、[IPA：基本情報技術者試験](https://www.ipa.go.jp/shiken/kubun/fe.html)から確認できます。

### BtoB・BtoC・CtoC以外の取引形態

ECでは「**誰から誰へ**」で取引の種類を判断します。

| 分類 | 取引主体 | 例 |
|---|---|---|
| GtoC | 行政機関から個人 | 行政による個人向けサービス提供 |
| GtoB | 行政機関から企業 | 行政による企業向けオンライン手続 |
| CtoG | 個人から行政機関 | 個人による電子申請 |
| BtoG | 企業から行政機関 | 企業による電子入札への参加 |

行政との電子的な手続は広い意味で電子政府・電子行政に関わりますが、**すべてが商取引（EC）に当たるわけではありません**。GtoCなどは取引・サービス提供の関係者を区別する分類として覚えます。行政サービスは[電子行政サービスの記事](/fe/e-government-digital-services/)で確認してください。

### オムニチャネル・ショールーミング・ロングテール

| 用語 | 見分けるポイント |
|---|---|
| オムニチャネル | 実店舗・ECサイト・アプリなど複数の販売接点を連携し、一貫した購買体験を提供 |
| ショールーミング | 実店舗で商品を確認し、オンラインなど別の販路で購入する行動 |
| ロングテール | 個々の売上は小さい商品でも、多数の品目を合計すると一定の売上を生み得るという考え方 |

**オムニチャネルは事業者側の販売接点の連携、ショールーミングは消費者側の購買行動**です。同じ意味ではありません。

例えば、店舗で在庫を確認した商品をアプリから購入し、別の店舗で受け取れる仕組みはオムニチャネルの例です。一方、店舗で試した商品を別のネットショップで安く買う行動はショールーミングです。

ロングテールも「必ず売れ筋商品をなくす」という意味ではありません。商品群全体の売上構成を考える際の概念です。

## 科目Aでどう出る？

科目Aでは、仕組みが支援する対象を見分けます。

| 問題文の中心 | 選ぶ用語 |
|---|---|
| 電子的ネットワーク上で商取引そのものを行う | EC |
| 多数の売り手と買い手がインターネット上の市場で取引する | eマーケットプレイス |
| Webの施策から実店舗への来店・購買を促す | O2O |
| 調達・製造・在庫・物流などを一連の流れで最適化する | SCM |
| 企業間で注文書・請求書などの取引データを交換する | EDI |
| 営業担当者の活動を支援する | SFA |
| 人・物・金などの経営資源を全社で統合する | ERP |

単に業務でネットワークを使うだけではECとは限りません。商品やサービスの売買という**商取引そのもの**が行われているかを確認します。

### eマーケットプレイス・O2O・SCM・EDIを見分ける

同じ「電子的な取引・ビジネス」の周辺用語でも、着目する対象が違います。

| 用語 | 主な目的 | 判断の合図 |
|---|---|---|
| **eマーケットプレイス** | 売り手と買い手が取引する場を提供 | 多数の売り手・買い手、インターネット上の市場 |
| O2O（Online to Offline） | オンラインから実店舗への来店・購買につなぐ | ネットのクーポン、店舗への誘導 |
| SCM（Supply Chain Management） | 調達から生産・在庫・物流までの全体最適 | 原材料・生産・在庫・物流の連携 |
| EDI（Electronic Data Interchange） | 企業間の取引データを電子的に交換 | 受発注・請求データ、標準化した形式 |

例えば、**インターネット上に市場を開いて複数企業が部品を売買**するならeマーケットプレイス、**Web広告から店舗へ誘導**するならO2Oです。取引に関わる原材料調達から配送までを最適化するのはSCM、注文データを企業間で決められた形式で交換するのはEDIです。

詳しくは[SCMの記事](/fe/scm/)と[EDIの記事](/fe/edi/)を参照してください。

### BtoB・BtoC・CtoCは「誰から誰へ？」で判断する

ECの取引形態を問う問題では、サービス名を先に覚えるより、**誰が売り手で、誰が買い手か**を確認します。

```text
企業 → 企業
→ BtoB

企業 → 消費者
→ BtoC

消費者 → 消費者
→ CtoC
```

例えば、複数の電子店舗が集まり、一般消費者に商品を販売するWebサイトは、企業から消費者への取引なので **BtoC** に当たります。

このようなサイトは、**バーチャルモール**やECモールなどと呼ばれます。

```text
電子店舗
↓
一般消費者に販売
↓
BtoC
```

### 選択肢の用語が知らなくても切れることがある

ECの問題では、BtoCとは直接関係しない用語が選択肢に混ざることがあります。

| 用語 | 見るポイント |
|---|---|
| バーチャルモール | 複数の電子店舗が集まるECサイト |
| Web-EDI | Web技術を使った企業間のデータ交換 |
| バーチャルカンパニー | ネットワークを活用して企業などが連携する形態 |
| CALS | 製品・技術情報などを電子化して共有・活用する考え方 |

試験では、

```text
一般消費者に商品を販売
↓
企業 → 消費者
↓
BtoC
↓
バーチャルモール
```

という順で考えると判断しやすくなります。

用語名を丸暗記するより、**「誰から誰への取引か？」を先に決める**のがポイントです。

## どんな場面で使う？

ECは、商品やサービスの販売、発注、契約、決済などをネットワーク上で行う場面で使われます。

代表的な例は次のとおりです。

```text
企業間の電子発注
オンラインショップ
バーチャルモール
オンライン予約
電子チケット販売
フリマアプリ
ネットオークション
```

基本情報技術者試験では、ECそのものの定義だけでなく、似た用語との切り分けも問われます。

| 用語 | 何をするものか | 判断の合図 |
|---|---|---|
| EC | 電子的な商取引 | ネットワーク、商品取引、サービス取引 |
| SFA | 営業活動を支援 | 商談、営業効率、営業支援 |
| ERP | 経営資源を統合管理 | 人・物・金・情報、全社、一元管理 |
| リテールサポート | 小売店の経営を支援 | 売場づくり、販売支援、店舗支援 |
| EDI | 企業間で取引データを交換 | 注文書、請求書、データ交換 |

特に、ECとEDIは混同しやすい用語です。

```text
EC
→ 電子的に商取引を行う広い概念

EDI
→ 企業間で注文書や請求書などのデータを交換する仕組み
```

EDIは、BtoBのECを支える手段として使われることがあります。

## よくある誤解・混同

### インターネットを使えば、すべてECになる

違います。

インターネットを利用していても、単に情報を閲覧しているだけなら、商取引を行っているとは限りません。

```text
会社案内を見る
→ ECとは限らない

商品を注文する
→ EC
```

### ECはBtoCだけを指す

違います。

一般消費者向けのネットショップはBtoCですが、企業間取引のBtoBや、個人間取引のCtoCもECに含まれます。

### eマーケットプレイスとEDIは同じ？

違います。**eマーケットプレイスは取引の場**、**EDIは企業間で取引データを交換する仕組み**です。eマーケットプレイスで成立した取引にEDIが使われることはありますが、役割は異なります。

### eマーケットプレイスは必ずBtoB？

違います。もともと企業間の電子取引を説明する場面でよく使われますが、BtoCやCtoCを含む仕組みにも広がっています。**取引の場の形態と売り手・買い手の分類を分けて考えます。**

### Web-EDIはBtoCのサービス？

基本的には違います。

Web-EDIは、Web技術を使って企業間で注文や請求などの取引データを交換する仕組みです。

```text
企業 ↔ 企業
→ Web-EDI
→ BtoB寄り

企業 → 一般消費者
→ BtoC
```

「Webを使っているからBtoC」と判断しないようにします。

### キャッシュレス決済がECそのものである

キャッシュレス決済は、ECを支える仕組みの一つです。

ECは、注文・契約・決済などを含む、電子的な商取引全体を指します。

### SFAやERPもECである

違います。

```text
SFA
→ 営業活動を効率化する

ERP
→ 経営資源を統合管理する

EC
→ 電子的なネットワークで商取引する
```

「何を支援・管理しているか」を見ると切り分けやすくなります。

## まとめ（試験直前用）

- ECは、**電子的なネットワークを利用した商取引**
- BtoBは企業間、BtoCは企業と消費者、CtoCは消費者間
- BtoB・BtoC・CtoCは、まず **「誰から誰への取引か」** で判断する
- **eマーケットプレイスはネット上の取引市場**。BtoBなどの取引主体の分類とは別
- **O2Oはネットから実店舗へ誘導、SCMは供給全体の最適化、EDIは企業間のデータ交換**
- バーチャルモールは、企業が一般消費者に販売する **BtoCの代表例**
- 営業活動の支援はSFA、経営資源の統合管理はERP
- 小売店の経営支援はリテールサポート
- EDIは企業間で注文書や請求書などのデータを交換する仕組み
- 判断の決め手は、**ネットワーク上で商品やサービスを取引しているか**
- CtoCでは、第三者が代金を預かる**エスクローサービス**が使われることがある

## 確認問題（科目A・オリジナル）

複数の工作機械部品メーカーが商品を登録し、複数の購入企業が同じWebサービス上で商品を探して直接発注できる。このサービスの仕組みを表す用語として、最も適切なものはどれか。

- ア：O2O
- イ：eマーケットプレイス
- ウ：SCM
- エ：EDI

**正解：イ**

- **ア：誤り。** O2Oはネット上の施策から実店舗への来店・購買につなぐ考え方です。

- **ウ：誤り。** SCMは調達・生産・在庫・物流などを全体として最適化する取り組みです。
