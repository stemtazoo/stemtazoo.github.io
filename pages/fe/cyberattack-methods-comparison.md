## まず結論

サイバー攻撃の名称を見分けるには、**誰を狙うのか、どこを偽るのか、何をさせるのか**を確認します。

| 手法 | 特徴 | 目印 |
|---|---|---|
| 標的型攻撃 | 特定の組織・人物を狙って攻撃 | 特定の相手、業務に合わせた誘導 |
| APT型攻撃 | 高度な手法を使い、侵入後も長期間活動することがある | 継続的、潜伏、段階的な侵害 |
| 水飲み場型攻撃 | 標的がよく使うサイトを悪用して待ち伏せ | よく利用する正規サイト |
| セッションハイジャック | 有効なセッションを乗っ取る | セッションIDなど |
| DNSキャッシュポイズニング | 名前解決の情報を改ざんして偽の接続先へ誘導 | DNSの偽応答・キャッシュ |
| SEOポイズニング | 検索結果を悪用して不正サイトへ誘導 | 検索順位の操作 |
| IPスプーフィング | IPパケットの送信元アドレスを偽装 | 送信元IPアドレス |

これらは必ずしも排他的ではありません。**一つの攻撃で、複数の手口が組み合わされる場合もあります。**

## 直感的な説明

会社を狙う攻撃を例に考えます。

```text
特定企業を調べ、関係者に偽装メールを送る
→ 標的型攻撃メール

その企業の従業員がよく使うWebサイトで待ち伏せする
→ 水飲み場型攻撃

一度侵入した後、発見されないよう活動を続ける
→ APT型攻撃に見られる特徴
```

標的型攻撃は**対象の選び方**、水飲み場型攻撃は**待ち伏せする場所**、APTは**継続性や攻撃活動の特徴**に注目します。

## 定義・仕組み

### 標的型攻撃・APT・水飲み場型攻撃の関係

**APT（Advanced Persistent Threat）**は、一般に高度な手法を組み合わせ、特定の対象への侵入、潜伏、情報収集などを継続的に行う脅威や攻撃活動を指します。**一通の標的型メールを送っただけで、必ずAPTと呼べるわけではありません。**

APT型攻撃では、標的型メール、水飲み場型攻撃、認証情報の悪用など、複数の侵入手段が利用される場合があります。

**水飲み場型攻撃**では、標的が日頃利用する正規Webサイトを改ざんするなどして待ち伏せします。閲覧した端末を感染させる方法として、[ドライブバイダウンロード](/fe/drive-by-download/)が使われることがあります。

[標的型攻撃メール](/fe/targeted-attack-email/)ではメールの見分け方を詳しく説明しています。

### なりすまし・誘導の種類

| 攻撃 | 何を偽る・悪用する？ | 主な結果 |
|---|---|---|
| IPスプーフィング | IPパケットの送信元アドレス | 送信元の偽装 |
| DNSキャッシュポイズニング | DNSが保持・参照する名前解決情報 | 偽サイトなどへ誘導 |
| SEOポイズニング | 検索順位や検索結果の信頼感 | 不正ページへ誘導 |
| Evil Twin（偽アクセスポイント） | 正規の無線LANに似せたアクセスポイント | 接続の誘導、通信の盗聴など |
| セッションハイジャック | 正規利用者の有効なセッション | ログイン済み利用者へのなりすまし |

**IPスプーフィングはIPアドレスの偽装であり、必ずしもログイン認証を突破できるわけではありません。** DNSキャッシュポイズニングとSEOポイズニングも、それぞれ**DNSの情報**と**検索結果**という攻撃対象が異なります。

### そのほかの攻撃：目的を比べる

| 手法 | 何を狙う？ |
|---|---|
| フィッシング | 偽の連絡やサイトなどで認証情報・個人情報を盗む |
| ドライブバイダウンロード | Web閲覧をきっかけに意図しない不正プログラムを送り込む |
| クリックジャッキング | 画面の表示を重ねるなどして意図しないクリックを誘う |
| バッファオーバーフロー攻撃 | プログラムの領域外への書込みなどの欠陥を悪用 |
| Webビーコン | 画像等の読み込みを通じアクセス状況を把握。**技術自体が必ず攻撃とは限らない** |

Webビーコンはアクセス解析などの正当な用途にも使われます。そのため、試験では「小さな画像を使う」というだけで**攻撃**と決めつけないことが大切です。

- [フィッシング](/fe/phishing/)
- [Webビーコン](/fe/web-beacon/)

## 科目Aでどう出る？

### 問題文の手掛かりから判断する

| 問題文の説明 | 選びたい名称 |
|---|---|
| 特定組織を長期的に狙い、侵入後も潜伏して活動 | APT型攻撃 |
| 特定組織の社員がよく閲覧するサイトを悪用 | 水飲み場型攻撃 |
| 送信元のIPアドレスを偽装 | IPスプーフィング |
| DNSキャッシュに偽の名前解決情報を保存 | DNSキャッシュポイズニング |
| 検索結果から不正サイトへ誘導 | SEOポイズニング |
| 正規利用者のセッションIDを悪用 | セッションハイジャック |
| 偽の無線LANアクセスポイントに接続させる | Evil Twin |
| 画面を重ねて意図しないボタンを押させる | クリックジャッキング |

### 確認問題

ある攻撃者が特定企業の情報を調査し、関係者を狙って侵入した。侵入後も複数の手段を用いて長期間潜伏し、情報を継続的に収集した。この活動の特徴を表す用語として最も適切なのはどれか。

- ア：SEOポイズニング
- イ：APT型攻撃
- ウ：Webビーコン

**正解：イ。** 特定の対象への侵入に加えて、継続的な活動・潜伏が決め手です。SEOポイズニングは検索結果の悪用、Webビーコンは画像等の読み込みを利用した計測技術です。

## どんな場面で使う？

企業の情報セキュリティ教育、インシデント報告、脅威の分類などです。実際の防御は単一の攻撃名だけでは決まりません。認証、脆弱性対策、ログ監視、Web・メール対策などを組み合わせます。

例えば、APT型攻撃への備えでは、侵入防止だけでなく**侵入の兆候を検知し、横展開や情報流出を抑える**ことも重要です。

## よくある誤解・混同

### 「標的型攻撃メール＝APT型攻撃」？

同義ではありません。標的型メールは侵入手段の一つで、APT型攻撃は継続的な活動など、より広い攻撃の特徴を含みます。

### 「水飲み場型攻撃＝ドライブバイダウンロード」？

同義ではありません。前者は標的が利用するサイトで**待ち伏せする狙い方**、後者はWeb閲覧を通じた**感染手段**です。

### 「Webビーコンは必ず違法なマルウェア」？

違います。アクセス計測など正当な目的にも使われます。ただし、利用者への告知やプライバシーへの配慮が重要です。

## まとめ（試験直前用）

- 標的型攻撃：**誰を狙うか**
- 水飲み場型攻撃：**どこで待ち伏せするか**
- APT：**継続的・高度な攻撃活動**
- DNSキャッシュポイズニングは**名前解決**、SEOポイズニングは**検索結果**
- IPスプーフィングは**送信元IP偽装**、セッションハイジャックは**有効なセッションの乗っ取り**
- Webビーコン自体は正当なアクセス計測にも使われる
