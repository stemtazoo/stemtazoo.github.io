## まず結論

UPS（Uninterruptible Power Supply：無停電電源装置）は、**停電や瞬断が起きたときに、バッテリーなどから一時的に電力を供給する装置**です。

基本情報技術者試験では、次の表現が判断の合図になります。

```text
停電・瞬断
＋
短時間だけ電力を供給
→ UPS
```

目的は、停電中ずっと動かし続けることではありません。

**システムを安全に終了する時間を確保したり、自家発電装置へ切り替わるまでをつないだりする**のが重要な役割です。

## 直感的な説明

UPSは、電源の「橋渡し役」と考えると分かりやすいです。

```text
通常の電源
↓
停電・瞬断
↓
UPSがすぐに給電
↓
安全にシャットダウン
または
自家発電装置へ切替え
```

自家発電装置は発電を開始して電力を供給できますが、停電した瞬間から必ず電力を供給できるとは限りません。

そこでUPSが短時間をつなぎます。

> **UPSは短時間をつなぐ。自家発電装置は長時間を支える。**

この違いを押さえると、選択肢をかなり切りやすくなります。

## 定義・仕組み

UPSは、商用電源が正常なときには機器へ電力を供給しながら、内部のバッテリーを充電します。

停電や瞬断が発生すると、バッテリーなどの蓄電エネルギーを使って負荷へ電力を供給します。

代表的な流れは次のとおりです。

```text
通常時
商用電源 → UPS → サーバなど
            ↓
         バッテリー充電

停電時
バッテリー → UPS → サーバなど
```

UPSによって構成や給電方式は異なりますが、FE試験ではまず、

**「電源が途切れたときに一時的に電力を供給する」**

という役割を押さえれば十分です。

## 科目Aでどう出る？

科目Aでは、UPSそのものの定義だけでなく、似た電源設備との違いが問われます。

| 用語 | 主な役割 | 判断キーワード |
|---|---|---|
| AVR | 電圧を一定範囲に調整する | 電圧の安定 |
| CVCF | 電圧と周波数を一定にする | 定電圧・定周波数 |
| **UPS** | **停電・瞬断時に一時的に給電する** | **短時間・瞬断・安全停止** |
| 自家発電装置 | 発電して比較的長時間の停電に対応する | 長時間・発電 |

試験中は、まず「何を安定・確保したいのか」を見ます。

```text
電圧を安定
→ AVR

電圧＋周波数を安定
→ CVCF

停電直後に短時間給電
→ UPS

長時間の停電に備えて発電
→ 自家発電装置
```

特に、

> **「システムを終了するのに必要な時間だけ電力を供給する」**

のような表現があれば、UPSを強く疑います。

## どんな場面で使う？

UPSは、突然電源が切れるとデータ破損やシステム障害につながる機器で使われます。

例えば、

- サーバ
- ストレージ
- ネットワーク機器
- データベースを動かすシステム

などです。

停電時にUPSから一時的に給電できれば、必要なデータを保存し、OSやシステムを正常な手順で終了できます。

また、長時間の停電に備えて自家発電装置を設置している場合でも、

```text
停電
↓
UPSでつなぐ
↓
自家発電装置が始動
↓
発電機から給電
```

という組合せが考えられます。

電力そのものと電力量の計算は、[電力と電力量の違い](/fe/electric-power-energy-wh/)で整理しています。

## よくある誤解・混同

### 誤解1：UPSがあれば停電中ずっと運転できる

UPSの役割は、基本的に**短時間の給電**です。

```text
短時間をつなぐ
→ UPS

長時間の停電へ対応
→ 自家発電装置
```

「停電対策」という言葉だけで判断せず、**必要な時間の長さ**を確認します。

### 誤解2：UPSとAVRは同じ

違います。

```text
AVR
→ 電圧を安定させる

UPS
→ 電源が途切れたときに一時的に給電する
```

問題文に「電圧変動」とあればAVR、「停電・瞬断」とあればUPSを考えます。

### 誤解3：UPSとCVCFは同じ

CVCF（Constant Voltage Constant Frequency）は、**電圧と周波数を一定にする**ことが中心です。

```text
定電圧・定周波数
→ CVCF

停電時の一時給電
→ UPS
```

装置の実際の機能が重なる場合があっても、試験では**問われている主目的**で切り分けます。

### 誤解4：UPSはバックアップ装置だからデータも保存してくれる

UPSがバックアップするのは電源です。

データのバックアップとは役割が異なります。

```text
UPS
→ 電力を一時的に確保

データバックアップ
→ データを別の場所・媒体へ保存
```

## まとめ（試験直前用）

- UPS＝停電・瞬断時に一時的に電力を供給
- 安全なシャットダウンや発電機への切替えまでの時間を確保する
- AVR＝電圧を安定
- CVCF＝電圧と周波数を安定
- 自家発電装置＝比較的長時間の停電へ対応
- UPSとデータバックアップは別物

試験直前には、次の一文で整理します。

> **瞬断をつなぐならUPS、長時間なら発電機、電圧ならAVR、電圧＋周波数ならCVCF。**
