## まず結論

OCR・OMR・イメージスキャナ・タブレットは、すべて入力に関係しますが、**何を入力するか**が違います。

<div class="input-device-flow">
  <div class="input-device-card"><strong>OCR</strong>文字</div>
  <div class="input-device-card"><strong>OMR</strong>マーク</div>
  <div class="input-device-card"><strong>スキャナ</strong>画像</div>
  <div class="input-device-card"><strong>タブレット</strong>位置・座標</div>
</div>

FEでは、装置名を丸暗記するより、

> **文字・マーク・画像・座標のどれを入力するのか**

で選択肢を切ると判断しやすくなります。

## 直感的な説明

例えば、紙に書かれたものをコンピュータへ入力するとします。

~~~text
文章を文字データにしたい
→ OCR

マークシートを読みたい
→ OMR

紙面全体を画像として取り込みたい
→ イメージスキャナ

ペンで場所を指定して図形を描きたい
→ タブレット
~~~

同じ「入力装置」でも、役割はかなり違います。

特に**タブレットは位置を指し示す装置**なので、マウスと同じくポインティングデバイスとして考えられます。

## 定義・仕組み

### OCR：文字を読み取る

OCR（Optical Character Recognition / Reader）は、紙や画像に含まれる文字を認識し、コンピュータで扱える文字データに変換する技術・装置です。

~~~text
紙・画像の文字
↓
OCR
↓
文字データ
~~~

判断語は **「文字」** です。

### OMR：マークを読み取る

OMR（Optical Mark Reader）は、用紙に記入されたマークの位置を読み取る装置です。

代表例はマークシートです。

~~~text
塗りつぶしたマーク
↓
OMR
↓
選択された位置を読み取る
~~~

判断語は **「マーク」** です。

### イメージスキャナ：画像として取り込む

イメージスキャナは、写真や書類などを画像データとしてコンピュータへ取り込みます。

スキャナで文章を読み込んだだけでは、基本的には画像です。文字として認識する処理が必要ならOCRを使います。

> **スキャナ＝画像を取り込む、OCR＝画像内の文字を認識する**

と切り分けます。

### タブレット：位置・座標を入力する

ここでいうタブレットは、主にペンタブレットのような入力装置です。

ペンなどで指した位置を座標として入力できるため、図形入力や描画に向いています。

~~~text
ペンで位置を指す
↓
座標を入力
↓
画面上のポインタ・図形に反映
~~~

このため、タブレットは**ポインティングデバイス**に分類されます。

## CADとタブレットの関係

CADでは、図面上の位置を正確に指定する操作が多くあります。

~~~text
点を指定する
↓
線の始点・終点を決める
↓
図形を配置する
~~~

必要なのは「文字を読む」ことではなく、**位置・座標を指定すること**です。

したがってFEで、

> CADの図形入力に使うポインティングデバイス

と出たら、

~~~text
CAD
→ 図形
→ 座標指定
→ ポインティングデバイス
→ タブレット
~~~

と判断できます。

## 科目Aでどう出る？

次の対応を覚えておけば、多くの選択肢を意味から切れます。

| 問題文のキーワード | 選ぶもの |
|---|---|
| 文字を認識 | OCR |
| マークシート | OMR |
| 写真・書類を画像として取り込む | イメージスキャナ |
| 位置・座標を指定 | タブレット |
| CADで図形入力 | タブレット |

特に「ポインティング」という言葉が出たら、

> **point＝場所を指す**

と考えるのが近道です。

## どんな場面で使う？

OCRは紙の文書を文字データ化するとき、OMRはアンケートや試験のマークシートを読み取るとき、イメージスキャナは写真や書類を画像として保存するときに使います。

タブレットは、CADによる図面作成やイラスト制作など、細かな位置を指定する作業に向いています。

## よくある誤解・混同

### OCRとスキャナは同じ

違います。

~~~text
スキャナ
→ 画像を取り込む

OCR
→ 画像などにある文字を認識する
~~~

スキャンした画像にOCR処理を行う、という組合せもあります。

### OCRとOMRは同じ

違います。

名前は似ていますが、

~~~text
OCR → Character → 文字
OMR → Mark → マーク
~~~

と考えると区別できます。

### 入力装置ならすべてポインティングデバイス

違います。

ポインティングデバイスは、**画面上などの位置を指定するための入力装置**です。

OCR・OMR・スキャナは入力に使いますが、位置を指し示すことが主目的ではありません。

### 「タブレット」はタブレット端末だけを意味する

試験では文脈に注意します。

入力装置やCAD、ポインティングデバイスの文脈で「タブレット」とあれば、ペンなどで位置を入力する装置を指していると判断します。

## まとめ（試験直前用）

~~~text
文字 → OCR
マーク → OMR
画像 → スキャナ
座標 → タブレット
~~~

さらに、

> **CAD → 図形 → 座標指定 → タブレット**

とつなげておけば、ポインティングデバイスの問題にも対応できます。

装置名を一つずつ暗記するのではなく、**「何を入力するのか？」を先に見る**のがFEでの判断基準です。
