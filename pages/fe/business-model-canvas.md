## まず結論

**ビジネスモデルキャンバス（Business Model Canvas：BMC）**は、事業が**誰に、どのような価値を、どう届け、何で収益を得るか**を、9つの要素で整理する枠組みです。

| 見る視点 | 主な問い | 要素 |
|---|---|---|
| 顧客・価値 | 誰に、何を提供する？ | 顧客セグメント・価値提案 |
| 顧客との接点 | どう届け、関係を続ける？ | チャネル・顧客との関係 |
| 事業の実現 | 何が必要で、誰と実行する？ | 主要活動・主要リソース・主要パートナー |
| お金の流れ | 何に費用が掛かり、どう稼ぐ？ | コスト構造・収益の流れ |

**9要素を一つの事業について並べて整理すること**が大切です。単なる財務計算表や事業の作業手順書ではありません。

## 直感的な説明

例えば、工場向けの「設備の遠隔監視サービス」を始めるとします。

```text
誰に？        → 設備を保守する工場
何を？        → 故障の兆候を早めに知る価値
どう届ける？  → Web画面と通知
何が必要？    → センサー、分析システム、保守人員
いくらで？    → 月額利用料
何に費用？    → 開発、通信、サーバ、サポート
```

このように、サービスを成立させるための要素を**一枚に整理して、抜けや矛盾がないかを考える**のがビジネスモデルキャンバスです。

## 定義・仕組み

### 9つの構成要素

| 要素（英語） | 何を考える？ | 遠隔監視サービスの例 |
|---|---|---|
| 顧客セグメント（Customer Segments） | 誰のための事業か | 中小製造業の保全担当者 |
| 価値提案（Value Propositions） | 顧客のどんな問題を解決するか | 異常の兆候を早く把握できる |
| チャネル（Channels） | 顧客にどう届けるか | 営業、Web、販売代理店 |
| 顧客との関係（Customer Relationships） | 顧客とどう継続的に関わるか | 導入支援、問い合わせ対応 |
| 収益の流れ（Revenue Streams） | どう売上を得るか | 月額契約、初期導入費 |
| 主要リソース（Key Resources） | 事業に必要な資源は何か | センサー、分析基盤、人材 |
| 主要活動（Key Activities） | 重要な活動は何か | 異常検知モデルの運用、保守 |
| 主要パートナー（Key Partners） | 誰と協力するか | センサーメーカー、販売会社 |
| コスト構造（Cost Structure） | どんな費用が生じるか | 開発費、通信費、保守費 |

ここでの「収益の流れ」は**売上の得方**であり、「コスト構造」は**費用の発生源**です。両者は混同しません。

### 9要素の関係を整理する

```text
主要パートナー ─ 主要活動 ─ 価値提案 ─ チャネル ─ 顧客セグメント
                    │          │          │
               主要リソース    │     顧客との関係
                    │          │          │
                 コスト構造    └────── 収益の流れ
```

これは9要素の関係を簡略化した学習用の図です。正式なキャンバスの配置を完全に再現したものではありません。

試験では、配置の暗記よりも**「顧客」「提供価値」「販売・関係」「実行資源」「お金」**のどの内容を説明しているかで切り分けましょう。

### 触って覚える：事業の説明を9要素に当てはめる

最初に、以下の説明がどの構成要素を指すかを予想し、見出しを開いて正解を確認してください。

<details markdown="1">
<summary>ケース1：故障の予兆を通知することで、設備停止のリスクを減らす</summary>

**価値提案**。顧客がサービスを利用して得る便益や、解決する問題を説明しています。

</details>

<details markdown="1">
<summary>ケース2：保全担当者に、月額2万円の利用料を請求する</summary>

**収益の流れ**。事業がどのように売上を得るかを説明しています。金額はこの教材用の仮定です。

</details>

<details markdown="1">
<summary>ケース3：センサーを作る企業と協力して機器を供給する</summary>

**主要パートナー**。事業を成り立たせる外部の協力先を説明しています。

</details>

<details markdown="1">
<summary>ケース4：機械学習モデルを継続的に更新して予測精度を保つ</summary>

**主要活動**。価値を提供するために実行する重要な業務です。

</details>

<details markdown="1">
<summary>ケース5：顧客からの問合せにサポート窓口で対応する</summary>

**顧客との関係**。顧客との接点を維持・発展させる方法です。

</details>

### ブルーオーシャン戦略との関係

ビジネスモデルキャンバスは**事業の仕組みを9要素に整理するツール**です。一方、[ブルーオーシャン戦略](/fe/blue-ocean-strategy/)は、**新しい価値と市場をつくり、既存の競争を回避する戦略**です。

| 用語 | 問い |
|---|---|
| ビジネスモデルキャンバス | 事業はどのような仕組みで成立するか？ |
| ブルーオーシャン戦略 | 既存の競争から離れ、新しい需要をどう生み出すか？ |

ブルーオーシャン戦略の中心には、**差別化と低コストを同時に追求するバリューイノベーション（価値革新）**という考え方があります。事業の価値や費用の見直しをキャンバスに反映させることもできますが、**両者は同義ではありません**。

## 科目Aでどう出る？

問題文で次の表現があれば、対応する要素を探します。

| 問題文のキーワード | 要素 |
|---|---|
| 誰に売るか、対象顧客 | 顧客セグメント |
| 顧客が得られる便益、課題解決 | 価値提案 |
| 販路、サービスを届ける方法 | チャネル |
| 顧客への継続支援、関係維持 | 顧客との関係 |
| 利用料、販売収入 | 収益の流れ |
| 人材、設備、技術など必要な資源 | 主要リソース |
| 開発、製造、運用など重要な活動 | 主要活動 |
| 取引先、外部協力会社 | 主要パートナー |
| 人件費、運用費などの費用 | コスト構造 |

### 確認問題

新しい工場向けサービスについて、対象とする顧客企業を「従業員50～300人の製造業」と定めた。この記述が最も直接的に該当するビジネスモデルキャンバスの要素はどれか。

- ア：価値提案
- イ：顧客セグメント
- ウ：主要活動
- エ：コスト構造

<details markdown="1">
<summary>正解と解説を見る</summary>

**正解：イ（顧客セグメント）**。誰に価値を提供するかを定めているからです。「どんな問題を解決するか」は価値提案になります。

</details>

## どんな場面で使う？

新規サービスの構想、既存事業の見直し、収益構造の検討、部門間の認識合わせに利用できます。例えば、顧客にとって重要な価値を変更すれば、販売チャネル、必要な活動や資源、コストにも影響するため、**要素間のつながり**を確認します。

## よくある誤解・混同

### 「9要素を埋めれば必ず成功する」？

違います。仮説を整理する道具です。顧客への確認や収支の検証を通じて更新する必要があります。

### 「収益の流れ＝利益」？

違います。収益は売上の得方であり、利益を考えるには費用も確認する必要があります。

### 「業務モデルの現物理・現論理・新論理・新物理と同じ」？

違います。こちらは業務を現状／将来、論理／物理の観点から整理する分類です。詳しくは[業務モデルの4種類](/fe/business-model-four-types/)を参照してください。

### 「ブルーオーシャン戦略と同じ」？

違います。キャンバスは事業全体の仕組みを可視化する枠組み、ブルーオーシャンは新しい需要や市場をつくる戦略です。

## まとめ（試験直前用）

- **ビジネスモデルキャンバスは9要素**で事業の仕組みを整理する。
- 「顧客・価値・接点・実行・収益とコスト」に分けると覚えやすい。
- **チャネルは届け方**、**顧客との関係は関係維持の方法**。
- **主要リソースは必要なもの**、**主要活動は行うこと**。
- ブルーオーシャン戦略とは役割が異なる。
