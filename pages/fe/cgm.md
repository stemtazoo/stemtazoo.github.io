## まず結論

**CGM（Consumer Generated Media）**とは、**一般の利用者が投稿・作成した情報を中心に成り立つメディア**です。

基本情報技術者試験の科目Aでは、まず「**誰がコンテンツを作っているか**」を確認します。

> **利用者の口コミや投稿が中心 → CGM**

企業が商品情報を発信する公式サイトとは、情報の作り手が違います。

## 直感的な説明

同じ商品を紹介するページでも、情報の作り手によって性質が変わります。

```text
企業が「この商品の特徴」を紹介
  → 企業公式サイト

購入者が「使ってみた感想」を投稿
  → 利用者の投稿を中心とするCGM
```

**商品について書いてあるかどうかではなく、誰が内容を作ったか**を見るのがポイントです。

## 定義・仕組み

CGMは、利用者の投稿によって情報が増えていくメディアです。

| CGMの例 | 利用者が作る内容 |
|---|---|
| 口コミ・レビューサイト | 商品やサービスの評価 |
| Q&Aサイト | 質問と回答 |
| SNS | 個人の投稿や感想 |
| 個人ブログ | 体験談や解説 |
| 動画投稿サイト | 利用者が制作した動画 |

ただし、**SNSに掲載された情報がすべてCGMというわけではありません**。企業公式アカウントの広告や告知は、利用者が作成した投稿とは区別します。

### UGCとの違い

**UGC（User Generated Content）**は、利用者が作った**コンテンツそのもの**を指します。

```text
口コミサイトというメディア → CGM
その中の利用者の口コミ → UGC
```

CGMは「メディア」、UGCは「コンテンツ」と捉えると整理しやすくなります。実際には両者が近い意味で使われる場面もあります。

## 科目Aでどう出る？

科目Aでは、Webサイトの説明からCGMに該当するものを選ぶ問題が考えられます。

| 説明の手掛かり | 判断 |
|---|---|
| 個人が商品レビューを投稿し、利用者の投稿が中心となる | **CGM** |
| 企業が自社製品の特徴や価格を掲載する | 企業公式サイト |
| 企業が株主・投資家向けに業績を公表する | IR情報 |
| 行政機関が政策や手続きを案内する | 行政公式サイト |

特に、**「商品情報」という共通点だけで判断しない**ことが大切です。

```text
企業が説明する → 公式情報
利用者が体験を投稿する → CGM
```

## どんな場面で使う？

商品を購入する前に、公式サイトで仕様を調べ、口コミサイトで実際の利用者の感想を確認する場面を考えます。

公式サイトは企業からの説明、口コミサイトは利用者による評価を中心とする情報源です。CGMでは多様な体験を知ることができますが、投稿の正確さや公平さが常に保証されるわけではありません。

## よくある誤解・混同

### ❌ SNSならすべてCGM

SNSは利用者の投稿を中心とするCGMの代表例ですが、企業の公式告知も掲載されます。**投稿の作り手**まで見て判断します。

### ❌ CGMとUGCは全く同じ意味

近い関係にありますが、試験では次のように整理できます。

- **CGM**：利用者の情報によって成り立つメディア
- **UGC**：利用者が作成した投稿・写真・動画などのコンテンツ

### ❌ 商品を紹介するサイトはすべてCGM

企業自身が商品の仕様を掲載する公式サイトは、通常CGMとは区別します。

## まとめ（試験直前用）

- **CGM：利用者が作る情報を中心としたメディア**
- **UGC：利用者が作ったコンテンツそのもの**
- 口コミサイト、Q&Aサイト、個人ブログなどが代表例
- 企業公式サイトとの違いは、**情報を作る主体**
- 「SNSだから」ではなく、**誰の投稿か**で判断する

> **利用者が投稿してメディアを形作る → CGM**
