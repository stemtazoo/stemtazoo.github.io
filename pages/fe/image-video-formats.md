## まず結論

画像・音声・動画の圧縮方式は、**何を圧縮する技術なのか**から切り分けます。JPEG・GIF・BMP・MPEGに加え、音声のMP3・AACや動画のH.264を混同しないことが重要です。

基本情報技術者試験では、次のように切り分けます。

```text
写真などの静止画を圧縮
→ JPEG

256色・簡易アニメーション
→ GIF

Windowsで使われる基本的な無圧縮画像
→ BMP

動画や音声を圧縮
→ MPEG
```

特に重要なのは、**JPEGは静止画、MP3・AACは音声、H.264は動画**という違いです。

さらに、問題文に **「静止画データの圧縮符号化に関する国際標準」** とあれば、JPEGを強く疑います。

> **静止画の圧縮標準 → JPEG、動画の圧縮標準 → MPEG**

## 直感的な説明

画像や動画の形式は、すべて同じ目的で使われるわけではありません。

例えば、次のように考えると分かりやすいです。

```text
写真を軽く保存したい
→ JPEG

色数の少ないロゴや簡単なアニメーション
→ GIF

画素データをそのまま保存したい
→ BMP

動画を圧縮して保存・配信したい
→ MPEG
```

つまり、試験では形式名だけを暗記するよりも、**何を扱い、どのように圧縮するか**を見ることが大切です。

## 定義・仕組み

### JPEG

JPEGは、写真などの静止画を圧縮するための国際標準規格です。

一般に、画像の一部の情報を減らしてファイルサイズを小さくする**非可逆圧縮**が使われます。

| 項目 | 内容 |
|---|---|
| 主な対象 | 写真などの静止画 |
| 圧縮 | 非可逆圧縮 |
| 規格の位置づけ | 静止画の圧縮符号化に関する国際標準 |
| 得意 | 色の変化が滑らかな画像 |
| 苦手 | 文字、線画、ロゴ |

圧縮率を高くすると容量は小さくなりますが、輪郭のにじみやブロック状の乱れが目立つことがあります。

### GIF

GIFは、最大256色を扱える画像形式です。

| 項目 | 内容 |
|---|---|
| 主な対象 | ロゴ、アイコン、簡単なイラスト |
| 圧縮 | 可逆圧縮 |
| 色数 | 最大256色 |
| 特徴 | 透過、簡易アニメーション |

色数が少ないため、フルカラー写真には向きません。

### BMP

BMPは、Windowsで広く使われてきたビットマップ画像形式です。

基本情報技術者試験では、**基本的に無圧縮で容量が大きい静止画形式**として扱われます。

| 項目 | 内容 |
|---|---|
| 主な対象 | 静止画 |
| 圧縮 | 基本的に無圧縮 |
| 特徴 | 画素データをそのまま保持しやすい |
| 注意 | ファイル容量が大きくなりやすい |

### PNG

PNGは、静止画像に用いられる形式で、一般に**可逆圧縮**を使います。写真よりも文字・図形や透過画像に向く場面があります。

### MP3・AAC

**MP3とAACは音声を圧縮する方式**です。音楽や動画に含まれる音声などで使われます。AACはMPEG規格群に含まれる音声符号化方式でもあるため、**「MPEGという名前が出たら必ず動画専用」ではありません**。

### H.264 / MPEG-4 AVC

**H.264（MPEG-4 AVC）は動画を圧縮する規格**です。ワンセグ放送などに採用されており、動画配信や録画にも使われます。H.264とMPEG-4 AVCは同じ規格を指す名称です。規格間の違いは[ MPEGの種類とH.264 ](/fe/mpeg/)でも整理しています。

### MPEG

MPEGは、動画や音声を圧縮するための国際標準規格群です。

動画では、各フレームをすべて独立して保存するのではなく、前後の画像との差分なども利用してデータ量を減らします。

| 項目 | 内容 |
|---|---|
| 主な対象 | 動画、音声 |
| 圧縮 | 主に非可逆圧縮 |
| 特徴 | 時間方向の変化も利用して圧縮 |

このテーマは、基本情報技術者試験の「マルチメディア」「画像・動画の符号化」と関係します。公式の出題範囲やシラバスは、[IPA：基本情報技術者試験](https://www.ipa.go.jp/shiken/kubun/fe.html) から確認できます。

## 科目Aでどう出る？

科目Aでは、画像や動画の特徴から対応する形式を選ぶ問題が出やすいです。

| 問題文のキーワード | 選ぶ形式 |
|---|---|
| 静止画、圧縮符号化、国際標準 | JPEG |
| 写真、静止画、非可逆圧縮 | JPEG |
| 256色、透過、簡易アニメーション | GIF |
| Windows Bitmap、無圧縮 | BMP |
| 動画、映像、音声、圧縮標準 | MPEG |

### 圧縮対象で最初に切り分ける

| 問題文のヒント | 候補となる方式 |
|---|---|
| デジタルカメラの静止画・写真 | JPEG |
| 静止画・可逆圧縮・透過 | PNG |
| 音楽・音声の圧縮 | MP3・AAC |
| 5.1チャンネルのサラウンド音声 | Dolby Digital（AC-3）など |
| 携帯電話の通話音声 | AMR・EVSなど |
| ワンセグ放送の動画 | H.264 / MPEG-4 AVC |

まず「静止画・音声・動画」を判定し、次に用途を確認します。例えば**ワンセグの動画圧縮**ならH.264を選び、音声圧縮や静止画圧縮の選択肢を除外できます。

### 「国際標準」だけで決めない

JPEGだけでなく、MPEGも国際標準です。

そのため、問題文に「国際標準」とあるだけでJPEGを選ぶのではなく、**何を圧縮する規格なのか**まで確認します。

```text
静止画の圧縮符号化
→ JPEG

動画・音声の圧縮
→ MPEG
```

### JPEGとMPEGの切り分け

名前が似ていますが、対象が違います。

```text
JPEG
→ 静止画

MPEG
→ 動画・音声
```

### 可逆圧縮と非可逆圧縮

| 種類 | 特徴 | 代表例 |
|---|---|---|
| 可逆圧縮 | 元のデータへ完全に戻せる | GIF、PNG |
| 非可逆圧縮 | 一部の情報を失う代わりに圧縮率を高める | JPEG、MPEG |

問題文に「元に完全に戻せる」とあれば可逆圧縮、「多少画質を落として容量を小さくする」とあれば非可逆圧縮を考えます。

## どんな場面で使う？

音楽配信などではMP3・AACのような音声圧縮、動画配信ではH.264のような動画圧縮を利用します。一本の動画に**映像と音声が両方含まれる**場合も、それぞれ異なる方式で圧縮されることがあります。


### JPEGが向く場面

- デジタルカメラの写真
- Webサイトの写真
- 商品画像
- 背景画像

色の変化が多い写真を比較的小さな容量で保存できます。

### GIFが向く場面

- アイコン
- 色数の少ないロゴ
- 短いアニメーション
- 単純な図形

ただし、写真には向きません。

### BMPが向く場面

- 圧縮せずに画像を保持したい場面
- Windowsアプリケーション内部での画像処理
- 学習用の単純なビットマップデータ

容量が大きいため、Web配信には一般に不向きです。

### MPEGが向く場面

- 動画ファイル
- 映像配信
- 音声付き映像
- デジタル放送や動画保存

## よくある誤解・混同

### H.264は音声圧縮方式？

違います。**H.264は動画圧縮**です。音声圧縮のMP3・AAC・AC-3・AMRなどと区別します。

### MPEG-4とH.264は必ず同じ意味？

MPEG-4は幅広い規格群を指し、**H.264 / MPEG-4 AVCはその中の動画符号化規格**です。「MPEG-4」という語だけでH.264と同一視しないようにします。


### JPEGは可逆圧縮である

誤りです。

一般的なJPEGは非可逆圧縮です。圧縮後に完全に元へ戻るわけではありません。

### 「国際標準」とあれば必ずJPEG

誤りです。

MPEGも動画や音声の圧縮に関する国際標準です。

**静止画ならJPEG、動画・音声ならMPEG** と対象まで確認します。

### GIFはフルカラー写真に向く

誤りです。

GIFは最大256色なので、写真では色の不足が目立ちやすくなります。

### BMPは圧縮率が高い

誤りです。

試験では、BMPは基本的に無圧縮で容量が大きい形式として扱います。

### MPEGは静止画専用である

誤りです。

MPEGは動画や音声の圧縮に使われます。

### PNGとGIFは同じ

どちらも可逆圧縮に対応しますが、PNGは一般にフルカラーや半透明を扱えます。

```text
GIF
→ 256色、簡易アニメーション

PNG
→ フルカラー、可逆圧縮、透過
```

## まとめ（試験直前用）

- **JPEG・PNG：静止画、MP3・AAC：音声、H.264：動画**
- **H.264 = MPEG-4 AVC**。ワンセグなどの動画圧縮に使われる
- MPEG-4は規格群であり、H.264だけを指す名称ではない

- JPEGは、写真などの静止画を非可逆圧縮する国際標準
- GIFは、最大256色で透過や簡易アニメーションに対応する
- BMPは、基本的に無圧縮で容量が大きい
- MPEGは、動画や音声を圧縮する国際標準規格群
- **静止画の圧縮標準ならJPEG、動画・音声ならMPEG**
- 「国際標準」だけでなく、何を扱う規格かを見る
- 元へ完全に戻せるのが可逆圧縮、戻せないのが非可逆圧縮
