## まず結論

2進数の問題では、最初に何を問われているかを分けます。

```text
負数の表現 → 2の補数
小数の表現 → 2進小数
```

2の補数で表された負数の絶対値は、**ビットを反転して1を足す**ことで求めます。

2進小数は、小数点以下を `1/2、1/4、1/8、1/16…` と読みます。

「2進数で有限小数なら、10進数でも有限になるのか？」のような基数間の有限・循環の判断は、[有限小数になる条件とは？](/fe/finite-fraction-radix/)で整理しています。

## 直感的な説明

2進数は0と1だけで数を表します。

ただし、同じビット列でも、

- 符号なし整数
- 2の補数
- 2進小数

のどれとして読むかで意味が変わります。

FE試験では、まず「どのルールで読むのか」を確認します。

## 定義・仕組み

### 2の補数

2の補数は、負数を2進数で表す代表的な方法です。

絶対値を求める手順は次のとおりです。

```text
1. すべてのビットを反転する
2. 1を足す
```

例えば、`11100100` を8ビットの2の補数として読む場合です。

```text
11100100
↓ 反転
00011011
↓ 1を足す
00011100
```

したがって、絶対値は `00011100`（10進数の28）です。

### 2進小数

2進小数では、小数点以下の桁に2の負の累乗を使います。

```text
0.1     = 1/2
0.01    = 1/4
0.001   = 1/8
0.0001  = 1/16
0.00001 = 1/32
```

例えば `7/32` は、

```text
7/32 = 4/32 + 2/32 + 1/32
     = 1/8 + 1/16 + 1/32
```

なので、2進小数では `0.00111` です。

### 2進小数の桁を目で確認する

2進小数は、**小数点から右へ進むほど各桁の値が半分になる**と考えます。

| 小数第1位 | 小数第2位 | 小数第3位 | 小数第4位 | 小数第5位 |
|---|---|---|---|---|
| 1/2 | 1/4 | 1/8 | 1/16 | 1/32 |
| 0 | 0 | **1** | **1** | **1** |

上の1がある位置だけを足すと、次の値になります。

```text
0 . 0 0 1 1 1 ₂
    │ │ │ │ └─ 1/32
    │ │ │ └─── 1/16
    │ │ └───── 1/8
    │ └─────── 1/4（0なので足さない）
    └───────── 1/2（0なので足さない）
```

`1/8 + 1/16 + 1/32 = 7/32` なので、`0.00111₂` と確認できます。

### 2の累乗で割るときの別解

分母が `2ⁿ` なら、整数を2進数へ変換し、**小数点を左へn桁動かす**方法も使えます。

```text
7₁₀ = 111₂
32 = 2⁵

111.₂
↓ 小数点を左へ5桁
0.00111₂
```

これは「値を2⁵で割る」操作を、2進数の桁の位置で表したものです。

**注意：** ここで動かしているのは小数点です。整数のビット列を論理右シフトすると、通常は小数部分が捨てられるため、同じ結果にはなりません。整数のシフトについては[シフト演算とは？](/fe/shift-operation/)で確認できます。

## 科目Aでどう出る？

科目Aでは、問題文で指定された表現方法を確認してから計算します。

```text
2の補数で表された負数を読む → ビットを反転して1を足し、絶対値を求める
2進小数を変換する           → 小数点以下を1/2、1/4、1/8…の位として読む
```

同じビット列でも、符号なし整数か2の補数かで値が変わります。また、2進小数は各桁の重みを足すか、分数を2の累乗へ分解して判断します。

## どんな場面で使う？

2の補数は、コンピュータ内部で負数を表すときに使われます。

2進小数は、小数を2進数で表すときの基本です。浮動小数点数を学ぶ前提にもなります。

## よくある誤解・混同

### 反転だけで終わる

2の補数では、反転したあとに1を足します。

### 先頭が1なら必ず負数

「2の補数で表されている」と指定された場合に限ります。符号なし整数なら、先頭が1でも負数ではありません。

### 2進小数を10進小数の感覚で読む

`0.001(2)` は1000分の1ではなく、8分の1です。

### 確認問題：2進小数を選ぶ

10進数の `5 ÷ 16` を2進小数で表すと、どれでしょうか。

- ア. `0.00101₂`
- イ. `0.0101₂`
- ウ. `0.101₂`
- エ. `0.011₂`

<details markdown="1">
<summary>▶ 答えと考え方を見る</summary>

**正解：イ（0.0101₂）**

```text
5/16 = 4/16 + 1/16
     = 1/4 + 1/16

小数第1位 1/2  → 0
小数第2位 1/4  → 1
小数第3位 1/8  → 0
小数第4位 1/16 → 1
```

したがって `0.0101₂` です。

別解として `5₁₀ = 101₂`、`16 = 2⁴` なので、`101.₂` の小数点を左へ4桁動かしても同じ答えになります。

誤答の `0.00101₂` は `5/32`、`0.101₂` は `5/8` です。**小数点の移動量が1桁ずれるだけで値が2倍または半分になる**点を確認しましょう。

</details>

## まとめ（試験直前用）

- 2の補数は負数を表す方法
- 絶対値は「反転して1を足す」
- 2進小数は小数点以下を `1/2、1/4、1/8…` と読む
- 問題文で表現方法を先に確認する
- 分数は2の累乗へ分解すると考えやすい
