## まず結論

キャッシュメモリは、**CPUがよく使うデータや命令を一時的に保存し、主記憶へのアクセス回数を減らす高速なメモリ**です。

基本情報技術者試験では、次の判断軸を覚えておくと選択肢を切りやすくなります。

> **一度読み出した内容を保持し、同じ内容を再び使うときに高速化する。**

キャッシュメモリは、命令を並列に処理する装置でも、命令を実行する装置でもありません。

## 直感的な説明

CPUを作業する人、主記憶を遠くにある資料棚だと考えます。

必要な資料を使うたびに、毎回遠くの棚まで取りに行くと時間がかかります。

そこで、よく使う資料を机の上に置いておきます。

```text
遠くの資料棚 ＝ 主記憶
机の上       ＝ キャッシュメモリ
作業する人   ＝ CPU
```

一度取り出した資料を机の上に置いておけば、次に同じ資料が必要になったとき、すぐに使えます。

キャッシュメモリも同じように、主記憶から読み出したデータや命令の一部を保存しておきます。

## 定義・仕組み

キャッシュメモリは、CPUと主記憶の速度差を埋めるために使われます。

```text
CPU
 ↓ 高速
キャッシュメモリ
 ↓
主記憶
```

一般に、CPUは非常に高速に動作しますが、主記憶へのアクセスには比較的時間がかかります。

CPUが主記憶からデータを読み出すたびに待つと、処理効率が低下します。

そこで、使用したデータや命令をキャッシュメモリにコピーして保持します。

### キャッシュヒット

CPUが必要とする内容がキャッシュメモリにある場合を、**キャッシュヒット**といいます。

```text
CPUがデータを要求
→ キャッシュメモリにある
→ すぐに読み出せる
```

この場合、主記憶にアクセスする必要がないため、高速に処理できます。

### キャッシュミス

必要な内容がキャッシュメモリにない場合を、**キャッシュミス**といいます。

```text
CPUがデータを要求
→ キャッシュメモリにない
→ 主記憶から読み出す
→ キャッシュメモリにも保存する
```

最初のアクセスでは主記憶から読み出しますが、その後に同じ内容を使う場合は、キャッシュヒットになる可能性があります。

### 局所性

キャッシュメモリが効果を発揮する背景には、プログラムの**局所性**があります。

| 種類 | 意味 |
|---|---|
| 時間的局所性 | 一度使ったデータや命令は、近いうちに再び使われやすい |
| 空間的局所性 | ある場所を使うと、その近くの場所も使われやすい |

例えば、ループ処理では同じ命令を繰り返し実行するため、時間的局所性があります。

配列を先頭から順番に読む処理では、近くのデータを続けて使うため、空間的局所性があります。

### SRAMとDRAM

一般に、キャッシュメモリには高速な**SRAM**が使われ、主記憶には大容量化しやすい**DRAM**が使われます。

| 比較 | SRAM | DRAM |
|---|---|---|
| 主な用途 | キャッシュメモリ | 主記憶 |
| 速度 | 高速 | SRAMより低速 |
| 容量 | 小さめ | 大きくしやすい |
| 価格 | 高い | 比較的安い |
| リフレッシュ | 不要 | 必要 |

キャッシュメモリが小容量なのは、高速なSRAMが高価だからです。

このテーマは、基本情報技術者試験の「コンピュータ構成要素」や「メモリ」と関係する内容です。公式の出題範囲やシラバスは、[IPA：基本情報技術者試験](https://www.ipa.go.jp/shiken/kubun/fe.html)から確認できます。

## 科目Aでどう出る？

科目Aでは、キャッシュメモリの役割を説明した選択肢を選ぶ問題が出ます。

正しい説明の中心は、次の内容です。

```text
主記憶から読み出したデータや命令を保持する
同じ内容を再び使うときのアクセスを高速化する
```

### 正しい選択肢の見分け方

次のような表現があれば、キャッシュメモリの説明である可能性が高いです。

- 主記憶から読み出した内容を一時的に保持する
- CPUと主記憶の間に置かれる
- 再アクセスを高速化する
- 主記憶へのアクセス回数を減らす
- ヒット率が高いほど平均アクセス時間が短くなる

### 誤った選択肢の見分け方

次の内容は、キャッシュメモリの役割ではありません。

| 選択肢の内容 | 関係する仕組み |
|---|---|
| 命令を同時に処理する | パイプライン、スーパスカラ、マルチプロセッサ |
| 命令をデコードする | CPUの制御装置 |
| 命令を実行する | CPUの演算装置や実行ユニット |
| 主記憶とキャッシュへ同時に読み出す | キャッシュの基本的な効果ではない |

キャッシュメモリは、並列処理を行うための装置ではありません。

また、命令のデコードや実行をキャッシュメモリ上で行うわけでもありません。

> **キャッシュメモリの正しい説明は、「一度読み出した内容を保持し、後で同じ内容を再利用するときに高速化する」が基本です。**

選択肢の前半が正しくても、後半に「命令を並列に処理する」「キャッシュ上でデコードして実行する」など、別の仕組みが混ざっていれば、その選択肢全体は誤りです。

なお、キャッシュメモリにはデータだけでなく命令も保持されます。重要なのは、命令かデータかではなく、保持した内容を再利用して主記憶へのアクセスを減らすことです。

### 平均アクセス時間

問題によっては、キャッシュメモリを使ったときの平均アクセス時間を計算します。

基本的な考え方は次のとおりです。

```text
平均アクセス時間
＝ ヒットした場合の時間
＋ ミスした場合の時間
```

ヒット率が高いほど、主記憶へアクセスする回数が減るため、平均アクセス時間は短くなります。

ただし、計算式は問題文で示される条件によって変わることがあります。キャッシュと主記憶を直列に調べるのか、別の前提があるのかを確認してから計算します。

## どんな場面で使う？

キャッシュメモリは、CPUの処理速度を生かすために使われます。

例えば、同じ命令を何度も実行するループ処理では、命令がキャッシュメモリに保持されやすくなります。

```text
同じ命令を繰り返す
→ キャッシュヒットしやすい
→ 主記憶へのアクセスが減る
→ 処理が速くなる
```

配列を順番に処理する場合も、近くのデータをまとめて読み込むことでキャッシュが働きやすくなります。

一方、広い範囲のデータへばらばらにアクセスすると、必要なデータがキャッシュに残りにくく、キャッシュミスが増えることがあります。

## よくある誤解・混同

| 誤解 | 正しい理解 |
|---|---|
| キャッシュメモリが計算を実行する | 計算を実行するのはCPU |
| キャッシュメモリが命令をデコードする | デコードするのはCPUの制御装置 |
| キャッシュメモリは並列処理を行う | 並列処理はパイプラインやマルチプロセッサなどの役割 |
| 最初のアクセスから必ず高速になる | 最初は主記憶から読む場合があり、再利用時に効果が出やすい |
| キャッシュメモリは主記憶より大容量 | 高速だが小容量である |
| キャッシュにある内容だけをCPUが使える | キャッシュにない場合は主記憶から読み出す |
| SRAMとDRAMは同じ用途 | SRAMは主にキャッシュ、DRAMは主に主記憶に使われる |

### キャッシュとバッファの違い

キャッシュとバッファは、どちらも一時的にデータを保持しますが、目的が異なります。

```text
キャッシュ
→ 同じデータの再利用を高速化する

バッファ
→ 処理速度や転送単位の違いを調整する
```

試験では、「再利用」「再アクセス」「同じデータ」という表現があればキャッシュを疑います。

## まとめ（試験直前用）

- キャッシュメモリはCPUと主記憶の速度差を埋める
- 主記憶から読み出したデータや命令を一時的に保持する
- 同じ内容を再び使うとき、キャッシュヒットすれば高速に読み出せる
- キャッシュミス時は主記憶から読み出す
- キャッシュは並列処理、命令デコード、命令実行を行う装置ではない
- 選択肢は前半だけでなく、後半まで正しいか確認する
- キャッシュにはデータだけでなく命令も保持される
- キャッシュには主にSRAM、主記憶には主にDRAMが使われる
- **「一度読み出した内容を再利用する」が判断キーワード**
