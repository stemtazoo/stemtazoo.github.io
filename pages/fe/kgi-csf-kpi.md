## まず結論

KGI・CSF・KPIは、**目標から改善活動へ落とし込む流れ**で考えると見分けやすくなります。

| 用語 | 役割 | 判断するときの質問 |
|---|---|---|
| KGI | 最終的に達成したい目標 | 最後に何を達成する？ |
| CSF | 目標達成のカギになる重要要因 | 何がうまくいけば成功する？ |
| KPI | 達成状況を測る指標 | 途中を何で測る？ |

試験では、次の順番を押さえます。

```text
KGI
最終ゴール
↓
CSF
成功のカギ
↓
KPI
達成状況を測る
```

特に注意したいのは、**「数値だからKPI」とは限らない**ことです。KGIも数値目標になることがあります。

## 直感的な説明

たとえば、あるECサイトが「年間売上を20％増やす」という目標を立てたとします。

これは最終的に達成したい結果なので **KGI** です。

そのために、

- 購入する利用者を増やす
- リピーターを増やす

ことが重要だと考えたなら、これらが **CSF** です。

さらに、その進み具合を確認するため、

- 購入率5％以上
- リピート率30％以上

などを測るなら、これらが **KPI** です。

```text
年間売上20％増
→ KGI

購入者・リピーターを増やす
→ CSF

購入率5％、リピート率30％
→ KPI
```

「ゴール → 成功のカギ → 測る数字」と考えると整理できます。

## 定義・仕組み

### KGI

**KGI（Key Goal Indicator）** は、最終的な目標の達成度を表す指標です。

```text
最終的にどうなりたい？
→ KGI
```

売上、利益、コスト削減率など、最終的な成果を数値で示すことがあります。

### CSF

**CSF（Critical Success Factor）** は、目標達成のために特に重要となる成功要因です。

```text
KGIを達成するには
何が重要？
→ CSF
```

CSFは「何を重点的に改善するか」という方向を示します。

### KPI

**KPI（Key Performance Indicator）** は、目標に向かう活動やプロセスの達成状況を測る指標です。

```text
CSFがどのくらい進んでいる？
→ KPIで測る
```

KPIを継続的に確認することで、最終目標に向かって改善が進んでいるかを把握できます。

## 科目Aでどう出る？

科目Aでは、目標設定から改善活動までの図や文章を読み、KGI・CSF・KPIのどれに当たるかを判断する問題に注意します。

### 「数値」という言葉だけでKPIを選ばない

ここが最も重要なひっかけです。

たとえば、

```text
利益を15％増加
```

が最終目標なら **KGI** です。

一方、

```text
成約率10％以上
問い合わせ対応時間30分以内
```

のように、最終目標へ向かうプロセスをモニタリングする数字なら **KPI** と判断します。

```text
× 数値だからKPI

○ 最終ゴールを表す数字
  → KGI

○ 途中の達成状況を測る数字
  → KPI
```

### CSFは「測る数字」ではなく「成功のカギ」

「顧客離脱を減らす」「不良品を減らす」のように、目標達成に重要な要因を示していればCSFを疑います。

```text
何を達成する？
→ KGI

何が重要？
→ CSF

何で測る？
→ KPI
```

この3問に置き換えると判断しやすくなります。

## どんな場面で使う？

KGI・CSF・KPIは、経営目標や業務改善を具体的な活動へ落とし込む場面で使われます。

たとえば品質改善なら、

```text
KGI
年間の品質損失を20％削減
        ↓
CSF
工程内の不良を減らす
        ↓
KPI
工程内不良率1％以下
        ↓
改善活動を実施
        ↓
KPIを確認
        ↓
KGIに近づいているか確認
```

というようにつながります。

単語を別々に暗記するより、**一つの流れとして理解する**ことが重要です。

## よくある誤解・混同

### 誤解1：数値目標ならKPI

違います。

KGIもKPIも数値で表されることがあります。

- 最終的な成果を測る → KGI
- 途中の活動・プロセスを測る → KPI

**数字の形ではなく、目標体系のどこにある数字か**を見ます。

### 誤解2：CSFとKPIは同じ

違います。

```text
CSF
→ 何が重要か

KPI
→ それをどのくらい達成したか
```

たとえば、

```text
納期遅延を減らす
→ CSF

納期遵守率98％以上
→ KPI
```

という関係です。

### 誤解3：KPIが最終ゴール

KPIは途中の状態を確認するための指標です。

KPIを達成していても、必ず最終的なKGIを達成できるとは限りません。KPIは、KGIへ向かっているかを確認するために使います。

### 誤解4：MBOもKGI・CSF・KPIと同じ種類

**MBO（Management by Objectives）** は「目標による管理」という管理手法です。

```text
KGI・CSF・KPI
→ 目標・成功要因・評価指標

MBO
→ 目標を用いて管理する手法
```

選択肢にMBOが混ざっていたら、まず「指標・要因」と「管理手法」の違いを確認します。

## SGとの違い

SGにも [CSFとは｜KGI・KPIとの違いをやさしく整理](/sg/csf/) があります。

SGでは、CSFを中心にKGI・KPI・MBOとの違いや、組織での目標管理まで理解する構成です。

このFE記事では重複を避け、**科目Aで図や選択肢を見たときに、KGI・CSF・KPIを素早く切り分けること**を中心にしています。

## 一次情報で確認する

FEの出題範囲は、IPAの「基本情報技術者試験（レベル2）シラバス」で確認できます。

- [IPA：試験要綱・シラバスについて](https://www.ipa.go.jp/shiken/syllabus/gaiyou.html)

試験では英語の正式名称だけを暗記するより、**目標 → 成功要因 → 測定指標**という関係を理解して選択肢を判断できるようにします。

## まとめ（試験直前用）

- **KGI** → 最終的に何を達成するか
- **CSF** → 目標達成のために何が重要か
- **KPI** → 途中の達成状況を何で測るか

迷ったら、

```text
ゴール → KGI
成功のカギ → CSF
途中を測る → KPI
```

で切り分けます。

そして、**「数値だからKPI」と決めない**ことが重要です。
