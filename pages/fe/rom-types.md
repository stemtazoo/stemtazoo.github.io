## まず結論

ROM系は「出荷後に書き換えられるか」「何で消去するか」でまず分類し、EEPROMとフラッシュメモリは必要に応じて消去単位・書込み単位を分けて見ます。

| 種類 | 出荷後の再書込み | 消去方法 | 消去単位の目安 | 書込み単位の目安 |
|---|---|---|---|---|
| マスクROM | できない | なし | 対象外 | 製造工程で内容を固定 |
| PROM | 1回だけ可能 | なし | 対象外 | 1回だけプログラム（単位は方式による） |
| EPROM | 可能 | 紫外線 | 一般にチップ全体 | 装置の仕様による |
| EEPROM（専用EEPROMの典型） | 可能 | 電気 | バイト単位など | バイト単位など |
| フラッシュメモリ | 可能 | 電気 | ページ／ブロック単位が一般的 | バイト・ワード・ページなど、装置の仕様による |

EEPROMとフラッシュメモリはいずれも電気的に消去・書換えできる不揮発性メモリです。試験では、従来型の専用EEPROMは細かい単位、フラッシュメモリはページやブロック単位で消去するものとして対比されます。実際の消去単位と書込み単位はデバイスによって異なるため、同じものとして扱わないようにします。

基本情報技術者試験では、次の流れを思い出すと選択肢を切りやすくなります。

~~~text
製造時に内容を固定
→ マスクROM

一度だけ書き込む
→ PROM

紫外線で消去
→ EPROM

電気的に消去・書換え
→ EEPROM・フラッシュメモリ

ページ／ブロック単位で消去
→ フラッシュメモリの典型的な見分け方
~~~

> **「出荷後にプログラムを書き換えたい」なら、フラッシュメモリが強い候補です。**

## 直感的な説明

ROM系メモリを「書き直せるメモ帳」にたとえると分かりやすくなります。

~~~text
マスクROM
→ 印刷済みの本
→ 後から内容を変えられない

PROM
→ 1回だけ書けるカード
→ 書いた後は消せない

EPROM
→ 紫外線を当てると消せるメモ帳

EEPROM
→ 電気で消して書き直せるメモ帳

フラッシュメモリ
→ 電気で、まとまった範囲を消して書き直せるメモ帳
~~~

重要なのは、**「ROMだから必ず書換え不可」ではない**ことです。

FEでは、ROM系の中にも書換え可能なものがあると理解しておくと、EEPROMやフラッシュメモリの選択肢を切りやすくなります。

## 定義・仕組み

### マスクROM

マスクROMは、半導体の製造工程で内容を書き込み、その内容を固定するROMです。

~~~text
製造時に内容を決める
↓
製品として完成
↓
後から内容を変えない
~~~

大量生産する機器で、プログラムや固定データを変更する必要がない場合に向いています。

### PROM

PROM（Programmable ROM）は、製造後に利用者側で**一度だけ**書き込めるROMです。

~~~text
未書込み
↓
一度だけ書込み
↓
その後は消去・再書込みできない
~~~

「一度だけ書き込める」が判断の合図です。

### EPROM

EPROM（Erasable Programmable ROM）は、**紫外線を当てて内容を消去し、再び書き込めるROM**です。

~~~text
書込み
↓
紫外線で消去
↓
再書込み
~~~

科目Aでは、**「紫外線」＝ EPROM**と結び付けると判断しやすくなります。

### EEPROM

EEPROM（Electrically Erasable Programmable ROM）は、電気的に消去・書換えできる不揮発性メモリです。

フラッシュメモリも電気的に消去・書換えできるため、広い意味ではEEPROM系のメモリに含めて説明されることがあります。一方、FEの学習では、従来型の専用EEPROMとフラッシュメモリを、消去単位の違いで対比すると整理しやすくなります。

~~~text
専用EEPROMの典型
→ バイトなど細かい単位で消去・書込み

フラッシュメモリの典型
→ ページ／ブロック単位で消去
→ 書込み単位はデバイスによって異なる
~~~

「EEPROMは必ず1バイト、フラッシュは必ず1ブロック」といった普遍的な仕様ではありません。試験上の典型的な区別と、個々の製品仕様を分けて覚えます。

### フラッシュメモリ

フラッシュメモリは、電源を切っても内容を保持する**不揮発性メモリ**で、電気的に消去・書換えできます。

大容量化しやすく、次のような用途で使われます。

- SSD
- USBメモリ
- SDカード
- 組込み機器のプログラム保存
- マイコンのファームウェア保存

フラッシュメモリ単体の特徴やSRAM・DRAMとの違いは、[フラッシュメモリとは？](/fe/flash-memory/)で整理しています。

DRAM・SRAMを含めてメモリ全体を比較したい場合は、[メモリの種類](/fe/memory-types/)を参照してください。

このテーマは、基本情報技術者試験の「コンピュータシステム」や「メモリ」に関係します。公式の出題範囲やシラバスは、[IPA：基本情報技術者試験](https://www.ipa.go.jp/shiken/kubun/fe.html)から確認できます。マイコンの製品例では、[Microchip：Memory Features](https://www.microchip.com/en-us/products/microcontrollers/8-bit-mcus/peripherals/system-flexibility/memory)が、データEEPROMのバイト単位の消去・書込みと、プログラムフラッシュの行単位の変更を説明しています。実際の単位は各デバイスの仕様を確認してください。

## 科目Aでどう出る？

科目Aでは、ROMの種類そのものを聞く問題だけでなく、**組込み機器のプログラムを出荷後に変更できるか**という形でも出ます。

### 判断軸1：製造後に書き換える必要があるか

~~~text
製造時に内容を固定
→ マスクROM

出荷後も内容を更新したい
→ EEPROM・フラッシュメモリ
~~~

マイコンのファームウェアを出荷後に更新したい場合は、フラッシュメモリが適しています。

### 判断軸2：何で消去するか

~~~text
紫外線
→ EPROM

電気
→ EEPROM・フラッシュメモリ
~~~

「消去方法」は、EPROMとEEPROMを分ける強い手掛かりです。

### 判断軸3：一度だけか、何度も書き換えるか

~~~text
一度だけ書込み
→ PROM

繰り返し書換え
→ EPROM・EEPROM・フラッシュメモリ
~~~

「Programmable」という名前だけでPROMを選ばず、**再書込みできるか**まで確認します。

## どんな場面で使う？

### 電源投入直後の起動用プログラム

ROM系の不揮発性メモリは、電源断後も保持しておきたい起動用プログラムの格納先にも使われます。PCのBIOS・UEFIファームウェアには、更新可能なフラッシュメモリを使う構成があります。

起動用途だから必ずマスクROM、という意味ではありません。DRAM・SRAMやHDDとの役割の違い、起動処理の簡略図は、[メモリの種類：電源投入直後のプログラムはどこに置く？](/fe/memory-types/)で整理しています。

### 組込み機器のファームウェア更新

マイコン内部のフラッシュメモリにプログラムを保存しておけば、製品の出荷後でもファームウェアを書き換えられる構成にできます。

~~~text
出荷時のプログラム
↓
不具合修正・機能追加
↓
フラッシュメモリを書換え
↓
新しいプログラムで動作
~~~

機器を分解してROMを交換しなくても更新できるため、保守しやすくなります。

### ISPとフラッシュメモリの違い

ISP（In-System Programming）は、**基板に実装したままプログラムを書き込む方法**です。

~~~text
フラッシュメモリ
→ 書換え可能な記憶媒体

ISP
→ 基板に載せたまま書き込む方法
~~~

つまり、ISPはメモリの種類ではありません。

「出荷後に書き換えられる」という性質を実現する土台としてフラッシュメモリがあり、実際の書込み方法としてISPなどが使われる、と分けて考えます。

## よくある誤解・混同

### ROMはすべて書き換えられない

違います。

~~~text
マスクROM
→ 書換え不可

PROM
→ 一度だけ書込み

EPROM
→ 紫外線で消去して再書込み

EEPROM
→ 電気で消去・再書込み

フラッシュメモリ
→ 電気でまとめて消去・再書込み
~~~

ROM系の中にも、後から書き換えられるものがあります。

### EPROMとEEPROMは同じ

どちらも再書込みできますが、**消去方法**が違います。

~~~text
EPROM
→ 紫外線

EEPROM
→ 電気
~~~

最初のEが同じでも、ここを混同しないようにします。

### EEPROMとフラッシュメモリはどう違う？

両方とも電気的に消去・書換えできる不揮発性メモリです。FEでは、従来型の専用EEPROMとフラッシュメモリを、主に消去単位で区別します。

~~~text
専用EEPROMの典型
→ バイトなど細かい単位で消去・書込み

フラッシュメモリの典型
→ ページ／ブロック単位で消去
→ 書込み単位はデバイス仕様による
~~~

広い分類ではフラッシュをEEPROM系に含める場合もあります。問題文に個別の仕様が示されているときは、その記述を優先します。

### フラッシュメモリなら処理速度が上がる

フラッシュメモリを採用しただけで、CPUの演算性能が上がるわけではありません。

組込み機器の問題では、

> **「出荷後にプログラムを書き換えられる」**

という利点を優先して考えます。

## まとめ（試験直前用）

- 製造時に内容を固定 → **マスクROM**
- 一度だけ書込み → **PROM**
- 紫外線で消去 → **EPROM**
- 電気的に消去・書換え → **EEPROM・フラッシュメモリ**
- ページ／ブロック単位で消去するのが典型 → **フラッシュメモリ**
- 出荷後にファームウェア更新 → **フラッシュメモリ**
- ISPはメモリの種類ではなく、基板に実装したまま書き込む方法

> **ROM系は「再書込みの可否 → 消去方法」を見て、必要なら消去単位も確認する。**
