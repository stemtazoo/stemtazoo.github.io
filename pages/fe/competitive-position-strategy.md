## まず結論

競争地位別戦略とは、企業を市場での立ち位置によって **リーダー・チャレンジャー・ニッチャー・フォロワー** の4つに分け、それぞれに合った戦い方を考える枠組みです。

基本情報技術者試験では、次の4つで切り分けると判断しやすくなります。

```text
市場シェア1位
→ リーダー

上位企業に挑む
→ チャレンジャー

狭い市場に集中する
→ ニッチャー

先行企業に追随する
→ フォロワー
```

特に、**「市場全体のシェアは高くないが、特定分野に経営資源を集中して独自の地位を築く」** ならニッチャーを疑います。

## 直感的な説明

4つの立場を、スポーツのリーグ戦にたとえると分かりやすいです。

```text
リーダー
→ 現在の1位。首位を守る

チャレンジャー
→ 1位を追いかける上位勢

ニッチャー
→ 大会全体では目立たなくても、特定種目では圧倒的に強い

フォロワー
→ 強いチームのやり方を参考にして安定して戦う
```

大切なのは、**強い・弱いだけで分けるのではなく、どこで、誰と、どう戦うか**を見ることです。

## 定義・仕組み

### リーダー

リーダーは、市場で最大のシェアをもつ企業です。

主な目的は、首位の地位を守りながら市場全体を広げることです。

```text
最大シェア
→ リーダー
```

FEでは、**「市場シェア1位」「首位を維持」「市場全体を対象」** といった表現が判断材料になります。

### チャレンジャー

チャレンジャーは、リーダーに次ぐ地位にあり、上位企業からシェアを奪おうとする企業です。

価格、製品、サービス、販売方法などで差別化して、上位を狙います。

```text
上位企業に挑戦
→ チャレンジャー
```

### ニッチャー

ニッチャーは、市場全体で大きなシェアを狙うのではなく、**特定の顧客層・製品・地域・用途などに経営資源を集中する企業**です。

```text
狭い市場
＋
専門特化
＋
独自の地位
→ ニッチャー
```

市場全体では小さくても、対象を絞った市場では強い地位を築けます。

### フォロワー

フォロワーは、リーダーやチャレンジャーの戦略を参考にしながら、市場で安定した地位を維持する企業です。

```text
先行企業を追随
→ フォロワー
```

大きなリスクを取って首位を狙うより、既存の成功例を活用して効率的に競争します。

## 科目Aでどう出る？

科目Aでは、企業の置かれた状況や戦略目標から、4つの競争地位を選ばせる問題が出ます。

| 問題文の表現 | 選びたい地位 |
|---|---|
| 最大シェアを維持したい | リーダー |
| 上位企業からシェアを奪いたい | チャレンジャー |
| 特定の製品・顧客・地域に集中したい | ニッチャー |
| 先行企業の戦略を模倣・追随したい | フォロワー |

試験では、まず次の順番で読みます。

```text
1. 市場全体で何位か
2. 市場を広く狙うか、狭く絞るか
3. 首位を守るのか、挑むのか、追随するのか
```

### ニッチャーを見抜くポイント

次の3つがまとまっていたら、ニッチャーの可能性が高いです。

```text
市場シェアは高くない
＋
特定分野に集中
＋
独自の地位を築く
```

単に「シェアが低い」だけではフォロワーと区別できません。

**狭い市場で強みを作る**という部分まで確認するのがポイントです。

## どんな場面で使う？

競争地位別戦略は、企業が自社の市場での立場を確認し、どのように競争するかを考えるときに使います。

例えば、次のような場面です。

- 業界1位の企業が首位を維持する
- 2位企業が差別化して1位を追う
- 小規模企業が特殊用途の製品に特化する
- 後発企業が先行企業の成功例を参考にする

公式の出題範囲やシラバスは、[IPA：基本情報技術者試験](https://www.ipa.go.jp/shiken/kubun/fe.html) から確認できます。

## よくある誤解・混同

### ニッチャーとチャレンジャー

ここが最も混同しやすいポイントです。

```text
チャレンジャー
→ 大きな市場で上位を狙う

ニッチャー
→ 狭い市場で強い地位を作る
```

どちらも差別化することがありますが、**目指す市場の広さと戦う相手**が違います。

### ニッチャーとフォロワー

```text
ニッチャー
→ 独自の専門領域を作る

フォロワー
→ 先行企業に追随する
```

市場シェアが大きくないという点は共通する場合がありますが、ニッチャーは独自性、フォロワーは追随が中心です。

### リーダーとチャレンジャー

```text
リーダー
→ すでに1位

チャレンジャー
→ 1位を狙う側
```

「シェア拡大」という言葉だけで決めず、現在の地位を確認します。

### ポーターの競争戦略との違い

競争地位別戦略は、**市場での立ち位置**から戦略を考えます。

一方、ポーターの競争戦略は、コスト・差別化・集中など、**どの方法で競争優位を作るか**に注目します。

```text
競争地位別戦略
→ 自社は市場でどの立場か

ポーターの競争戦略
→ どの方法で優位を作るか
```

## まとめ（試験直前用）

- 市場シェア1位 → リーダー
- 上位企業に挑む → チャレンジャー
- 狭い市場に集中して独自の地位を築く → ニッチャー
- 先行企業を模倣・追随する → フォロワー
- **「シェアは高くない＋特定分野へ集中＋独自地位」ならニッチャー**
- チャレンジャーは「広い市場で上位を狙う」、ニッチャーは「狭い市場で強くなる」と切り分ける
