## まず結論

フィードバック制御とフィードフォワード制御は、**「いつ修正するか」**で切り分けると分かりやすくなります。

```text
フィードバック制御
結果を測る → 目標との差を見る → 後から修正

フィードフォワード制御
外乱を検知・予測 → 影響が出る前に先回りして修正
```

基本情報技術者試験では、特に次の違いが重要です。

> **外乱そのものを見るのか、外乱が出力に与えた影響を見るのか。**

フィードバックは、室温が実際に変化したことを測定してから修正します。

フィードフォワードは、「このままでは室温が上がる」と考えて、影響が現れる前に修正します。

## 定義・仕組み

### フィードバック制御

フィードバック制御では、制御対象の**出力を測定**し、目標値との差に応じて操作量を調整します。

```text
目標値
  ↓
制御 → 制御対象 → 出力
  ↑                │
  └── 測定・比較 ──┘
```

重要なのは、出力を戻して比較することです。

```text
目標値 − 測定値
       ↓
     差を小さくする
```

そのため、外乱が加わった場合も、まず出力にその影響が現れ、それを測定してから修正することになります。

### フィードフォワード制御

フィードフォワード制御では、出力への影響を待つのではなく、**外乱などを検知・予測して先回りして操作**します。

```text
外乱を検知・予測
       ↓
    補正を決める
       ↓
制御対象への影響を抑える
```

ただし、外乱とその影響を適切に把握できなければ、狙った補正にならないことがあります。そのため実際の制御では、フィードバックと組み合わせることもあります。

## 科目Aでどう出る？

FEでは、二つの制御方式を文章から判別させる問題が考えられます。

| 問題文の表現 | 考える方式 |
|---|---|
| 出力を測定する | フィードバック |
| 目標値と測定値を比較する | フィードバック |
| 差・偏差を小さくする | フィードバック |
| 外乱の影響が現れてから修正する | フィードバック |
| 外乱そのものを検知する | フィードフォワード |
| 外乱を予測する | フィードフォワード |
| 影響が出る前に補正する | フィードフォワード |

### 「外乱を検知」という言葉だけで判断しない

ここが特に引っかかりやすいところです。

```text
外乱による「影響」を検知
→ 出力が変化してから分かる
→ フィードバック

「外乱」を直接検知・予測
→ 出力が変化する前に対応
→ フィードフォワード
```

「検知」という同じ言葉が使われていても、**何を検知しているのか**まで確認します。

## どんな場面で使う？

### フィードバック制御の例

エアコンなら、現在の室温を温度センサで測定し、設定温度との差に応じて冷暖房を調整します。

```text
設定温度 25℃
現在温度 27℃
     ↓
2℃高い
     ↓
冷房を強める
```

### フィードフォワード制御の例

室温が上がってからではなく、日射量など室温を変化させる外乱を検知して、あらかじめ冷房能力を調整する考え方です。

```text
日射が強くなる
     ↓
室温が上がりそう
     ↓
先に冷房を調整
```

このように、同じシステムでも二つの方式を組み合わせることがあります。

## よくある誤解・混同

### ① フィードバックは外乱そのものを検知する？

- ❌ 外乱を直接検知して先回りする
- ⭕ **出力を測定し、目標との差を見て修正する**

外乱が原因でも、フィードバックが直接見ているのは基本的に制御結果です。

### ② 「予測」が出たらフィードバック？

逆です。

```text
結果を測定してから修正
→ フィードバック

外乱を予測して先に修正
→ フィードフォワード
```

### ③ フィードフォワードは外乱を増幅する方式？

そう覚えるのは適切ではありません。

フィードフォワード制御も、外乱による望ましくない影響を**先回りして抑える**ための制御です。

ただし、外乱と出力の関係を誤って見積もると、補正が適切に働かないことがあります。

### ④ 「検知」があればフィードバック？

「検知」の対象を確認します。

```text
出力・結果・外乱の影響を検知
→ フィードバック

外乱そのものを検知
→ フィードフォワード
```

## 確認問題（基本情報技術者試験対策）

室温を一定に保つ制御について、フィードバック制御の説明として最も適切なものはどれか。

- ア. 室温を測定し、設定温度との差に応じて冷房能力を調整する
- イ. 翌日の日射量を予測し、あらかじめ冷房能力を調整する
- ウ. 窓から入る日射を検知し、室温が変化する前に冷房能力を調整する
- エ. 外気温の変化を予測するだけで、室温は測定しない

## まとめ（試験直前用）

- フィードバック＝**結果を測ってから直す**
- フィードフォワード＝**外乱を見て先回りする**
- 目標値と測定値の差 → フィードバック
- 外乱の検知・予測 → フィードフォワード
- 「検知」という単語だけでなく、**何を検知しているか**を見る

試験では、

> **結果を見る＝フィードバック、原因を見て先回り＝フィードフォワード**

まで圧縮して覚えると、選択肢を切りやすくなります。
