## まず結論

クリッピング（clipping）とは、**表示する範囲の外側にある部分を描画対象から除外し、見える範囲だけを残す処理**です。

FE試験では、次の言葉が出たらクリッピングを疑います。

```text
表示範囲・ウィンドウを決める
        ↓
範囲の外側を除外する
        ↓
見える部分だけを残す
        ↓
クリッピング
```

細かな計算方法より、**「範囲外を切る」処理**だと判断できることが重要です。

## 直感的な説明

大きな絵の上に、小さな窓を置くイメージです。

```text
元の図形
──────────────
   △△△△△△
──────────────

表示する窓
    ┌─────┐
────│ △△△ │────
    └─────┘

窓の外側は描画しない
→ クリッピング
```

図形そのものを「きれいにする」処理ではありません。

**最終的に見えない部分を描画対象から外す**ことで、必要な範囲だけを扱います。

## 定義・仕組み

3次元グラフィックスでは、物体を画面に表示するまでに複数の処理を行います。

クリッピングでは、視点から見える領域（ビュー・ボリューム、クリップ領域）と図形を比較し、領域の外側にある部分を除外します。

図形が境界をまたぐ場合は、境界で切り分けて、内側にある部分を残します。

OpenGLの仕様でも、プリミティブは**clip volume（クリップ領域）に対してクリッピングされる**ものとして定義されています。

試験では、次の違いを押さえておけば十分です。

| 処理 | 何をする？ | 試験での合図 |
|---|---|---|
| クリッピング | 表示範囲の外を除外 | 範囲外、ウィンドウ、見える部分 |
| レンダリング | 最終的な画像を生成 | 描画、映像化 |
| アンチエイリアシング | 輪郭のギザギザを滑らかにする | 階段状、ギザギザ |
| シェーディング | 明暗を付けて立体感を出す | 光源、陰影、立体感 |

## 科目Aでどう出る？

科目Aでは、CG処理の説明から技術名を選ぶ問題が出ます。

このタイプは、**「何を変える処理か」**に注目します。

```text
表示範囲の外を切る
→ クリッピング

最終的な画像を作る
→ レンダリング

輪郭のギザギザを滑らかにする
→ アンチエイリアシング

光・陰影で立体感を出す
→ シェーディング
```

### 「切る」という言葉だけで決めない

クリッピングの本質は、単に図形を切断することではありません。

**表示する領域との関係で、範囲外を描画対象から除外する**ところがポイントです。

問題文に「ウィンドウの外側を除去」「表示範囲内だけを取り出す」などがあれば、クリッピングと判断しやすくなります。

## どんな場面で使う？

3DCGでは、シーン全体に多数の物体や図形があっても、そのすべてが画面に見えるとは限りません。

クリッピングによって、表示領域の外側にある部分を描画対象から外し、後続の処理で扱う範囲を整理できます。

FEでは実装方法を深掘りするより、

**「見える範囲を決め、外側を除外する」**

という役割を理解しておきましょう。

## よくある誤解・混同

### レンダリングと混同する

レンダリングは、物体などのデータから最終的に表示する画像を生成する処理です。

```text
範囲外を除外
→ クリッピング

最終画像を作る
→ レンダリング
```

### アンチエイリアシングと混同する

アンチエイリアシングは、ピクセルの制約などで生じる輪郭のギザギザを目立たなくする処理です。

詳しくは[アンチエイリアシングとは？](/fe/anti-aliasing/)で整理しています。

```text
表示範囲
→ クリッピング

輪郭の滑らかさ
→ アンチエイリアシング
```

### シェーディングと混同する

シェーディングは、光源などを基に物体表面の明暗を表現する処理です。

```text
見える・見えない範囲
→ クリッピング

明るい・暗い
→ シェーディング
```

## 一次情報で確認する

試験範囲については、IPAの「基本情報技術者試験（レベル2）シラバス Ver.9.2」を学習範囲の基準として確認できます。

- [IPA｜試験要綱・シラバスについて](https://www.ipa.go.jp/shiken/syllabus/gaiyou.html)
- [Khronos Group｜OpenGL Graphics System Specification](https://registry.khronos.org/OpenGL/specs/gl/glspec20.pdf)

OpenGL仕様の「Clipping」では、図形（primitive）をクリップ領域に対して処理する仕組みが規定されています。

## まとめ（試験直前用）

- **表示範囲の外側を除外する → クリッピング**
- 最終的な画像を作る → レンダリング
- 輪郭のギザギザを滑らかにする → アンチエイリアシング
- 光・陰影で立体感を出す → シェーディング
- 「何を変える処理か」で選択肢を切る

試験直前は、次の4つをセットで確認します。

```text
範囲外 → クリッピング
画像化 → レンダリング
ギザギザ → アンチエイリアシング
陰影 → シェーディング
```
