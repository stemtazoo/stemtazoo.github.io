## まず結論

**スマートメーターは、電気の使用量を計測し、通信機能で計測データを送る電力量計**です。自動検針や電気使用状況の見える化に役立ち、計測情報を需要制御に活用できます。

判断の軸は、**「測る・データを送る」がスマートメーター、「家庭内を管理・制御する」がHEMS、「停電時に給電する」がUPS**です。

## 直感的な説明

スマートメーターは、電気の使用状況を報告する「通信できる計量器」と考えると分かりやすくなります。

家庭で照明やエアコンを使うと、メーターが使用量を計測します。その情報を電力会社へ送れば、人が現地で数字を読み取る検針を自動化できます。

また、対応するHEMSへ情報を送ると、家庭側で使用状況を把握し、機器の設定や運転時間を見直す材料になります。**測定結果を得ることと、家電を制御することは別の役割**です。

## 定義・仕組み

### 計測した情報を通信で届ける

スマートメーターの中心となる機能は、電力量の計測と計測データの通信です。

| 活用 | 計測データが役立つ理由 |
|---|---|
| 自動検針 | 電力会社が遠隔で使用量を取得できる |
| 見える化 | 時間帯ごとの使用状況を把握する材料になる |
| 需要制御 | 使用状況に応じて消費を抑えたり、運転時間を変えたりする判断を支える |

東京電力パワーグリッドの[電力メーターの説明](https://www.tepco.co.jp/pg/consignment/for-general/basic-knowledge/smart-mater.html)では、自動検針やHEMSを通じた見える化、30分ごとの電気使用量の計測が紹介されています。

「電力」はその時点の電気を使う勢いで、単位はWやkWです。「電力量」は一定時間に使った電気の量で、単位はWhやkWhです。詳しくは[電力と電力量の違い](/fe/electric-power-energy-wh/)で確認できます。

スマートメーターからHEMSへデータを送る経路は、Bルートと呼ばれます。[東京電力パワーグリッドのBルートサービス](https://www.tepco.co.jp/pg/consignment/liberalization/smartmeter-broute.html)では、30分ごとの使用量や現在の電流値などを把握できると説明されています。

ただし、利用できるデータや更新間隔、表示方法は機器やサービスによります。スマートメーターを設置しただけで、すべての家電が自動制御されたり、どのアプリにも瞬時に使用状況が表示されたりするわけではありません。

## 科目Aでどう出る？

スマートメーターの機能や導入目的を、似たエネルギー関連技術と切り分けます。

| 説明の手掛かり | 判断する用語・役割 |
|---|---|
| 電気使用量を計測し、通信で送信する | スマートメーター |
| 遠隔で使用量を取得し、検針作業を効率化する | スマートメーターの活用 |
| 家庭内の使用状況を管理し、対応家電を制御する | HEMS |
| 電力網全体の需給をICTで調整する | スマートグリッド |
| 停電時にバッテリーから一定時間給電する | UPSなどの電源設備 |

「通信機能がある」「高機能である」という説明から、給電や発電までできると考えないようにします。**何を計測・管理・供給しているのか**を見ると、選択肢を判断しやすくなります。

計測情報を使ってピーク電力を抑えることは、スマートメーターを活用する目的として適切です。ただし、実際の調整は利用者の行動や、HEMS・対応設備などとの連携によって行います。

## どんな場面で使う？

例えば、夕方にエアコン、調理器具、給湯設備を同時に使い、消費電力が大きくなる家庭を考えます。

使用状況が分かれば、急ぐ必要のない機器の運転を別の時間へ移すなど、ピーク時の電力需要を抑える判断ができます。対応する機器では、HEMSなどを通じた制御にも活用できます。

**ピークを抑えることと、合計の電力量を減らすことは同じではありません。** 運転時間をずらすだけなら、消費の集中は避けられても、1日で使う電力量が減るとは限りません。

家庭内の連携は[HEMSの役割](/fe/hems/)で、電力網全体の需給調整は[スマートグリッドの仕組み](/fe/smart-grid/)で詳しく整理しています。

## よくある誤解・混同

| 誤解 | 正しい理解 |
|---|---|
| スマートメーターは停電時に家電へ給電する | 計測・通信が中心。停電時の給電にはUPSや蓄電設備などが必要 |
| スマートメーター単体で家電を最適制御する | 計測情報を使い、HEMSや対応機器などと連携して管理・制御する |
| 通信できれば、すべての表示が常にリアルタイム | データの種類・更新間隔・表示は機器やサービスによる |
| 見える化すれば自動的に節電できる | 状況を把握し、設定や使い方を変えるための材料になる |
| スマートメーターとスマートグリッドは同じ | 前者は計測・通信する装置、後者は電力網全体の仕組み |

スマートメーターに通信や内部動作用の電源があっても、それは家庭の機器へ電力を供給し続ける機能とは別です。停電時の電源確保は[UPSの役割](/fe/ups/)で確認できます。

## まとめ（試験直前用）

- スマートメーターは、電気使用量を計測・通信する電力量計。
- 自動検針や、HEMSを通じた使用状況の見える化に役立つ。
- 計測情報を需要制御に活用できるが、家庭内の制御には連携する仕組みが必要。
- HEMSは家庭内の管理・制御、スマートグリッドは電力網全体の需給調整。
- 停電時の給電は、スマートメーターの役割ではなくUPSなどが担う。
