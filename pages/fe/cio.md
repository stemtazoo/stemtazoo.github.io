## まず結論

**CIO（Chief Information Officer：最高情報責任者）**は、企業の情報や情報システムに関する戦略を統括する役職です。

基本情報技術者試験では、役職名を丸暗記するより、**何を統括する人か**で見分けるのがポイントです。

```text
経営全体
→ CEO

財務
→ CFO

技術・研究開発
→ CTO

情報・情報システム戦略
→ CIO
```

CIOなら、まず **I = Information** に注目します。

## 直感的な説明

会社の最高責任者を、担当分野ごとに分けて考えてみます。

| 役職 | 英語 | 主な担当 |
|---|---|---|
| CEO | Chief Executive Officer | 経営全体 |
| CFO | Chief Financial Officer | 財務 |
| CTO | Chief Technology Officer | 技術・研究開発 |
| CIO | Chief Information Officer | 情報・情報システム |

英語の真ん中の単語を見ると、役割を思い出しやすくなります。

```text
Executive
→ 経営

Financial
→ 財務

Technology
→ 技術

Information
→ 情報
```

## 定義・仕組み

CIOは、経営戦略と整合させながら、情報や情報システムをどのように活用するかを考え、その戦略を統括します。

つまり、単に情報システムを管理するだけではなく、**経営目標の実現にITをどう生かすか**という視点を持つ役職です。

関連する考え方は、[情報戦略とは？経営計画との整合性と計画の上下関係](/fe/information-strategy/)で整理しています。

### CEO

CEOは、会社全体の経営や業務執行を統括します。

キーワードは**経営全体**です。

### CFO

CFOは、資金調達や財務報告など、財務面を統括します。

キーワードは**資金・財務**です。

### CTO

CTOは、企業の技術戦略や研究開発などを統括します。

キーワードは**技術・研究開発**です。

### CIO

CIOは、情報管理や情報システム戦略などを統括します。

キーワードは**情報・IT・情報システム戦略**です。

## 科目Aでどう出る？

科目Aでは、役職名と担当領域の組合せを選ばせる問題が考えられます。

選択肢に出てくる言葉から担当領域を判断します。

| 選択肢のキーワード | 判断 |
|---|---|
| 経営戦略、業務執行、経営全体 | CEO |
| 資金調達、財務報告、財務戦略 | CFO |
| 技術戦略、研究開発 | CTO |
| 情報管理、情報システム、情報戦略 | CIO |

### 試験中の判断手順

```text
1. 何の「最高責任者」かを見る
2. 経営・財務・技術・情報に分類する
3. 英語の真ん中の単語と対応させる
```

特にCIOを問われたら、**Informationに対応する説明を探す**と素早く切れます。

## どんな場面で使う？

CIOは、企業が情報やITを経営に活用するときに重要な役割を担います。

例えば、全社的な情報システムの方針を決めたり、IT投資の方向性を経営戦略と合わせたりする場面です。

ここで重要なのは、CIOの仕事を「パソコンやシステムの管理担当」とだけ考えないことです。

```text
システムを管理するだけ
→ CIOの説明として狭すぎる

経営戦略に合わせて情報・IT戦略を統括する
→ CIO
```

## よくある誤解・混同

### CIOとCTOは同じ？

同じではありません。

どちらもITや技術に関係するため混同しやすいですが、試験では担当領域を見ます。

```text
CIO
→ Information
→ 情報・情報システム
→ ITを経営にどう生かすか

CTO
→ Technology
→ 技術・研究開発
→ 技術をどう伸ばすか
```

「IT」という言葉があるだけでCIOと決めず、**情報戦略なのか、技術・研究開発なのか**を確認します。

### CIOは情報システム部門だけを見る？

そうとは限りません。

CIOでは、経営戦略との整合や全社的な情報活用という視点が重要です。

### CEOとCIOを混同しない

CEOは経営全体、CIOは情報・情報システムの領域を担当します。

```text
会社全体の経営
→ CEO

経営を支える情報・IT戦略
→ CIO
```

## 一次情報で確認する

試験での用語の位置付けは、IPAの基本情報技術者試験シラバス・出題範囲で確認できます。

- [IPA：基本情報技術者試験](https://www.ipa.go.jp/shiken/kubun/fe.html)
- [IPA：試験要綱・シラバス](https://www.ipa.go.jp/shiken/syllabus/gaiyou.html)

試験対策では、役職の細かな組織上の違いより、**担当領域から役職を切り分けること**を優先します。

## まとめ（試験直前用）

- CEO → 経営全体
- CFO → 財務
- CTO → 技術・研究開発
- CIO → 情報・情報システム戦略
- CIOとCTOは「情報」か「技術・研究開発」かで切り分ける
