## まず結論

メモリの種類は、まず **電源を切ると消えるか**、次に **書き換えられるか**、最後に **どこで使われるか** を見ると切り分けやすくなります。

| メモリ | 電源OFF | 書換え | 主な用途 |
|---|---|---|---|
| DRAM | 消える | 可能 | 主記憶 |
| SRAM | 消える | 可能 | キャッシュメモリ |
| フラッシュメモリ | 残る | 可能 | SDカード、USBメモリ、SSD |
| マスクROM | 残る | 不可 | 内容を固定した機器 |

画像や音楽の保存媒体を問われたら、**不揮発性で書換え可能なフラッシュメモリ**を選びます。

電源投入直後の起動用プログラムの格納先を問われたら、**ROM系の不揮発性メモリ**を考えます。起動用プログラムは、電源を切った後も残り、OSがまだ動いていない段階から利用できる必要があります。

このページは、**DRAM・SRAM・フラッシュメモリ・ROMを比較するメモリ種類の総論**です。CPUと主記憶の間に置くキャッシュの仕組みや書込み方式は、[キャッシュメモリとは？](/fe/cache-memory/) で整理しています。 一方、固定区画・可変区画・ページングなど「主記憶をどう割り当てて管理するか」は、[主記憶管理方式の違い](/fe/memory-management-methods/) で確認できます。

## 直感的な説明

最初に、揮発性と不揮発性へ分けます。

```text
電源を切ると消える
→ DRAM、SRAM

電源を切っても残る
→ フラッシュメモリ、マスクROM
```

次に、不揮発性メモリを「書き換えられるか」で分けます。

```text
後から書き換えられる
→ フラッシュメモリ

製造時に内容を固定する
→ マスクROM
```

したがって、写真や音楽を追加・削除しながら保存する用途には、フラッシュメモリが向いています。

## 定義・仕組み

### DRAM

DRAMは、電源を切ると内容が消える揮発性メモリです。リフレッシュが必要ですが、高集積化しやすく、比較的安価なので主記憶に使われます。

詳しくは、[DRAMとは？リフレッシュが必要な主記憶の仕組み]({{ '/fe/dram/' | relative_url }})で整理しています。

### SRAM

SRAMも揮発性メモリですが、リフレッシュは不要です。DRAMより高速な一方、高価で大容量化しにくいため、主にキャッシュメモリに使われます。

詳しくは、[SRAMとは？リフレッシュ不要で高速なキャッシュメモリ]({{ '/fe/sram/' | relative_url }})で確認できます。

### フラッシュメモリ

フラッシュメモリは、不揮発性でありながら電気的に消去・書換えできる半導体メモリです。

代表的な用途は次のとおりです。

- SDカード
- USBメモリ
- SSD
- デジタルカメラ
- スマートフォン

詳しくは、[フラッシュメモリとは？EEPROM・SRAM・DRAMとの違い]({{ '/fe/flash-memory/' | relative_url }})で整理しています。SDカードのSD・SDHC・SDXC・SDUCの容量規格は、[SD・SDHC・SDXC・SDUCの違い](/fe/sd-sdhc-sdxc-sduc/)で確認できます。

### マスクROM

マスクROMは、製造工程で内容を書き込む不揮発性メモリです。

```text
電源を切っても残る
＋
後から内容を書き換えられない
→ マスクROM
```

大量生産する機器で、内容を変更しないプログラムや固定データを保存する用途に向いています。

このテーマは、基本情報技術者試験の「コンピュータシステム」や「メモリ」に関係します。公式の出題範囲は、[IPA：基本情報技術者試験](https://www.ipa.go.jp/shiken/kubun/fe.html)から確認できます。

### 電源投入直後のプログラムはどこに置く？

コンピュータは、OSが動く前から何らかのプログラムを実行し、主記憶や装置を使える状態にする必要があります。

この起動の入口を担うプログラムを、ROM系の不揮発性メモリに保持しておきます。バッテリバックアップをしないDRAM・SRAMでは、電源断で内容が失われるため、次の電源投入時に起動用プログラムが残っていません。

**不揮発性なら何でも同じ、というわけでもありません。** HDDも内容を保持しますが、HDDへアクセスしてプログラムを読み込むための初期処理が先に必要です。試験では、最初の起動処理をROM系、後から読み込むOSなどの保存先をHDD・SSDとして区別します。

ファームウェアは、機器の初期化や制御を担うソフトウェアです。PCではBIOS・UEFIファームウェアが代表例で、更新可能なフラッシュメモリに保存する構成があります。**起動に使うから必ず書換え不可のマスクROM、という意味ではありません。**

過去問では、初期のプログラム読込みを担うプログラムをIPL（Initial Program Loader）と呼ぶ説明もあります。試験の簡略化された起動モデルと、具体的なPCの複数段階の起動処理を分けて理解します。

Intelの[Microcode Update Guidance](https://www.intel.com/content/www/us/en/developer/articles/technical/software-security-guidance/best-practices/microcode-update-guidance.html)は、BIOSのSPIフラッシュ、リセット時のファームウェア実行、DRAMが利用可能になる前の処理を説明しています。これは具体的な実装例であり、すべての機器の起動手順を同一にするものではありません。

ROM系の書換え可否は[ROMの種類](/fe/rom-types/)、起動プログラムの信頼性を検証する仕組みは[セキュアブート](/fe/secure-boot/)で確認できます。

## 科目Aでどう出る？

科目Aでは、用途や特徴から適切なメモリを選ぶ問題が出ます。

| 問題文の表現 | 選びたい用語 |
|---|---|
| 主記憶、リフレッシュが必要、大容量・安価 | DRAM |
| キャッシュ、高速、リフレッシュ不要 | SRAM |
| 電源OFFでも残る、電気的に書換え可能 | フラッシュメモリ |
| 製造時に内容を固定、後から書換え不可 | マスクROM |
| 電源投入時、最初に実行するプログラムの格納先 | ROM系（選択肢がROMならROM） |

判断手順は次のとおりです。

```text
1. 電源を切っても残る必要があるか
2. 後から書き換える必要があるか
3. 主記憶・キャッシュ・保存媒体のどれか
```

例えば、デジタルカメラの画像を保存する場合は、電源を切っても残り、撮影のたびに書き換えられる必要があります。

```text
不揮発性
＋
書換え可能
→ フラッシュメモリ
```

### 「バッテリバックアップなし」という条件

バッテリバックアップは、通常の電源が切れても、別の電源からメモリへ電力を供給して内容を保持する方法です。

問題に「主記憶のバッテリバックアップはしない」とあれば、DRAM・SRAMに以前の内容が残る前提では考えません。SRAMのリフレッシュ不要という特徴も、電源供給中の話です。

| 判断する条件 | 考え方 |
|---|---|
| 電源断後にもプログラムが必要 | 不揮発性の格納先を考える |
| 最初の起動処理を始める | ROM系に保持された起動用プログラムを考える |
| HDD・SSDのプログラムを読み込む | そのための初期処理が先に必要 |
| SRAMはリフレッシュ不要 | 電源断でも保持するという意味ではない |

## どんな場面で使う？

問題文では、メモリの種類を直接選ぶ問題よりも、システム構成や処理の説明を読むときに役立ちます。

```text
実行中のプログラムやデータ
→ 主記憶（DRAM）

CPUが頻繁に使うデータ
→ キャッシュ（SRAM）

電源断後も残すデータ
→ フラッシュメモリなど
```

「一時的に使うデータ」と「保存し続けるデータ」を分けて考えると判断しやすくなります。

## よくある誤解・混同

### DRAMは大容量なので保存媒体に向く

DRAMは大容量にしやすいですが、電源を切ると内容が消えます。

```text
大容量
≠
長期保存できる
```

### SRAMは高速なので主記憶に使う

SRAMは高速ですが、高価で大容量化しにくいため、主にキャッシュメモリに使われます。

### ROMはすべて書き換えられない

ROM系には複数種類があります。

| 種類 | 書換え方法 |
|---|---|
| マスクROM | 製造後は書換え不可 |
| PROM | 一度だけ書込み可能 |
| EPROM | 紫外線で消去 |
| EEPROM | 電気的に消去・書換え |
| フラッシュメモリ | 電気的に消去・書換え（消去単位はページ／ブロックが典型） |

ROM系の再書込み可否、消去方法、消去・書込み単位を詳しく比較したい場合は、[ROMの種類とは？](/fe/rom-types/)を参照してください。

### SRAMの「Static」は不揮発性という意味

誤りです。SRAMも電源を切ると内容が消えます。

「Static」は、電源供給中にリフレッシュが不要という意味です。

### HDDは書換え可能だから起動に使えない？

HDD・SSDは、OSやブートローダなどの保存先として起動に使われます。ただし、それらへアクセスする初期処理より先に、起動の入口を担うプログラムが必要です。

また、フラッシュメモリも書換え可能ですが、起動用ファームウェアを保存できます。**書換え可否だけではなく、起動のどの段階で使うか**を見ます。

### プログラムの保存先と実行場所は同じ？

同じとは限りません。HDD・SSDに保存されたOSは、一般に主記憶へ読み込んで実行します。起動用ファームウェアも、機器によって直接読み出して実行したり、初期化後にRAMへ展開したりします。

「電源断後も残す場所」と「実行時に使う場所」を分けて考えます。

## まとめ（試験直前用）

- 主記憶・リフレッシュ必要ならDRAM、キャッシュ・高速・リフレッシュ不要ならSRAM
- 不揮発性で書換え可能ならフラッシュメモリ
- 不揮発性で製造時に内容を固定するならマスクROM
- 電源投入直後の起動用プログラムの格納先ならROM系。更新可能なフラッシュも使われる
- 不揮発性だけで選ばず、用途や起動の段階を見る。保存先と実行場所も区別する
