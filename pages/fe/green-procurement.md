## まず結論

グリーン調達とは、**製品やサービスを調達するときに、価格・品質だけでなく、環境への負荷や供給者の環境への取組も考慮して選ぶこと**です。

基本情報技術者試験では、まず次の判断を使います。

```text
環境に配慮
+
購入・調達
↓
グリーン調達
```

さらに、似た用語が並んだら**何をしているか**を見ます。

```text
買う・調達する
→ グリーン調達

投資する
→ グリーン投資

認定・表示する
→ 環境ラベル

再エネの環境価値を証書化する
→ グリーン電力証書
```

「グリーン」という名前だけではなく、**行為を表す動詞で切り分ける**のがポイントです。

## 直感的な説明

グリーン調達は、会社が部品や設備、サービスを仕入れるときに、**商品だけでなく取引先も見る**イメージです。

例えば、同じ性能・価格帯の部品が二つあるとします。

```text
A社の部品
・省エネルギーで使える
・A社自身も環境負荷低減に取り組んでいる

B社の部品
・性能は同程度
・環境への取組は確認できない
```

このとき、製品そのものの環境性能だけでなく、供給者の環境への取組も含めて調達先を選ぶのが、グリーン調達の考え方です。

つまり、見る範囲を広げると次のようになります。

```text
製品・サービスを見る
        ↓
供給者の取組も見る
        ↓
環境面を含めて調達先を選ぶ
```

## 定義・仕組み

グリーン調達では、調達時の判断基準に環境面を加えます。

主な確認対象は、次のように整理できます。

| 見る対象 | 確認する例 |
|---|---|
| 製品・サービス | 省エネルギー、再生材料、廃棄時の環境負荷 |
| 供給者 | 環境方針、環境負荷低減への取組 |
| 調達条件 | 環境基準を満たしているか |
| 情報 | 環境ラベルや公表情報など、判断材料があるか |

ポイントは、単に「環境に良さそうな商品を買う」だけで終わらないことです。

```text
価格・品質・納期
＋
製品の環境負荷
＋
供給者の環境への取組
→ 調達先を判断
```

IPAの基本情報技術者試験シラバス Ver.9.2 では、ストラテジ系の「システム企画」→「調達計画・実施」→「調達リスク分析」の中で、**CSR調達、グリーン調達などの観点からリスクを分析・評価し、対策を立てること**が示されています。

公式の出題範囲は、[IPA：基本情報技術者試験 シラバス Ver.9.2](https://www.ipa.go.jp/shiken/syllabus/omgdg50000005kpe-att/syllabus_fe_ver9_2.pdf)で確認できます。

また、環境省はグリーン購入を、製品やサービスを購入するときに必要性を考え、環境への負荷ができるだけ少ないものを選ぶこととして説明しています。

グリーン購入法については、[環境省：グリーン購入について](https://www.env.go.jp/policy/hozen/green/g-law/)で確認できます。

## 科目Aでどう出る？

科目Aでは、環境に関する似た用語を選択肢から切り分ける問題で狙われます。

まず、問題文の**動作**に注目します。

| 問題文の内容 | 選ぶ用語 |
|---|---|
| 環境負荷の小さい製品・サービスを優先して購入・調達する | グリーン調達 |
| 環境保全に関係する事業などへ資金を投じる | グリーン投資 |
| 第三者が環境配慮製品を認定・表示する | 環境ラベル |
| 再生可能エネルギーの環境価値を証書として扱う | グリーン電力証書 |

### 判断の順番

迷ったら、次の順番で読みます。

1. **何をしているか**：購入・投資・認定・証書化のどれか
2. **何を対象にしているか**：製品、資金、環境性能、再エネなど
3. **誰を評価しているか**：製品だけか、供給者まで含むか

特に、

```text
購入・調達
+
環境負荷が小さい
+
環境保全に取り組む事業者
```

がまとまって出てきたら、グリーン調達を第一候補にします。

### 「環境」という言葉だけでは決めない

環境関連の選択肢では、どれにも「環境」「グリーン」「環境保全」といった言葉が入ることがあります。

そのため、

> **環境という名詞ではなく、その後に何をしているかを見る**

ことが大切です。

```text
買う
→ 調達

資金を出す
→ 投資

認定する
→ ラベル

価値を証明する
→ 証書
```

## どんな場面で使う？

グリーン調達は、企業や組織が継続的に製品・部品・設備・サービスを調達する場面で使われます。

例えば、次のような場面です。

- 環境負荷の小さい事務用品を選ぶ
- 省エネルギー性能の高い設備を調達する
- 再生材料を使った部品を優先する
- 供給者の環境方針や環境への取組を確認する
- 調達基準に環境面の条件を加える
- サプライチェーン全体の環境負荷を下げる

FEでは、実務の細かな運用方法よりも、**「調達時に環境面を評価する考え方」**を押さえることが重要です。

## よくある誤解・混同

### グリーン調達とグリーン購入

最も迷いやすい組合せです。

```text
環境負荷の少ない製品・サービスを選んで買う
→ グリーン購入

製品・サービスに加えて、
供給者の環境への取組も含めて調達を考える
→ グリーン調達
```

ただし、実務では両者を近い意味で使う場合もあります。

そのためFEでは、名称だけを暗記するよりも、**問題文がどこまで評価対象にしているか**を見る方が安全です。

グリーン購入については、[グリーン購入とは？](/fe/green-purchasing/)も参照してください。

### グリーン調達とグリーン投資

どちらも環境保全に関係しますが、行動が違います。

```text
環境に配慮した製品・サービスを買う
→ グリーン調達

環境保全に関係する活動へ資金を投じる
→ グリーン投資
```

試験では、**購入か投資か**で切り分けます。

### グリーン調達と環境ラベル

環境ラベルは、製品やサービスの環境情報を示し、購入・調達時の判断材料にするものです。

```text
環境情報を示す・認定する
→ 環境ラベル

その情報も使いながら調達先を選ぶ
→ グリーン調達
```

「第三者が基準に基づいて認定する」という説明なら、購入・調達そのものではなく、認証制度や環境ラベルの説明を疑います。

### グリーン調達とグリーン電力証書

グリーン電力証書は、太陽光・風力・バイオマスなどの再生可能エネルギーがもつ**環境価値を証書として扱う仕組み**です。

```text
製品・サービスを環境面から選んで調達する
→ グリーン調達

再エネの環境価値を証書として扱う
→ グリーン電力証書
```

「グリーン」という名前が共通していても、役割は異なります。

### グリーン調達とCSR

CSRは、企業が社会や環境に対して責任ある行動をするという広い考え方です。

```text
企業活動全体で社会・環境への責任を果たす
→ CSR

調達活動で環境面を考慮する
→ グリーン調達
```

グリーン調達は、企業がCSRを実践する方法の一つになり得ますが、CSRそのものと同じ意味ではありません。

CSRについては、[CSRとは？](/fe/csr/)も参照してください。

## まとめ（試験直前用）

- グリーン調達は、調達時に製品・サービスの環境負荷や供給者の環境への取組を考慮する
- FEでは **「購入・調達」「供給者」「環境負荷低減」** が重要な判断語
- グリーン投資は、環境関連の活動へ資金を投じる
- 環境ラベルは、環境性能を認定・表示する
- グリーン電力証書は、再生可能エネルギーの環境価値を証書として扱う
- 「環境」という単語だけで選ばず、**購入・投資・認定・証書化のどの行為か**で切り分ける

```text
買う・調達する
→ グリーン調達

投資する
→ グリーン投資

認定・表示する
→ 環境ラベル

再エネ + 証書
→ グリーン電力証書
```

> **「グリーン」という名前ではなく、何をしているかで切り分ける。**
