## まず結論

科目Bでは、**計算結果が合っていても、何を求める問題なのかを取り違えると誤答になる**ことがあります。プログラムを読む前に、**入力・返す値・返す値が満たす条件**を分けて確認しましょう。

特に「0を返す」と「入力に足すと0になる値を返す」は別の要求です。

## 直感的な説明

「お釣りを0円にする」と「支払額に足すと合計が1000円になる金額を返す」は違います。

後者は、支払額によって返す金額が変わります。プログラムでも、**出力そのものの値**と、**出力を使った結果**を混同しないことが大切です。

## 定義・仕組み

プログラムを読む前に、次の4点をメモします。

| 確認すること | 自分への質問 |
|---|---|
| 入力 | 最初に与えられる値は何か |
| 出力 | `return` で何を返すか |
| 条件 | 返す値は何を満たす必要があるか |
| 途中処理 | 返す前に値をどう更新するか |

例えば、8ビットの符号なし整数 `x` を受け取り、**`x` に加えると下位8ビットが0になる値**を返す処理を考えます。9ビット目への桁あふれは捨てます。

```text
○f(x)
  y ← （空欄）
  y ← y + 00000001
  return y
```

このとき求めるのは、`y` を直接0にする式ではありません。**最後に返す `y` が、`x + y = 0`（下位8ビット）を満たす式**です。

`x = 00000101`（5）なら、返す値は `11111011`（251）です。

```text
    00000101  (5)
  + 11111011  (251)
  ----------
  1 00000000  → 下位8ビットは0
```

全ビットを反転して1を足す「2の補数」を使えば、この値を作れます。

```text
x                 00000101
x XOR 11111111    11111010
さらに1を加える   11111011
```

## 科目Aでどう出る？

関連する基礎知識は、2の補数とビット演算です。

| 演算・処理 | 役割 |
|---|---|
| `x OR 11111111` | 常に `11111111` にする |
| `x XOR 11111111` | xの全ビットを反転する |
| 全ビット反転して1を加える | 8ビットで加算すると0になる値を作る |

演算の意味が分かることと、**要求された値を返せること**は別々に確かめます。

## 科目Bでどう使う？

### まず戻り値から逆向きに読む

```text
y ← （空欄）
y ← y + 00000001
return y
```

最後に1を加えているので、空欄は「完成した戻り値」ではなく**1を加える前の値**を作ります。

### もっともらしい選択肢を小さな値で試す

例えば空欄に `x OR 11111111` を入れると、

```text
x = 00000101
y = 11111111
y = y + 1 = 00000000
return y = 00000000
```

ここまでの計算は正しいです。しかし、要求は「0を返す」ことではありません。

```text
x + return y
= 00000101 + 00000000
= 00000101  ← 0ではない
```

この選択肢は**計算が間違っているのではなく、要求を満たしていない**ため除外できます。

一方、`x XOR 11111111` なら、次の1加算と合わせて2の補数を返せます。

### 試験中の3ステップ

1. **条件を言い換える**：「何を返すか」だけでなく「返す値で何が成立するか」を書く。
2. **returnから逆向きに見る**：返す直前の加算や代入を見落とさない。
3. **0以外の小さな入力で検算する**：候補が要求を満たすか確かめる。

### 確認問題

次の処理は整数 `x` を受け取り、`x` に足すと10になる整数を返したいものです。

```text
○g(x)
  y ← （空欄）
  y ← y + 2
  return y
```

空欄に入る式はどちらでしょうか。

- A：`10 - x`
- B：`8 - x`

<details markdown="1">
<summary>答えと理由を見る</summary>

**B：`8 - x`** です。

`return y` は `10 - x` にならなければいけませんが、その前に2を足しています。したがって空欄では `8 - x` を作ります。

`x = 3` なら、`y = 5` → `y = 7` → `3 + 7 = 10` です。

</details>

## よくある誤解・混同

| 誤解 | 正しい読み方 |
|---|---|
| 0になる計算を見つけたら正解 | **何と何を計算した結果が0か**確認する |
| 空欄で最終結果を作ればよい | 空欄の**後の処理**も含めて判断する |
| 例としてx=0を試せば十分 | x=0だけでは誤った処理を見抜けないことがある |
| 途中計算が正しければ選択肢も正しい | 最終的に**問題文の条件を満たすか**確認する |

なお、具体例で一つの候補が失敗すれば、その候補は除外できます。ただし、**一つの例で成功しただけでは、すべての入力で正しい証明にはなりません**。

## まとめ（試験直前用）

- **入力・戻り値・戻り値が満たす条件**を区別する。
- 空欄の後にある代入や加算まで読む。
- `return` から逆向きに考える。
- 0以外の小さな値で、誤った候補を切る。
- 計算が正しいことと、要求を満たすことは別。
