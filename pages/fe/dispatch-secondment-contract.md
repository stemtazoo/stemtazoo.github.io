## まず結論

派遣・出向・請負を見分けるときは、**「誰と雇用関係があるか」と「誰が労働者へ指揮命令するか」**を分けて考えるのがポイントです。

基本情報技術者試験では、次の整理を基準にすると選択肢を切りやすくなります。

| 形態 | 雇用関係 | 業務上の指揮命令 |
|---|---|---|
| 労働者派遣 | 派遣元と労働者 | 派遣先 → 労働者 |
| 在籍出向 | 出向元・出向先の双方と雇用関係 | 出向先 → 労働者 |
| 請負 | 請負会社と労働者 | 請負会社 → 労働者 |

試験では特に、**請負なのに発注側が労働者へ直接指示する**という記述を誤りとして切れることが重要です。

このページでは、**雇用関係と指揮命令の観点から派遣・出向・請負を比較**します。成果物完成責任や業務遂行責任で契約を見分ける場合は、[請負・準委任・派遣契約の違い](/fe/contract-types-outsourcing/) を参照してください。

派遣元・派遣先それぞれの36協定、賃金支払、労働時間管理の責任は、[派遣元と派遣先の責任分担]({{ '/fe/dispatch-worker-responsibility/' | relative_url }})で整理しています。

さらに、**作業場所だけでは契約関係を判断しません。**

```text
発注者の事業所で作業している
≠
発注者が作業者へ指揮命令してよい
```

請負契約なら、発注者の事業所で作業していても、作業者への指揮命令は受注者側が行うのが基本です。

## 直感的な説明

3つの形態を「誰が仕事を指示するか」でイメージします。

### 労働者派遣

```text
派遣元企業 ── 雇用 ── 労働者
                         ↑
                         │ 指揮命令
                         │
                     派遣先企業
```

労働者を雇っているのは派遣元ですが、実際の仕事の指示は派遣先から受けます。

### 在籍出向

```text
出向元企業 ── 関係を維持 ── 労働者
                              ↑
                              │ 指揮命令
                              │
                          出向先企業
```

労働者は出向元との関係を残したまま出向先で働き、出向先の管理・指揮命令の下で業務を行います。

### 請負

```text
発注企業
   │
   │ 仕事を依頼
   ↓
請負会社 ── 雇用・指揮命令 ── 労働者
```

発注企業が依頼する相手は、個々の労働者ではなく請負会社です。

そのため、発注企業が請負会社の労働者へ直接作業指示を出す、という説明は請負の基本的な関係とは合いません。

ここで大切なのは、**作業している場所と、指揮命令する会社を分けること**です。

例えば、受注者の作業者が発注者の事業所へ出向いて作業していても、それだけで派遣になるわけではありません。

```text
どこで働いている？
→ 補助情報

誰が指示している？
→ 契約形態を見分ける重要情報
```

## 定義・仕組み

### 労働者派遣

労働者派遣では、**派遣元が労働者を雇用し、その労働者が派遣先の指揮命令を受けて働きます。**

さらに、会社同士では**派遣元事業主と派遣先事業主の間に労働者派遣契約**があります。

試験では、次の3本を分けて考えると安定します。

```text
派遣元 ↔ 派遣先   → 労働者派遣契約
派遣元 ↔ 労働者   → 雇用関係
派遣先 → 労働者   → 指揮命令関係
```

したがって、次の2つを分けて覚えます。

```text
雇用する      → 派遣元
仕事を指示する → 派遣先
```

派遣先と労働者の間に、派遣元とは別の通常の雇用関係が生じる、と考えないことがポイントです。

### 出向

出向では、労働者が別の企業で一定期間勤務し、**出向先の管理・指揮命令の下で働きます。**

FEでは、まず在籍出向をイメージすると整理しやすいです。

在籍出向では、出向元との雇用関係を維持しつつ、出向先とも雇用関係が生じ、出向先の指揮命令の下で勤務します。

一方、転籍出向では元の会社との雇用関係が終了し、転籍先へ移る形になります。

試験問題で単に「出向」と書かれている場合は、問題文の契約関係や雇用関係の説明を確認して判断します。

### 請負

請負では、発注企業が請負会社に仕事の完成などを依頼し、**請負会社が自社の労働者へ指揮命令して仕事を進めます。**

```text
発注企業
↓ 依頼
請負会社
↓ 指揮命令
労働者
```

したがって、

```text
発注企業
↓ 直接指揮命令
請負会社の労働者
```

という関係を請負の説明として選ぶのは不適切です。

また、作業場所が発注企業の事業所であっても、この基本関係は変わりません。

```text
発注企業の事業所で作業
＋
請負契約
↓
雇用関係     → 請負会社と労働者
指揮命令     → 請負会社 → 労働者
```

作業場所だけを見て、発注企業と労働者の間に雇用関係ができると判断しないようにします。

請負・準委任・派遣の責任範囲をまとめて比較したい場合は、[請負契約・準委任契約・派遣契約の違い]({{ '/fe/contract-types-outsourcing/' | relative_url }})もあわせて確認すると整理しやすくなります。

### 請負の労務管理は誰が行う？（37号告示）

請負は、**作業の指示だけでなく、労働時間や休暇、職場規律なども請負会社が自ら管理する**ことが重要です。厚生労働省の「労働者派遣事業と請負により行われる事業との区分に関する基準」（**37号告示**）に沿って整理します。

| 管理項目 | 請負で基本的に指示・管理する側 |
|---|---|
| 業務の遂行方法の指示 | 請負会社（受託側） |
| 業務遂行に関する評価 | 請負会社（受託側） |
| 始業・終業時刻、休憩、休日、休暇 | **請負会社（受託側）** |
| 残業・休日労働の指示 | 請負会社（受託側） |
| 服務規律、作業者の配置・変更 | 請負会社（受託側） |

例えば、機械設備の制御ソフト開発を請け負った会社が、顧客の工場で作業する場合を考えます。

```text
発注企業
 ├─ 受託会社の責任者へ成果物・納期を相談 …… 原則として可能
 └─ 受託会社の作業者へ休暇日や残業を直接指示 …… 要注意

請負会社の責任者
 └─ 自社の作業者に仕事を割り振り、休暇や勤務時間を管理
```

**発注者から受託会社の責任者への業務上の要請**と、**発注者から作業者への直接の指揮命令**は違います。受託会社の責任者が自社で判断して業務を管理することが大切です。ただし、責任者が発注者の指示を機械的に伝えるだけなら、実態として発注者が直接指揮命令していると判断される可能性があります。

また、発注者が**勤務時間や入退場時刻を単に把握すること**と、休暇の取得日・時間外労働などを**指示・決定すること**も区別します。安全衛生上の連絡や施設利用上のルールがあるだけで、直ちに偽装請負になるとは限りません。個別の事案では契約名より実際の指揮命令・独立性が判断されます。

**科目Aでの判断：** 「請負なのに発注側が休暇のルールや残業を直接決める」なら注意。「請負会社が自ら勤務管理や業務評価を行う」なら請負の基本に合います。

一次情報：[厚生労働省・37号告示（第2条第1号）](https://www.mhlw.go.jp/web/t_doc?dataId=75024000&dataType=0&pageNo=1)、[厚生労働省・区分基準関係の疑義応答集](https://www.mhlw.go.jp/bunya/koyou/gigi_outou01.html)。

## 科目Aでどう出る？

科目Aでは、企業A・企業B・労働者Cのような図を見て、雇用関係や指揮命令関係を判断する問題が出ます。

### 判断手順

まず契約名を確認します。

```text
派遣？
出向？
請負？
```

次に、次の2問を別々に考えます。

```text
Q1. 労働者を雇っているのは誰か？
Q2. 日々の仕事を指示するのは誰か？
```

この2つを混ぜないことが重要です。

さらに、作業場所が書かれていても、次の順番を崩さないようにします。

```text
作業場所を見る
↓
すぐ契約形態を決めない
↓
雇用関係と指揮命令を見る
```

### 選択肢を切る判断表

| 問題文の表現 | 判断 |
|---|---|
| 派遣元事業主と派遣先事業主が労働者派遣契約を結ぶ | ○ |
| 派遣先が派遣労働者へ業務指示をする | ○ |
| 派遣先と派遣労働者に雇用関係が生じる | × |
| 出向先が出向者へ業務指示をする | ○ |
| 請負の発注側が受託側の労働者へ直接指示する | × |
| 請負の作業者が発注側の事業所で働く | それだけでは契約関係は変わらない |
| 請負の作業者が発注側と新たに雇用契約を結ぶ | × |

## どんな場面で使う？

企業が外部の人材や他社の組織を活用するとき、契約形態によって責任関係や指揮命令のあり方が変わります。

そのため、情報システム開発の外部委託や要員調達を考えるときにも、この違いが重要になります。

例えば、開発会社へ成果物の完成を依頼する請負契約なのに、発注企業が受託会社の担当者へ日常的に直接指示している場合、契約上想定された役割分担と実態がずれている可能性があります。

一方、セキュリティや設備上の理由から、受注者の作業者が発注者の事業所で作業することはあり得ます。

その場合でも、FE試験では「発注者の場所で働いている」という一点より、**誰が雇用し、誰が指揮命令するか**を優先して判断します。

FE試験では法律の細部を暗記するより、**契約形態ごとの基本的な関係を図で判断できること**が大切です。

## よくある誤解・混同

### 派遣先で働くなら、派遣先と雇用関係がある

誤りです。

派遣では、

```text
雇用関係   → 派遣元
指揮命令   → 派遣先
```

と分かれます。

「働く場所」と「雇用している会社」を同じだと思わないようにします。

### 発注者の事業所で働くなら、発注者が指示してよい

誤りです。

作業場所が発注者側でも、請負契約なら作業者への指揮命令は受注者側が行います。

```text
働く場所
≠
指揮命令する会社
```

この切り分けは、請負と派遣を見分けるときに特に重要です。

### 請負なら、作業者は発注者とも雇用契約を結ぶ

誤りです。

請負会社に所属する作業者は、基本的に請負会社との雇用関係のまま作業します。

発注者の事業所で働くためだけに、発注者と新たな雇用契約を結ぶとは考えません。

### 契約書に請負と書けば、必ず請負になる

誤りです。発注企業が請負会社の労働者へ直接指揮命令するなど、実態が労働者派遣に当たる場合、**偽装請負**として問題になることがあります。契約書の名称だけでなく、実際の指揮命令関係を確認します。

### 派遣と請負は、どちらも他社で働くので同じ

異なります。

最も大きな判断ポイントは、**発注側が労働者へ直接指揮命令するか**です。

```text
派遣
→ 派遣先が労働者へ指揮命令する

請負
→ 請負会社が自社の労働者へ指揮命令する
```

### 出向と派遣は同じ

異なります。

どちらも勤務先側から指揮命令を受ける点は似ていますが、出向は人材育成・企業間交流・業務上の必要などを背景に、出向先で勤務する形態です。

試験では、名称だけで判断せず、**雇用関係と指揮命令関係を図にして確認する**のが安全です。

### 出向なら必ず元の会社との雇用関係が残る

必ずしもそうとは限りません。

在籍出向では元の会社との関係を維持しますが、転籍出向では元の会社との雇用関係が終了します。

そのため、問題文に「在籍」「転籍」などの条件があれば、その条件を優先します。

## まとめ（試験直前用）

- **労働者派遣契約＝派遣元と派遣先の会社同士**
- 派遣は、**雇用＝派遣元、指揮命令＝派遣先**
- 在籍出向では、出向元との関係を残しつつ、**出向先が指揮命令**する
- 請負では、**請負会社が自社の労働者へ指揮命令**する
- **作業場所が発注側でも、請負なら指揮命令は受注側**
- 「雇用は誰と？ 指示は誰から？」を分けて考える
- 請負なのに発注側が労働者へ直接指示する選択肢は要注意

> **場所ではなく、雇用と指揮命令を見る。**
