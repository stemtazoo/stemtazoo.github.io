## まず結論

CG用語は、何をする技術なのかで整理すると覚えやすくなります。

| 役割 | 主な用語 |
|---|---|
| 形を表す | ポリゴン、ワイヤーフレーム、サーフェス、ソリッド、メタボール |
| 見える範囲を決める | クリッピング、隠線・隠面消去 |
| 表面を表現する | シェーディング、テクスチャマッピング、バンプマッピング |
| 光を計算する | レイトレーシング、ラジオシティ |
| 画像を作る・整える | レンダリング、アンチエイリアシング |
| 変化・動きを扱う | モーフィング、モーションキャプチャ |

## 直感的な説明

3DCGでは、まず形を作り、見える範囲を決め、表面や光を計算して、最後に画像として描きます。

~~~text
形を作る
 ↓
見える部分を決める
 ↓
明暗・模様・凹凸感を付ける
 ↓
光を計算する
 ↓
画像として描く
~~~

用語を工程の中に置くと、横並びの暗記ではなく役割の違いとして理解できます。

## 定義・仕組み

### 形を表す技術

**ポリゴン**は、多角形を使って立体の形状を表す基本要素です。

代表的な3Dモデル表現は次のとおりです。

- ワイヤーフレームモデル：頂点と辺による骨組み
- サーフェスモデル：面や曲面の集合
- ソリッドモデル：内部まで含む立体
- メタボール：球などを組み合わせて滑らかな形状を表現

### 見える部分を決める技術

[クリッピング](/fe/clipping/)は表示範囲の外側を描画対象から除外します。

[隠線消去・隠面消去](/fe/hidden-line-and-surface-removal/)は、他の面などに隠れて視点から見えない線や面を描画しないようにします。

~~~text
表示範囲の外 → クリッピング
物体に隠れて見えない → 隠線・隠面消去
~~~

### 表面を表現する技術

**シェーディング**は、表面に明暗・陰影を付けて立体感を表します。

**テクスチャマッピング**は、物体表面に画像や模様を対応付けて質感を表します。

**バンプマッピング**は、表面の見え方を工夫して細かな凹凸感を表します。

~~~text
明暗 → シェーディング
模様 → テクスチャマッピング
凹凸感 → バンプマッピング
~~~

### 光を扱う技術

**レイトレーシング**は、光線の経路を追跡し、反射や透過などを考慮して画像を作る方法です。

**ラジオシティ**は、表面で光がさまざまな方向へ広がる**拡散反射**を前提に、面同士の光エネルギーのやり取りを計算して明るさを求める方法です。

~~~text
光線を追跡 → レイトレーシング
面同士の拡散反射による光のやり取り → ラジオシティ
~~~

### 画像を作る技術

**レンダリング**は、形状、視点、光源、表面などの情報から最終的な画像を生成する処理です。

[アンチエイリアシング](/fe/anti-aliasing/)は、斜め線や曲線の輪郭に生じるギザギザを目立たなくします。[ラスタデータとベクタデータ](/fe/raster-vector-graphics/)で扱う画素の考え方ともつながります。

### 変化・動きを扱う技術

[モーフィング](/fe/morphing/)は、ある画像や形状から別の画像や形状へ滑らかに変化させます。

**モーションキャプチャ**は、人や物体の実際の動きをセンサやカメラなどで取得し、CGの動きなどに利用します。

## どんな場面で使う？

ゲーム、CAD、映像制作などでは複数の技術を組み合わせます。例えば、ポリゴンなどで形を作り、テクスチャを貼り、シェーディングで明暗を付け、最終的にレンダリングします。

つまりCG用語は、互いに競合する技術だけではなく、一つの画像を作る工程の異なる役割でもあります。

## よくある誤解・混同

### シェーディングとテクスチャマッピング

シェーディングは主に明暗・陰影、テクスチャマッピングは模様や画像です。

### レイトレーシングとレンダリング

レンダリングは最終画像を作る広い処理です。レイトレーシングは画像生成に利用できる代表的な手法の一つです。

### レイトレーシングとラジオシティ

光線の経路を追跡するのがレイトレーシング、拡散反射を前提に面同士の光エネルギー交換を計算するのがラジオシティです。

光線追跡方式でも物体間の相互反射を計算できるため、**「相互反射」という言葉だけでラジオシティと決めない**ようにします。

[NVIDIA：GPU Gems 2 第39章](https://developer.nvidia.com/gpugems/gpugems2/part-v-image-oriented-computing/chapter-39-global-illumination-using-progressive)では、面同士のエネルギー交換と、ラジオシティが拡散反射面を前提とする点を確認できます。

### クリッピングと隠面消去

表示範囲の外を除くのがクリッピング、表示範囲内でも他の物体に隠れている部分を除くのが隠線・隠面消去です。

### ワイヤーフレーム・サーフェス・ソリッド

~~~text
線 → ワイヤーフレーム
面 → サーフェス
中身まである立体 → ソリッド
~~~

と整理します。

## まとめ（試験直前用）

- 形：ポリゴン、ワイヤーフレーム、サーフェス、ソリッド
- 範囲外：クリッピング
- 見えない部分：隠線・隠面消去
- 明暗：シェーディング
- 模様：テクスチャマッピング
- 凹凸感：バンプマッピング
- 光線追跡：レイトレーシング
- 拡散反射を前提とした面同士の光エネルギー交換：ラジオシティ
- 最終画像：レンダリング
- ギザギザ：アンチエイリアシング
- 滑らかな変化：モーフィング
- 実際の動き：モーションキャプチャ
