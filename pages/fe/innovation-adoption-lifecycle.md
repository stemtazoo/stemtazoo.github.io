## まず結論

イノベーター理論では、新しい製品やサービスを**採用する時期や態度**によって、人々を5つの層に分けて考えます。

試験では、名前を丸暗記するよりも次の違いで判断します。

```text
最初に飛び込む
→ イノベーター

早く採用し、周囲にも影響
→ アーリーアダプター

慎重だが比較的早い
→ アーリーマジョリティ

多数派を見てから
→ レイトマジョリティ

最後まで慎重
→ ラガード
```

特に重要なのが、**イノベーターとアーリーアダプターの違い**です。

## 直感的な説明

例えば、新しいサービスが登場した場面を考えます。

```text
登場
│
├─「面白そう。すぐ試そう」
│   → イノベーター
│
├─「調べて良さそうだから使おう。周りにも紹介しよう」
│   → アーリーアダプター
│
├─「評判も良いし、そろそろ使おう」
│   → アーリーマジョリティ
│
├─「みんな使っているなら使おう」
│   → レイトマジョリティ
│
└─「今のままで困っていない」
    → ラガード
```

ポイントは、単に「早い・遅い」だけではありません。

**新しいものへの姿勢や、周囲から受ける・与える影響**も判断材料になります。

## 定義・仕組み

イノベーションの普及研究では、採用者を採用時期の違いによって分類します。

| 分類 | 特徴 | 試験での判断キーワード |
|---|---|---|
| イノベーター（Innovators） | 最も早く採用する | 冒険的・リスクを取る |
| **アーリーアダプター（Early Adopters）** | **早期に採用し、周囲にも影響を与える** | **情報収集・判断・オピニオンリーダー** |
| アーリーマジョリティ（Early Majority） | 比較的早いが慎重 | 慎重・平均より早い |
| レイトマジョリティ（Late Majority） | 多数が採用した後に採用する | 懐疑的・周囲を見てから |
| ラガード（Laggards） | 最も遅い層 | 保守的・伝統を重視 |

順番は、

```text
イノベーター
↓
アーリーアダプター
↓
アーリーマジョリティ
↓
レイトマジョリティ
↓
ラガード
```

です。

## 科目Aでどう出る？

科目Aでは、ある消費者層の特徴を文章で示して、どの分類かを選ばせる問題が考えられます。

### イノベーターとアーリーアダプター

どちらも早期に採用するため、ここが最も混同しやすいポイントです。

```text
最も早い
＋
新しいものを積極的に試す
＋
リスクを取る
→ イノベーター

早い
＋
自ら情報収集して判断
＋
周囲への影響が大きい
→ アーリーアダプター
```

**「オピニオンリーダー」「周囲への影響」**が出てきたら、アーリーアダプターを強く疑います。

### アーリーマジョリティとレイトマジョリティ

こちらは「周囲がどこまで採用しているか」に注目します。

```text
慎重だが平均より早く採用
→ アーリーマジョリティ

多数の人が採用したのを確認してから
→ レイトマジョリティ
```

「慎重」という言葉だけでは決めず、**採用するタイミング**まで確認します。

## どんな場面で使う？

新製品や新サービス、新技術などが、社会や市場へどのように広がっていくかを考えるときに使われます。

例えばマーケティングでは、

- 新製品を最初に受け入れる人は誰か
- 初期の利用者が周囲へどう影響するか
- どの段階で多数派へ広がるか

といった普及の流れを考える手掛かりになります。

FEではマーケティング理論そのものを深く研究するより、**5分類の特徴から用語を識別できること**を優先します。

## よくある誤解・混同

### 誤解1：最初に買う人はアーリーアダプター

最も早い層はイノベーターです。

```text
最初
→ イノベーター

その次
→ アーリーアダプター
```

アーリーアダプターは早期採用者ですが、イノベーターとは別の層です。

### 誤解2：早く採用する人は全部同じ

イノベーター、アーリーアダプター、アーリーマジョリティはいずれも比較的早い側ですが、特徴が異なります。

特に試験では、

> **冒険・リスク → イノベーター**  
> **影響力・オピニオンリーダー → アーリーアダプター**

という切り分けが有効です。

### 誤解3：レイトマジョリティとラガードは同じ

違います。

```text
多数派になってから採用
→ レイトマジョリティ

最後まで採用に慎重・伝統重視
→ ラガード
```

「遅い」という共通点だけで判断しないようにします。

## 一次・原典で確認する

この分類は、Everett M. Rogers の *Diffusion of Innovations* で体系的に扱われているイノベーション普及研究に基づきます。

試験範囲については、[IPA：試験要綱・シラバスについて](https://www.ipa.go.jp/shiken/syllabus/gaiyou.html)で確認できます。

なお、実際の普及現象は製品や社会環境によって異なります。FEでは、5分類を現実の人へ固定的に当てはめるのではなく、**試験で示された採用時期・態度から分類を判断する**ことを意識します。

## まとめ（試験直前用）

- イノベーター＝最も早く、新しいものへ積極的
- アーリーアダプター＝早期採用＋周囲への影響
- アーリーマジョリティ＝慎重だが比較的早い
- レイトマジョリティ＝多数派を確認してから
- ラガード＝最も遅く、保守的
- 「オピニオンリーダー」が出たらアーリーアダプターを疑う

試験直前には、

> **最初＝イノベーター、影響力＝アーリーアダプター、多数派を見てから＝レイトマジョリティ。**

を判断軸にします。
