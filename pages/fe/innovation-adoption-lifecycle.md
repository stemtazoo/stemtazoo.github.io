## まず結論

イノベーター理論では、新しい製品やサービスを**採用する時期や態度**によって、人々を5つの層に分けて考えます。

試験では、名前を丸暗記するよりも次の違いで判断します。

```text
最初に飛び込む
→ イノベーター

早く採用し、周囲にも影響
→ アーリーアダプター

慎重だが比較的早い
→ アーリーマジョリティ

多数派を見てから
→ レイトマジョリティ

最後まで慎重
→ ラガード
```

特に重要なのが、**イノベーターとアーリーアダプターの違い**です。

## 直感的な説明

例えば、新しいサービスが登場した場面を考えます。

```text
登場
│
├─「面白そう。すぐ試そう」
│   → イノベーター
│
├─「調べて良さそうだから使おう。周りにも紹介しよう」
│   → アーリーアダプター
│
├─「評判も良いし、そろそろ使おう」
│   → アーリーマジョリティ
│
├─「みんな使っているなら使おう」
│   → レイトマジョリティ
│
└─「今のままで困っていない」
    → ラガード
```

ポイントは、単に「早い・遅い」だけではありません。

**新しいものへの姿勢や、周囲から受ける・与える影響**も判断材料になります。

## 定義・仕組み

イノベーションの普及研究では、採用者を採用時期の違いによって分類します。

| 分類 | 典型的な割合 | 特徴 | 試験での判断キーワード |
|---|---:|---|---|
| イノベーター（Innovators） | 2.5% | 最も早く採用する | 冒険的・リスクを取る |
| **アーリーアダプター（Early Adopters）** | 13.5% | **早期に採用し、周囲にも影響を与える** | **情報収集・判断・オピニオンリーダー** |
| アーリーマジョリティ（Early Majority） | 34% | 比較的早いが慎重 | 慎重・平均より早い |
| レイトマジョリティ（Late Majority） | 34% | 多数が採用した後に採用する | 懐疑的・周囲を見てから |
| ラガード（Laggards） | 16% | 最も遅い層 | 保守的・伝統を重視 |

割合は採用者全体に占める**モデル上の典型的な比率**です。売上高の構成比ではなく、すべての製品で必ずこの割合になるわけでもありません。人の性格を固定的に決める分類ではなく、その製品を採用する時期に注目します。

順番は、

```text
イノベーター
↓
アーリーアダプター
↓
アーリーマジョリティ
↓
レイトマジョリティ
↓
ラガード
```

です。

### キャズムとは？

**キャズム（Chasm）**は、特にハイテク製品の市場で、**アーリーアダプターとアーリーマジョリティの間にある大きな普及の壁**を表す概念です。初期採用者に受け入れられても、一般層へ広まるとは限りません。

```text
イノベーター → アーリーアダプター ║ キャズム ║ アーリーマジョリティ
```

キャズムは普及理論の5分類とは別に提唱された、特定の市場での普及上の難所を説明する考え方です。

### プロダクトライフサイクルとの違い

| 比較 | イノベーター理論 | プロダクトライフサイクル（PLC） |
|---|---|---|
| 分類対象 | **いつ採用する人か** | **製品が市場でどの段階か** |
| 典型的な分類 | 5つの採用者層 | 導入期・成長期・成熟期・衰退期 |
| 注目すること | 普及の順序、採用行動 | 売上・需要・競争の推移 |

PLCの詳細は[プロダクトライフサイクルの記事](/fe/product-life-cycle/)で確認できます。

## 科目Aでどう出る？

科目Aでは、ある消費者層の特徴を文章で示して、どの分類かを選ばせる問題が考えられます。

### イノベーターとアーリーアダプター

どちらも早期に採用するため、ここが最も混同しやすいポイントです。

```text
最も早い
＋
新しいものを積極的に試す
＋
リスクを取る
→ イノベーター

早い
＋
自ら情報収集して判断
＋
周囲への影響が大きい
→ アーリーアダプター
```

**「オピニオンリーダー」「周囲への影響」**が出てきたら、アーリーアダプターを強く疑います。

### アーリーマジョリティとレイトマジョリティ

こちらは「周囲がどこまで採用しているか」に注目します。

```text
慎重だが平均より早く採用
→ アーリーマジョリティ

多数の人が採用したのを確認してから
→ レイトマジョリティ
```

「慎重」という言葉だけでは決めず、**採用するタイミング**まで確認します。

### 確認問題

ある新製品は先進的な利用者には好評だったが、一般の利用者からは実績不足を理由に採用されず、普及が伸び悩んだ。この状況を説明する考え方として適切なのはどれか。

- ア：キャズム
- イ：コストプラス法
- ウ：プロダクトポートフォリオマネジメント

<details markdown="1">
<summary>正解と解説を見る</summary>

**正解：ア。** 初期採用者から一般層へ広がる間の壁を示しています。

</details>

## どんな場面で使う？

新製品や新サービス、新技術などが、社会や市場へどのように広がっていくかを考えるときに使われます。

例えばマーケティングでは、

- 新製品を最初に受け入れる人は誰か
- 初期の利用者が周囲へどう影響するか
- どの段階で多数派へ広がるか

といった普及の流れを考える手掛かりになります。

FEではマーケティング理論そのものを深く研究するより、**5分類の特徴から用語を識別できること**を優先します。

## よくある誤解・混同

### 誤解1：最初に買う人はアーリーアダプター

最も早い層はイノベーターです。

```text
最初
→ イノベーター

その次
→ アーリーアダプター
```

アーリーアダプターは早期採用者ですが、イノベーターとは別の層です。

### 誤解2：早く採用する人は全部同じ

イノベーター、アーリーアダプター、アーリーマジョリティはいずれも比較的早い側ですが、特徴が異なります。

特に試験では、

> **冒険・リスク → イノベーター**  
> **影響力・オピニオンリーダー → アーリーアダプター**

という切り分けが有効です。

### 誤解3：レイトマジョリティとラガードは同じ

違います。

```text
多数派になってから採用
→ レイトマジョリティ

最後まで採用に慎重・伝統重視
→ ラガード
```

「遅い」という共通点だけで判断しないようにします。

### 「キャズムは必ずすべての製品で起きる」？

違います。普及の壁を説明する考え方ですが、すべての製品で同じ形で発生するとは限りません。

### 「採用者比率の34%は売上高の34%」？

違います。分類で用いるのは採用者の割合です。金額の構成比とは別です。

## 一次・原典で確認する

この分類は、Everett M. Rogers の [*Diffusion of Innovations*（出版社公式）](https://www.simonandschuster.com/books/Diffusion-of-Innovations-5th-Edition/Everett-M-Rogers/9780743222099) で体系的に扱われているイノベーション普及研究に基づきます。

キャズムはGeoffrey A. Mooreの *Crossing the Chasm* による概念です。[著者の公式解説](https://geoffreyamoore.com/book/crossing-the-chasm)では、初期採用者から実用性を重視する一般層へ移る際の難しさを説明しています。5分類そのものと、普及の壁を説明する概念を区別しましょう。

試験範囲については、[IPA：試験要綱・シラバスについて](https://www.ipa.go.jp/shiken/syllabus/gaiyou.html)で確認できます。

なお、実際の普及現象は製品や社会環境によって異なります。FEでは、5分類を現実の人へ固定的に当てはめるのではなく、**試験で示された採用時期・態度から分類を判断する**ことを意識します。

## まとめ（試験直前用）

- 最も早く試す＝**イノベーター**、早期採用＋周囲への影響＝**アーリーアダプター**
- 慎重だが比較的早い＝**アーリーマジョリティ**、多数派を確認してから＝**レイトマジョリティ**
- 最も遅く、従来の方法を重視＝**ラガード**
- **キャズム**＝アーリーアダプターとアーリーマジョリティの間の普及の壁
- 採用者分類は**人の採用時期**、PLCは**製品の市場段階**を見る

試験直前には、

> **最初＝イノベーター、影響力＝アーリーアダプター、多数派を見てから＝レイトマジョリティ。**

を判断軸にします。
