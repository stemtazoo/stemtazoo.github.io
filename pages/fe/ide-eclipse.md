## まず結論

**IDE（Integrated Development Environment：統合開発環境）とは、プログラムを書く・実行する・デバッグするなど、開発に必要な機能をまとめたソフトウェアです。**

基本情報技術者試験では、まず次のように切り分けます。

```text
Eclipse
→ IDE（統合開発環境）

Perl / PHP / Ruby
→ プログラミング言語
```

つまり、**IDEは「開発するための環境」、プログラミング言語は「プログラムを書くための言語」**です。

## 直感的な説明

IDEは、プログラミングのための「作業机セット」のようなものです。

プログラム開発では、コードを書くだけでなく、実行したり、エラーの原因を調べたり、複数のファイルを管理したりします。

IDEには、こうした作業を助ける機能がまとめられています。

```text
コードを書く
↓
ビルドする
↓
実行する
↓
エラーを調べる
```

Eclipseは、この一連の作業を支援する代表的なIDEです。

一方、Perl・PHP・Rubyは、IDEそのものではなく、**プログラムの処理内容を記述するための言語**です。

## 定義・仕組み

IDEには、一般に次のような機能があります。

| 機能 | 役割 |
|---|---|
| ソースコードエディタ | プログラムを書く |
| ビルド支援 | コンパイルや実行準備を行う |
| 実行機能 | 作ったプログラムを動かす |
| デバッガ | 処理を追跡して不具合を調べる |
| プロジェクト管理 | 複数のソースや設定をまとめて管理する |
| プラグイン | 必要な機能を追加する |

Eclipseは、もともとIBMが開発し、その後オープンソースとして広く利用されるようになった統合開発環境です。

Java開発でよく知られていますが、プラグインを追加することで、さまざまな開発用途に拡張できます。

重要なのは、**Eclipse自体はプログラミング言語ではない**という点です。

```text
Eclipse
→ 開発を支援するソフトウェア

Java / Perl / PHP / Ruby など
→ プログラムを書くための言語
```

このテーマは、基本情報技術者試験のソフトウェア開発や開発環境に関係します。公式の出題範囲やシラバスは、[IPA：基本情報技術者試験](https://www.ipa.go.jp/shiken/kubun/fe.html) から確認できます。

## 科目Aでどう出る？

科目Aでは、複数の製品名・言語名を並べて、**どれが統合開発環境か**を選ばせる問題に注意します。

まず、「開発環境」なのか「言語」なのかを切り分けます。

| 用語 | 種類 | 判断のポイント |
|---|---|---|
| Eclipse | IDE | エディタ・実行・デバッグなどをまとめる |
| Perl | プログラミング言語 | スクリプト言語 |
| PHP | プログラミング言語 | Webのサーバサイドで使われることが多い |
| Ruby | プログラミング言語 | オブジェクト指向のスクリプト言語 |

試験中は、次の一言で切ると速いです。

```text
開発するための道具
→ IDE

処理を書くための言葉
→ プログラミング言語
```

### Eclipseが出たら？

Eclipseが選択肢にあれば、まず **「IDE」** を疑います。

```text
Eclipse
→ 統合開発環境
→ コード作成・実行・デバッグを支援
```

「Web向けのスクリプト言語」「オブジェクト指向言語」などの説明なら、Eclipseではなくプログラミング言語の話です。

## どんな場面で使う？

IDEは、プログラムを効率よく開発したいときに使います。

例えば、次のような場面です。

- ソースコードを編集する
- 文法ミスを見つける
- プログラムを実行する
- ブレークポイントを置いて処理を確認する
- 複数のファイルを一つのプロジェクトとして管理する
- プラグインで開発機能を追加する

単純なテキストエディタでもコードを書くことはできますが、IDEを使うと、開発に必要な作業を一つの環境で進めやすくなります。

## よくある誤解・混同

### EclipseはJavaというプログラミング言語である

誤りです。

EclipseはJava開発でよく使われますが、Eclipseそのものは言語ではありません。

```text
Eclipse
→ 開発環境

Java
→ プログラミング言語
```

### IDEとエディタは同じ？

完全には同じではありません。

テキストエディタは主に文章やコードを書く機能を持ちます。

IDEは、編集に加えて実行やデバッグ、プロジェクト管理などもまとめて提供します。

```text
エディタ
→ 書くことが中心

IDE
→ 書く + 実行 + デバッグ + 管理
```

### PHPやRubyもIDEである

誤りです。

PHPやRubyはプログラミング言語です。

```text
PHP / Ruby / Perl
→ 言語

Eclipse
→ 環境
```

### IDEがプログラムを自動で作ってくれる？

IDEは開発を支援するツールです。

コード補完などの支援機能はありますが、基本的には開発者がプログラムを書くための環境です。

## まとめ（試験直前用）

- IDEは、編集・実行・デバッグなどをまとめた統合開発環境
- Eclipseは代表的なIDE
- Perl・PHP・Rubyはプログラミング言語
- **IDE＝開発するための環境、言語＝処理を書くための言葉** と切り分ける
- Eclipseが出たら、まず「統合開発環境」を疑う

試験直前には、次の一文を思い出してください。

> **Eclipseは「言語」ではなく「開発するための環境」。**
