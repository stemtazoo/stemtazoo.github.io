## まず結論

BCMとは、**事業継続の方針策定・分析・BCPの策定から、教育・訓練・テスト・見直しまでを含む、継続的な管理活動**です。

基本情報技術者試験では、次のように切り分けると分かりやすいです。

```text
影響を分析する                 → BIA
事業を継続・復旧する計画       → BCP
教育・訓練・見直しを続ける活動 → BCM
```

BCMは、BCPを「作って終わり」にしないための考え方です。**BCPを作った後に始まる活動だけを指すのではなく、BCPを策定する活動も含みます。**

このページでは、**BCPの策定から教育・訓練・見直しまでを回すBCMの管理活動**を中心に扱います。非常時の計画そのものは、[BCPとは？](/fe/business-continuity-plan/) で整理しています。 日常的なサービス品質の目標値を管理する考え方は、[SLAとは？](/fe/sla/) を参照してください。

## 直感的な説明

BCPは、災害や障害が起きたときの行動計画です。

ただし、計画書を作っただけでは、実際の非常時にうまく動けるとは限りません。

例えば、次のようなことが起きます。

```text
担当者が異動していた
連絡先が古くなっていた
代替手順を誰も試したことがなかった
システム構成が変わっていた
```

このような状態だと、BCPがあっても使えません。

そこで、訓練したり、教育したり、定期的に見直したりして、計画を使える状態に保ちます。

この継続的な活動がBCMです。

## 定義・仕組み

BCMは、Business Continuity Management の略です。日本語では **事業継続マネジメント** といいます。

BCMでは、BCPを中心に、次のような活動を継続します。

| 活動 | 内容 |
|---|---|
| 方針・体制 | 事業継続の基本方針と責任・役割を決める |
| 分析 | 重要業務や停止時の影響、リスクを分析する |
| 計画 | BCPを作成する |
| 教育 | 関係者に役割や手順を理解してもらう |
| 訓練 | 非常時の手順を実際に試す |
| テスト | BCPが有効に機能するか確認する |
| 見直し | 環境変化に合わせて計画を更新する |

流れとしては、次のように考えると整理しやすいです。

```text
方針・体制を決める
→ BIAやリスク分析を行う
→ 事業継続の戦略を決め、BCPを作る
→ 教育・訓練・テストを行う
→ 結果や環境変化をもとに見直す
→ また改善する
```

このように、BCMは計画を作る段階から続く改善活動です。内閣府の[事業継続ガイドライン（令和5年3月）](https://www.bousai.go.jp/kyoiku/kigyou/pdf/guideline202303.pdf)の1.1節・1.5節でも、方針・分析・計画策定・教育訓練・改善を含むプロセスとして整理されています。

公式の出題範囲やシラバスは、[IPA：基本情報技術者試験](https://www.ipa.go.jp/shiken/kubun/fe.html) から確認できます。BCMは、サービスマネジメントや事業継続の運用・改善に関係する考え方です。

## 科目Aでどう出る？

科目Aでは、「分析」「計画そのもの」「継続的な管理活動」のどれが問われているかを判断します。

```text
事業停止の影響を分析する             → BIA
事業を継続・復旧する計画そのもの     → BCP
教育・訓練・テスト・見直しを続ける   → BCM
```

BCPの策定もBCMの一部です。選択肢では、**計画そのものならBCP、策定・運用・改善を含む管理全体ならBCM**と読み分けます。

## どんな場面で使う？

BCMは、組織が非常時にも重要業務を続けられるようにするために使います。

例えば、次のような場面です。

- BCPの内容を社員に教育する
- 災害を想定した訓練を行う
- 代替拠点や代替手順を試す
- システム構成変更後にBCPを見直す
- 訓練結果をもとに復旧手順を改善する
- 取引先や外部サービスの変更をBCPに反映する

## よくある誤解・混同

一番混同しやすいのは、BCPとBCMです。

| 用語 | 見分け方 |
|---|---|
| BIA | 影響を分析し、重要業務や最大停止時間を整理する |
| BCP | 事業を継続・復旧するための計画 |
| BCM | BCPの策定・運用・教育・訓練・見直しを含む管理活動 |

選択肢では、次のように判断します。

| 選択肢の内容 | 判断 |
|---|---|
| 情報システムに許容される最大停止時間を決める | BIA |
| 代替手順や復旧手順を計画としてまとめる | BCP |
| 代替手順・復旧手順を教育する | BCM |
| BCPの有効性をテストする | BCM |
| 環境変化を踏まえてBCPを見直す | BCM |

特に、教育・訓練・テスト・見直しという言葉が出たら、BCP単体ではなく **BCMの活動** と考えるとよいです。

また、BCMはBCPと別物というより、BCPを含む広い管理活動です。

```text
BCM の中に BCP がある
```

と考えると、関係を思い出しやすくなります。

## まとめ（試験直前用）

- BCMは、事業継続のための **継続的な管理活動**
- BCPは計画、BCMはその策定・運用・教育・訓練・見直しを含む活動
- BIAは、BCPを作る前に影響や最大停止時間を分析する作業
- 「教育・訓練・テスト・見直し」が出たらBCMを疑う
- BCMは、BCPを作って終わりにしないための考え方
