## まず結論

機械学習の代表的な学習方法は、**何を手掛かりに学ぶか**で切り分けると分かりやすくなります。

```text
正解ラベルあり
→ 教師あり学習

正解ラベルなしで構造を探す
→ 教師なし学習

行動に対する報酬を使う
→ 強化学習
```

基本情報技術者試験では、まず **ラベル・構造・報酬** のどれが書かれているかを確認します。

> **ラベルあり＝教師あり、ラベルなしで構造発見＝教師なし、報酬＝強化学習。**

## 直感的な説明

勉強にたとえると、次のように考えられます。

### 教師あり学習

答え付きの問題集で勉強するイメージです。

```text
問題 + 正解
→ 正しい対応関係を学ぶ
```

### 教師なし学習

答えのないデータを見て、似たもの同士のまとまりや特徴を探すイメージです。

```text
データだけ
→ グループや構造を見つける
```

### 強化学習

試行錯誤しながら、得点が高くなる行動を覚えるイメージです。

```text
行動
↓
報酬・得点
↓
より良い行動を学ぶ
```

## 定義・仕組み

3つの違いを表にすると、次のようになります。

| 学習方法 | 学習時に使う手掛かり | 代表的な目的 |
|---|---|---|
| 教師あり学習 | 正解ラベル | 分類・回帰 |
| 教師なし学習 | ラベルなしデータ | クラスタリング・構造発見 |
| 強化学習 | 行動に対する報酬 | より良い行動・方策の学習 |

### 教師あり学習

入力データと、その入力に対応する**正解ラベル**を使って学習します。

例えば、メールを「迷惑メール」「通常メール」に分類したい場合、過去のメールに正解ラベルを付けて学習させます。

```text
入力：メール本文
正解：迷惑メール / 通常メール
→ 教師あり学習
```

### 教師なし学習

正解ラベルを与えず、データの中にある似た特徴やまとまりを見つけます。

代表例はクラスタリングです。

```text
顧客データ
↓
特徴が似た顧客をグループ分け
→ 教師なし学習
```

### 強化学習

エージェントが環境の中で行動し、その結果として得られる**報酬**を手掛かりに学習します。

```text
状態
↓
行動
↓
報酬
↓
将来の報酬が大きくなる行動を学ぶ
```

教師あり学習の「正解ラベル」と、強化学習の「報酬」は同じではありません。

```text
正しい答えを直接与える
→ 教師あり学習

行動の良し悪しを報酬で評価する
→ 強化学習
```

このテーマはFEの基礎知識として扱います。さらに詳しく学びたい場合は、G検定向けの[教師あり・教師なし・強化学習の比較](/gk/supervised-unsupervised-reinforcement/)も参考になります。

個別に確認したい場合は、[教師あり学習](/gk/supervised-learning/)、[教師なし学習](/gk/unsupervised-learning/)、[強化学習](/gk/reinforcement-learning/)も参照できます。

公式の出題範囲やシラバスは、[IPA：基本情報技術者試験](https://www.ipa.go.jp/shiken/kubun/fe.html) から確認できます。

## 科目Aでどう出る？

科目Aでは、説明文から学習方法を選ぶ問題として出ることがあります。

### 正解データを示す

```text
正解データ
ラベル付きデータ
入力と正解の組
分類
回帰
```

と書かれていたら、**教師あり学習**を疑います。

### 正解を示さず、まとまりを見つける

```text
正解ラベルなし
グループ分け
クラスタリング
データ構造を発見
```

と書かれていたら、**教師なし学習**を疑います。

### 得点・報酬で行動を学ぶ

```text
行動
報酬
得点
試行錯誤
方策
```

と書かれていたら、**強化学習**を疑います。

### 選択肢を切る判断表

| 問題文の手掛かり | 判断 |
|---|---|
| 正解データを提示する | 教師あり学習 |
| 正解なしでクラスタリングする | 教師なし学習 |
| 行動に得点を与える | 強化学習 |
| ラベル付きデータで分類する | 教師あり学習 |
| 類似したデータをグループ化する | 教師なし学習 |

## 科目Bでどう使う？

科目Bでは、AIやデータサイエンスを題材にしたプログラムを読む場合があります。

そのときは、処理の詳細に入る前に、**学習データに何が含まれているか**を見ると理解しやすくなります。

```text
特徴量 + 正解ラベル
→ 教師あり学習の処理

特徴量だけ
→ 教師なし学習の可能性

状態・行動・報酬
→ 強化学習の処理
```

例えば、配列や表に「正解クラス」が一緒に格納されていれば、教師あり学習の処理である可能性が高くなります。

プログラムを追うときは、まず次の3点を確認します。

1. 入力データだけか
2. 正解ラベルも与えられているか
3. 行動後に報酬を受け取る処理があるか

この切り分けを先に行うと、後続の分類・クラスタリング・行動選択の処理を読みやすくなります。

## よくある誤解・混同

### 強化学習も正解を与えるから教師あり学習

違います。

強化学習では、通常は各行動に対して「この行動が正解」と直接ラベルを与えるわけではありません。

```text
正解を直接教える
→ 教師あり学習

報酬によって良し悪しを評価
→ 強化学習
```

### クラスタリングは分類だから教師あり学習

違います。

FEでは、**分類とクラスタリングを分ける**ことが重要です。

```text
あらかじめ決められたクラスへ分ける
→ 分類 → 教師あり学習

データからグループそのものを見つける
→ クラスタリング → 教師なし学習
```

### 教師なし学習は何も目的がない

違います。

正解ラベルがないだけで、データの構造やまとまり、特徴を見つけるという目的があります。

### 「教師」という人間が操作するかどうかで決まる

違います。

「教師あり」の教師とは、学習時に**正解ラベルが与えられている**という意味で考えると分かりやすいです。

## まとめ（試験直前用）

- 正解ラベルあり → 教師あり学習
- 正解ラベルなしで構造を探す → 教師なし学習
- 行動と報酬で学ぶ → 強化学習
- 分類・回帰 → 教師あり、クラスタリング → 教師なし
- 強化学習の報酬と教師あり学習の正解ラベルを混同しない

```text
ラベル → 教師あり
構造   → 教師なし
報酬   → 強化学習
```

> **FEでは「ラベル・構造・報酬」の3語でまず切り分ける。**
