## まず結論

この4つは、名前を暗記するより **「何を共有するか」「待機するか」「同じ処理を照合するか」** で切り分けます。

| キーワード | 選ぶもの |
|---|---|
| 複数CPUが主記憶を共有・単一OS | 密結合マルチプロセッサ |
| 各プロセッサ側が独立したOS・主記憶をもつ | 疎結合マルチプロセッサ |
| 主系が動き、待機系へ切り替える | デュプレックスシステム |
| 2系統で同じ処理を行い、結果を照合する | デュアルシステム |

特にFEでは、**「主記憶を共有」なら密結合**、**「同じ処理＋結果照合」ならデュアル**が強い判断材料です。

## 直感的な説明

4方式は、目的が少し違います。

「密・疎」は **プロセッサ同士の結び付き方**、「デュアル・デュプレックス」は **信頼性を高めるための二重化方式** と考えると整理しやすくなります。

## 定義・仕組み

### 密結合マルチプロセッサシステム

複数のプロセッサが **主記憶を共有**し、一般に一つのOSの管理下で処理を分担する構成です。

~~~text
CPU 1 ─┐
       ├─ 共通の主記憶
CPU 2 ─┘
        ↑
      単一OS
~~~

タスクを細かい単位で複数CPUへ割り当てやすいのが特徴です。

### 疎結合マルチプロセッサシステム

各プロセッサ側が **独立した主記憶やOS** をもち、通信や共有資源を介して連携する構成です。

~~~text
CPU 1 ─ 主記憶1 ─ OS 1
          │
        連携
          │
CPU 2 ─ 主記憶2 ─ OS 2
~~~

試験では、密結合との対比として **「主記憶を共有しない」「独立したOS」** が手掛かりになります。

### デュプレックスシステム

通常は主系が処理を行い、別の系統を待機させます。主系に障害が起きたときに待機系へ切り替えて処理を継続します。

~~~text
通常時
主系   → 稼働
待機系 → 待機

障害発生
主系   → 故障
待機系 → 切替えて稼働
~~~

**「待機」「故障時に切替」** が見えたらデュプレックスを考えます。

### デュアルシステム

2系統が **同じ処理を同時に実行し、結果を照合**する方式です。

~~~text
      同じ入力
       ↓   ↓
     系統A 系統B
       ↓   ↓
       結果照合
~~~

**「同じ処理」「結果を照合」** が決め手です。

## 科目Aでどう出る？

問題文では方式名を直接説明するより、構成や動作から方式を選ばせる形がよく使われます。

~~~text
主記憶を共有
→ 密結合

独立したOS・主記憶
→ 疎結合

待機系へ切替
→ デュプレックス

同じ処理＋結果照合
→ デュアル
~~~

長い選択肢でも、まずこのキーワードを探すと判断しやすくなります。

## どんな場面で使う？

密結合と疎結合は、複数のプロセッサやコンピュータを使って **処理能力を高めたり、処理を分散したりする構成**として考えます。

一方、デュアルとデュプレックスでは **障害に備えてシステムを二重化すること**が中心です。試験では、この「性能・分散」と「信頼性・二重化」の目的の違いも手掛かりになります。

## よくある混同

### 「CPUが2台ある」だけでは判断しない

複数のCPUや系統が登場しても、それだけで方式は決まりません。

- **主記憶を共有するか** → 密結合・疎結合
- **待機して切り替えるか** → デュプレックス
- **同じ処理をして照合するか** → デュアル

動作まで確認します。

### デュアルとデュプレックスを名前で覚えない

名前が似ているため、ここは暗記だけだと逆になりやすいところです。

**デュアル＝照合、デュプレックス＝待機・切替**

と動作で覚える方が安全です。

### 疎結合とデュプレックスは別の分類

疎結合はプロセッサ同士の結び付き方を表します。デュプレックスは障害時の継続運転を目的とした二重化方式です。

「複数のコンピュータがある」という共通点だけで同じ分類にしないようにします。

## まとめ

FE科目Aでは、次の4点を思い出せれば十分です。

- **主記憶共有・単一OS → 密結合**
- **独立したOS・主記憶 → 疎結合**
- **待機して障害時に切替 → デュプレックス**
- **同じ処理をして結果照合 → デュアル**

方式名ではなく、**共有・独立・待機・照合**の4語から選択肢を切るのがポイントです。
