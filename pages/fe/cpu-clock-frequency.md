## まず結論

**クロック周波数**は、CPUなどが処理のタイミングを合わせるために使うクロック信号が、**1秒間に何回繰り返されるか**を表します。

FEで内部クロックと外部クロックが出てきたら、まず**「クロックがどこで使われるか」**で切り分けます。

| 見分ける視点 | 内部クロック | 外部クロック |
|---|---|---|
| どこ？ | CPU内部 | CPUと外部との接続側 |
| 何の基準？ | CPU内部の動作 | 外部とのやり取り |
| 典型的な関係 | 外部クロックより高いことがある | 内部クロックの基準になる |
| 倍率がある問題 | **外部クロック × クロック倍率 = 内部クロック** | 倍率を掛ける側 |

> **CPUの中 → 内部クロック**  
> **CPUの外とのやり取り → 外部クロック**

同じ「クロック」でも、**どこを動かすクロックなのか**を見るのがポイントです。

## 直感的な説明

CPUを工場だと考えてみます。

工場の中では、機械が高速なテンポで作業しています。一方、工場の外から材料を受け取ったり、外へ製品を渡したりするときには、外部とのやり取りに合わせたテンポがあります。

```text
外部
  ↕
[ 外部クロック ]
  ↕
┌──────── CPU ────────┐
│                      │
│   [ 内部クロック ]    │
│      CPU内部で動作    │
│                      │
└──────────────────────┘
```

このイメージなら、

```text
CPUの中の速さ
→ 内部クロック

CPUの外とのやり取り側
→ 外部クロック
```

と切り分けられます。

たとえば、外部クロックが100MHz、クロック倍率が20倍なら、

```text
100MHz × 20 = 2,000MHz
              = 2GHz
```

となり、内部クロックは2GHzです。

## 定義・仕組み

クロックは、コンピュータ内部の処理タイミングを合わせるための周期的な信号です。

クロック周波数の単位にはHzを使います。

```text
1 Hz  = 1秒間に1回
1 MHz = 1秒間に100万回
1 GHz = 1秒間に10億回
```

### 内部クロック

内部クロックは、CPU内部の回路が動作するときの基準となるクロックです。

試験問題ではCPUの動作周波数として扱われることがあります。

### 外部クロック

外部クロックは、CPUと外部との接続側で使われるクロックです。

FEの典型的な問題では、外部クロックとクロック倍率からCPUの内部クロックを求めます。

```text
内部クロック
= 外部クロック × クロック倍率
```

たとえば、外部クロック200MHz、クロック倍率15倍なら、内部クロックは3,000MHz、つまり3GHzです。

ここでは、**内部クロックと外部クロックは同じ周波数とは限らない**ことが重要です。

なお、実際の現代CPUではクロック生成や外部インタフェースの仕組みはより複雑です。FEでは、問題文で与えられた外部クロックと倍率の関係を使って判断するのが基本です。

## 科目Aでどう出る？

科目Aでは、まず「何を求めているか」を確認します。

### 外部クロックと倍率から内部クロックを求める

```text
外部クロック × クロック倍率
→ 内部クロック
```

例として、外部クロック100MHz、倍率30倍なら、内部クロックは3,000MHz、つまり3GHzです。

### 内部クロックから外部クロックを求める

式を逆にします。

```text
外部クロック
= 内部クロック ÷ クロック倍率
```

内部クロック2.4GHz、倍率24倍なら、2,400MHz ÷ 24 = 100MHzです。

### MIPS・CPIの問題との切り分け

| 問題で聞かれていること | 考えるもの |
|---|---|
| CPU内部と外部のクロックの関係 | 内部クロック・外部クロック・倍率 |
| 1命令に何クロック必要か | CPI |
| 1秒間に何百万命令実行できるか | MIPS |
| 1クロックに何秒かかるか | クロック周期 |

つまり、

```text
クロックは「どこ？」
→ 内部クロック / 外部クロック

1命令に「何クロック？」
→ CPI

1秒に「何百万命令？」
→ MIPS
```

と問いを分けると判断しやすくなります。

MIPSとCPIの計算は、[MIPSとCPIとは？クロック数からCPU性能と実行時間を求める]({{ '/fe/mips/' | relative_url }})で詳しく整理しています。

## どんな場面で使う？

内部クロックと外部クロックの区別は、CPUの動作周波数やバスとの関係を理解するときに使います。

ただし、FE対策では現代CPUの詳細なクロック生成回路まで覚える必要はありません。

問題文に「内部クロック」「外部クロック」「クロック倍率」「○倍で動作する」といった表現が出たら、

```text
外部クロック
↓ × 倍率
内部クロック
```

という関係をまず確認します。

## よくある誤解・混同

### 内部クロックと外部クロックは同じ周波数だと思う

同じとは限りません。FEの問題では、クロック倍率を使って異なる周波数で動作する例が扱われます。

### 「内部」と「外部」を速い・遅いだけで覚える

典型的な問題では内部クロックの方が高い例がありますが、本質は大小関係ではありません。

**CPU内部で使うのか、CPUと外部との接続側で使うのか**という場所・役割で覚えます。

### クロック周波数が2倍なら必ず処理性能も2倍になると思う

クロック周波数だけでCPU性能がすべて決まるわけではありません。

1命令に必要なクロック数であるCPIや、CPUの構成、実行する命令なども性能に関係します。

### クロック周波数とクロック周期を混同する

クロック周波数が高いほど、1クロックにかかる時間は短くなります。

```text
クロック周期 = 1 ÷ クロック周波数
```

周波数と周期は逆数の関係です。

## まとめ（試験直前用）

- クロック周波数は、クロック信号が1秒間に何回繰り返されるか
- **CPU内部 → 内部クロック**
- **CPUと外部との接続側 → 外部クロック**
- FEの典型問題では **外部クロック × クロック倍率 = 内部クロック**
- 「どこのクロック？」なら内部・外部、「1命令に何クロック？」ならCPI、「1秒に何百万命令？」ならMIPS
- 内部クロックと外部クロックを、単純な速い・遅いだけで覚えない
