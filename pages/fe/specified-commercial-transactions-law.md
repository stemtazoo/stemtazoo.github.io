## まず結論

**特定商取引法（正式名称：特定商取引に関する法律）は、訪問販売や通信販売など、消費者トラブルが起こりやすい取引について事業者のルールを定め、消費者の利益を守る法律**です。

基本情報技術者試験の科目Aでは、次のように考えると判断しやすくなります。

> **「訪問販売・ネット通販・電話勧誘などの売り方や契約条件に問題がある」→ 特定商取引法を考える。**

ただし、**対象となる取引すべてにクーリング・オフが認められるわけではありません。** 特に通信販売との違いに注意しましょう。

## 直感的な説明

普段の買い物では、商品を比較したり、購入条件を確認したりできます。しかし、突然家に訪問されたり、電話で強く勧誘されたりすると、十分に検討できないまま契約してしまうことがあります。

また、ネット通販では、販売業者の情報や送料・返品条件が分かりにくいと、購入後にトラブルになる可能性があります。

特定商取引法は、こうした**取引の方法ごとに、事業者が守るべきルール**を定めています。

- 訪問販売なら、勧誘に先立つ事業者名や勧誘目的などの明示、契約書面などが重要です。
- 通信販売なら、販売価格や支払条件、返品条件などの広告表示が重要です。
- 一定の取引では、契約後でも定められた期間内にクーリング・オフできる仕組みがあります。

「消費者を守る法律」という言葉だけで覚えず、**どの販売方法に、どんなルールを設けるか**をイメージしましょう。

## 定義・仕組み

### 対象となる7つの取引類型

消費者庁の[特定商取引法ガイド](https://www.no-trouble.caa.go.jp/what/)では、次の7類型が示されています。

| 取引類型 | イメージ |
|---|---|
| 訪問販売 | 自宅などへ訪問して販売する。キャッチセールスなども含む |
| 通信販売 | 広告を見た消費者がネットや郵便などで申し込む（電話勧誘販売に当たるものを除く） |
| 電話勧誘販売 | 事業者が電話で勧誘して申込みを受ける |
| 連鎖販売取引 | 新たな販売員の勧誘を通じて組織を広げる取引 |
| 特定継続的役務提供 | 法律で定められた、一定期間・金額を超える継続的なサービスの取引 |
| 業務提供誘引販売取引 | 「仕事を提供する」などと誘い、仕事に必要な商品などの購入負担を求める取引 |
| 訪問購入 | 事業者が消費者の自宅などを訪ね、物品を買い取る取引 |

**訪問販売は事業者が「売りに来る」、訪問購入は事業者が「買い取りに来る」**という違いがあります。

### 事業者に求められるルール

取引類型によって詳細は異なりますが、代表的には次のような規制があります。

| 規制・ルール | 考え方 |
|---|---|
| 氏名・勧誘目的などの明示 | 消費者が誰から何を勧められているか分かるようにする |
| 不実告知・威迫などの禁止 | うその説明や、消費者を困惑させる勧誘を防ぐ |
| 広告表示の義務・誇大広告の禁止 | 価格や取引条件などを分かりやすく示し、誤認を防ぐ |
| 契約内容を記した書面等に関する規定 | 対象取引で契約内容を確認できるようにする |
| クーリング・オフなどの民事ルール | 条件を満たす取引で、契約の解除などを認める |

**すべての取引にすべての規制が同じ形で適用されるわけではありません。** 例えば、通信販売では広告表示や申込みの表示ルールが重要ですが、通常の通信販売に法定のクーリング・オフ制度はありません。

### クーリング・オフが使える取引・使えない取引

クーリング・オフは、法律で定められた条件と期間内で、消費者が契約の申込みの撤回や契約の解除をできる制度です。特定商取引法での代表的な期間は、次のとおりです。

| 取引類型 | 原則の期間 |
|---|---|
| 訪問販売・電話勧誘販売 | 8日間 |
| 特定継続的役務提供・訪問購入 | 8日間 |
| 連鎖販売取引・業務提供誘引販売取引 | 20日間 |
| 通信販売 | **法定のクーリング・オフ規定はない** |

期間の起算点や適用除外は取引類型・状況により異なります。通常は法律で定められた書面を受け取った日などが基準になり、単純に「注文した日から8日」とは判断できません。

なお、**通信販売でも返品が一切できないという意味ではありません。** 販売業者が定めた返品条件や、法律上の返品に関する規定などを別に確認します。詳しくは[消費者庁：通信販売](https://www.no-trouble.caa.go.jp/what/mailorder/)を参照してください。

## 科目Aでどう出る？

### まず「何を規制する法律か」を見極める

選択肢に複数の法律が並んだときは、法律名より先に**問題になっている行為や保護対象**を読み取ります。

| 問題になっていること | 関係が深い法律 |
|---|---|
| 訪問販売、通信販売、電話勧誘販売の取引ルール | **特定商取引法** |
| 消費者に対する不当な勧誘や不当な契約条項 | 消費者契約法 |
| 事業者によるカルテルや私的独占 | 独占禁止法 |
| 営業秘密の不正取得・使用など | 不正競争防止法 |
| 委託取引での受注側への不当な代金減額など | 中小受託取引適正化法（取適法） |

例えば、**ネット通販サイトの販売条件の表示**なら特定商取引法、**事業者間の価格カルテル**なら独占禁止法、というように対象を分けます。

関連するFE記事：[独占禁止法](/fe/antimonopoly-law/)・[取適法](/fe/toriteki-law/)。

### 「ネット通販だから8日以内なら必ずクーリング・オフ」は誤り

訪問販売と通信販売は同じ法律の対象ですが、クーリング・オフの扱いが違います。

```text
突然、自宅に訪問して販売
→ 訪問販売
→ 条件を満たせば原則8日間のクーリング・オフ

自分でネットショップを見て注文
→ 通信販売
→ 特定商取引法上のクーリング・オフ規定はない
```

取引類型を確認せずに「特定商取引法の対象なら必ず8日間」と覚えるのは避けましょう。

## どんな場面で使う？

### ECサイトの販売条件を確認するとき

ネットショップで購入する場面では、販売業者名や連絡先、販売価格、送料、支払方法、返品条件など、消費者が判断するために必要な情報が示されているかが重要です。

このような**販売条件の表示と消費者保護**が特定商取引法の話です。一方、インターネットを利用して売買する仕組みそのものは[EC（電子商取引）](/fe/electronic-commerce/)で説明しています。

### 電話で商品購入を勧められたとき

事業者から電話で勧誘され、その後に申込みをした場合は、申込み手段が郵便やインターネットであっても、取引の実態によっては電話勧誘販売に当たります。

**「インターネットから申し込んだら必ず通信販売」とは限りません。** どのように勧誘され、どの取引類型に該当するかを確認します。

## よくある誤解・混同

### 特定商取引法はネット通販だけを対象にする？

いいえ。通信販売のほかに、訪問販売・電話勧誘販売・訪問購入なども対象です。対象は7つの取引類型で整理しましょう。

### 通信販売で返品できないのは、クーリング・オフがないから？

同じことではありません。クーリング・オフとは別に、返品特約や通信販売に関する返品ルールがあります。「クーリング・オフ規定がない」ことと「どんな場合も返品不可能」は区別します。

### 消費者契約法と特定商取引法は同じ？

どちらも消費者保護に関わりますが、着目点が異なります。特定商取引法は**トラブルを生じやすい特定の取引方法**に対する規制が中心で、消費者契約法は**消費者契約における不当な勧誘や契約条項**などを扱います。同じ取引に両方が関係する場合もあります。

### 電子メール広告の話なら特定商取引法は関係ない？

そうとは限りません。通信販売の電子メール広告には、特定商取引法の規制が関係する場合があります。特定電子メール法の広告メール送信規制と重なる場面があるので、**販売方法のルールか、広告メール送信のルールか**を意識します。

## 確認問題（科目A・オリジナル）

ある事業者は、消費者向けのWebサイトで商品を販売している。特定商取引法についての説明として、最も適切なものはどれか。

- ア：通信販売は特定商取引法の対象外なので、販売条件の広告表示に関する規制はない。
- イ：通信販売も対象の取引類型だが、通常の通信販売には同法のクーリング・オフ規定はない。
- ウ：通信販売では、消費者が商品を受け取った日から必ず8日間、無条件でクーリング・オフできる。
- エ：特定商取引法は事業者間の価格カルテルを規制するための法律である。

**正解：イ**

- **ア：誤り。** 通信販売は特定商取引法の対象で、販売条件などの広告表示に関する規制があります。
- **イ：正しい。** 対象取引であることと、クーリング・オフ規定があることは別です。
- **ウ：誤り。** 通常の通信販売に法定のクーリング・オフ規定はありません。返品条件などは別に確認します。
- **エ：誤り。** カルテルなどの競争制限行為は、主に独占禁止法の問題です。

## まとめ（試験直前用）

- **特定商取引法は、訪問販売・通信販売などトラブルになりやすい取引で消費者を保護する法律。**
- 対象は訪問販売・通信販売・電話勧誘販売などの**7類型**。
- 事業者の勧誘・広告表示などのルールと、一定の取引におけるクーリング・オフなどを定める。
- **通信販売は対象取引だが、法定のクーリング・オフ規定はない。** 返品制度とは分ける。
- 競争の規制は独占禁止法、委託取引の受注側保護は取適法と区別する。
