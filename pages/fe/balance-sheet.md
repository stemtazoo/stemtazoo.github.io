## まず結論

貸借対照表（Balance Sheet：B/S）は、**ある時点で会社がどれだけの資産を持ち、その資産をどのように調達したかを表す財務諸表**です。

基本情報技術者試験では、勘定科目を一つずつ丸暗記するより、まず次の**3つの箱**に分けます。

<div class="bs-three-boxes">
  <div class="bs-box">
    <strong>資産</strong>
    <span>持っている・受け取れる</span>
    <small>現金、売掛金、投資有価証券など</small>
  </div>
  <div class="bs-box">
    <strong>負債</strong>
    <span>返す・支払う</span>
    <small>買掛金、借入金、社債など</small>
  </div>
  <div class="bs-box">
    <strong>純資産</strong>
    <span>出資・利益の蓄積</span>
    <small>資本金、利益剰余金など</small>
  </div>
</div>

貸借対照表では、次の関係が成り立ちます。

```text
資産 = 負債 + 純資産
```

試験中は、

> **もらえる → 資産 / 返す → 負債 / 出資 → 純資産**

を最初の判断基準にします。

## 直感的な説明

会社が100万円の現金を持っているとします。

ただし、その100万円がどこから来たのかによって、貸借対照表の右側が変わります。

銀行から100万円を借りた場合は、

```text
現金 100万円
→ 資産

借入金 100万円
→ 負債
```

です。

一方、株主が100万円を出資した場合は、

```text
現金 100万円
→ 資産

資本金 100万円
→ 純資産
```

です。

つまり貸借対照表は、

```text
左側：何を持っているか
        資産

右側：どこから調達したか
        負債 + 純資産
```

を見る表だと考えると分かりやすくなります。

## 定義・仕組み

### 資産

資産は、**会社が保有しているものや、将来お金を受け取る権利**です。

代表例は、

- 現金・預金
- 売掛金
- 商品
- 建物・土地
- 投資有価証券

などです。

FEでは、

```text
持っている
受け取れる
価値がある
```

という内容なら資産を疑います。

### 負債

負債は、**将来お金を支払ったり返済したりする義務**です。

代表例は、

- 買掛金
- 借入金
- 社債

などです。

FEでは、

```text
返す
支払う
返済義務がある
```

という内容なら負債です。

### 純資産

純資産は、**資産から負債を差し引いた部分**で、株主からの出資や会社内部に蓄積された利益などを表します。

代表例は、

- 資本金
- 資本剰余金
- 利益剰余金

などです。

```text
純資産 = 資産 - 負債
```

と考えることもできます。

## 科目Aでどう出る？

科目Aでは、勘定科目が貸借対照表のどこに分類されるかを問われます。

### まず3つの箱に入れる

| 勘定科目 | 分類 | 判断ポイント |
|---|---|---|
| 現金 | 資産 | 会社が保有している |
| 売掛金 | 資産 | 将来代金を受け取る権利 |
| 投資有価証券 | 資産 | 会社が保有する金融資産 |
| 買掛金 | 負債 | 将来支払う義務 |
| 借入金 | 負債 | 将来返済する義務 |
| 社債 | 負債 | 将来償還する義務 |
| 資本金 | 純資産 | 株主からの出資 |
| 利益剰余金 | 純資産 | 利益の内部蓄積 |

### 試験中の切り分け

```text
① 受け取れる・持っている？
   → 資産

② 返す・支払う？
   → 負債

③ 株主からの出資・利益の蓄積？
   → 純資産
```

この3段階でかなりの選択肢を切れます。

## 資本金と社債は「資金調達」でも違う

ここは今回のような問題で特に重要です。

資本金も社債も、会社が資金を集める方法なので、一見すると似ています。

しかし、判断するポイントは**返済義務**です。

<div class="bs-compare">
  <div>
    <strong>資本金</strong>
    <span>株主からの出資</span>
    <span>原則として返済義務なし</span>
    <b>→ 純資産</b>
  </div>
  <div>
    <strong>社債</strong>
    <span>社債を発行して資金調達</span>
    <span>将来、償還する</span>
    <b>→ 負債</b>
  </div>
</div>

つまり、

> **「会社がお金を集めた」だけでは分類できない。返すのか、出資なのかを見る。**

というのが試験での切り分けです。

## 資本金はなぜ資産ではない？

資本金は「会社のお金」に見えるため、資産と思ってしまいやすい項目です。

しかし、資本金は、

> **株主から会社へ出資された金額を、資金の調達元として表す項目**

です。

例えば、株主から80万円の出資を受けた場合、

```text
現金 80万円増加
→ 資産

資本金 80万円増加
→ 純資産
```

となります。

同じ取引でも、

```text
何を持っているか
→ 現金

どこから調達したか
→ 資本金
```

という別の意味で記録されます。

## どんな場面で使う？

貸借対照表を見ると、その会社の**ある時点での財政状態**を確認できます。

例えば、

- 現金をどれだけ持っているか
- 借入金がどれだけあるか
- 資産に対して負債がどの程度あるか
- 株主資本がどの程度あるか

などを確認できます。

FEでは財務分析を深く行うより、

```text
資産
負債
純資産
```

の意味と代表的な勘定科目を区別できることが重要です。

## よくある誤解・混同

### 売掛金は負債？

違います。

売掛金は、すでに売上が成立していて、

```text
将来代金を受け取る権利
→ 資産
```

です。

「まだお金がない」ことではなく、**これから受け取れる側か、支払う側か**を見ます。

### 買掛金と売掛金を混同する

```text
売掛金
→ 売った
→ お金をまだ受け取っていない
→ 資産

買掛金
→ 買った
→ お金をまだ支払っていない
→ 負債
```

と整理します。

### 資本金は現金だから資産？

違います。

出資で受け取った**現金は資産**ですが、**資本金はその調達元を示す純資産**です。

### 社債と投資有価証券はどちらも有価証券？

名前だけで判断しないようにします。

会社が自ら発行した社債は、

```text
将来償還する
→ 負債
```

です。

一方、他社の有価証券を投資目的で保有している場合は、

```text
会社が保有する
→ 投資有価証券
→ 資産
```

です。

### 負債はすべて悪いもの？

そうとは限りません。

負債は、借入金など外部から調達した資金を表します。

FEでは「良い・悪い」ではなく、**返済・支払義務があるか**で分類します。

## 確認問題（基本情報技術者試験対策）

貸借対照表の純資産の部に表示されるものはどれか。

- ア. 売掛金
- イ. 長期借入金
- ウ. 資本金
- エ. 投資有価証券

**正解：ウ**

- 売掛金：資産
- 長期借入金：負債
- 資本金：純資産

## まとめ（試験直前用）

- **もらえる・持っている → 資産**
- **返す・支払う → 負債**
- **出資・利益の蓄積 → 純資産**
- 売掛金・投資有価証券 → 資産
- 社債 → 負債
- 資本金 → 純資産
- **資産 = 負債 + 純資産**
- 資本金と社債はどちらも資金調達だが、**返済義務の有無**で切り分ける
