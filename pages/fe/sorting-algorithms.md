## まず結論

基本情報技術者試験でソートアルゴリズムを見分けるときは、**「何を基準に、どのように並べ替えるか」**を見ます。

まずは次の6つを押さえると、多くの選択肢を切れます。

```text
隣同士を比較して交換
→ バブルソート

一定間隔で取り出した部分列を整列
→ シェルソート

最小値を探して前へ移す
→ 選択ソート

整列済み部分の正しい位置へ入れる
→ 挿入ソート

基準値（ピボット）で小さい側・大きい側に分ける
→ クイックソート

順序木を作り、最大値・最小値を取り出す
→ ヒープソート
```

特にクイックソートは、**基準値を選んで分割する**という表現が決め手です。

## 直感的な説明

数字が書かれたカードを小さい順に並べる場面を考えます。

同じ「並べ替え」でも、やり方はそれぞれ違います。

| 方法 | 直感的なイメージ |
|---|---|
| バブルソート | 隣のカードと比べながら、順番が逆なら交換する |
| シェルソート | 離れた位置のカードを一定間隔でグループ化して先に整える |
| 選択ソート | 残っているカードから最小のものを探して前へ置く |
| 挿入ソート | 既に並んでいる部分の正しい位置へカードを差し込む |
| クイックソート | 基準のカードを決め、小さい組と大きい組に分ける |
| ヒープソート | 順序木を作り、最大値・最小値を順に取り出す |

試験ではアルゴリズム名そのものより、**説明文に出てくる動作**を拾うのがコツです。

## 定義・仕組み

### バブルソート

隣り合う二つの要素を比較し、順序が逆なら交換します。これを繰り返すことで、大きい値や小さい値が端へ少しずつ移動します。

判断キーワードは、**「隣り合う」「比較」「交換」**です。

### シェルソート

シェルソートは、要素を**一定間隔おきに取り出して部分列を作り、それぞれを整列**します。

その後、間隔を少しずつ狭めて同じ操作を繰り返し、最後は間隔を1にして整列させます。

判断キーワードは、**「一定間隔」「部分列」「間隔を狭める」**です。

```text
一定間隔で取り出す
↓
部分列ごとに整列
↓
間隔を狭める
↓
最後は間隔1
```

### 選択ソート

未整列部分から最小値（または最大値）を探し、先頭の要素と交換します。

判断キーワードは、**「最小値を探す」「未整列部分から選ぶ」**です。

### 挿入ソート

整列済み部分に新しい要素を一つずつ取り込み、正しい位置へ挿入します。

判断キーワードは、**「整列済み部分」「正しい位置へ挿入」**です。

### クイックソート

基準値（ピボット）を一つ選び、データを基準値より小さい側と大きい側に分割します。分割した各グループでも同じ処理を繰り返します。

```text
基準値を選ぶ
↓
小さい側 / 大きい側に分ける
↓
それぞれのグループでも同じ処理を行う
```

この「分割して、さらに同じ処理を繰り返す」という考え方は、[再帰処理とは？呼び出しと戻りを追う方法]({{ '/fe/recursion/' | relative_url }})にもつながります。

### ヒープソート

ヒープソートは、要素を**ヒープ（順序木）**に並べ、最大値または最小値を取り出して整列済み部分へ移す操作を繰り返します。

判断キーワードは、**「順序木」「ヒープ」「最大値・最小値を取り出す」**です。

```text
順序木を作る
↓
最大値・最小値を取り出す
↓
整列済み部分へ移す
↓
残りで繰り返す
```

探索アルゴリズムとの違いを確認したい場合は、[ブロック探索とは？平均比較回数を公式なしで求める方法]({{ '/fe/block-search-average-comparisons/' | relative_url }})も参考になります。

基本情報技術者試験の出題範囲は、[IPA：試験要綱・シラバスについて](https://www.ipa.go.jp/shiken/syllabus/index.html) で確認できます。

## 科目Aでどう出る？

科目Aでは、アルゴリズムの処理方法を文章で示し、該当する名称を選ばせる問題が典型です。

### まず「最初の動作」を見る

長い説明文を最初から最後まで細かく追うより、**どのような動作から始まっているか**を見ると切り分けやすくなります。

```text
隣り合うデータを比較する
→ バブルソート

一定間隔で部分列を作る
→ シェルソート

未整列部分から最小値を探す
→ 選択ソート

整列済み部分へ新しい値を入れる
→ 挿入ソート

基準値を選んで二つに分ける
→ クイックソート

順序木から最大値・最小値を取り出す
→ ヒープソート
```

「交換する」「繰り返す」という言葉だけでは判断できません。どのソートでも、交換や繰り返しが現れることがあります。

**何を比較するのか、何を探すのか、何を基準に分けるのか**まで見るのがポイントです。

| 問題文の手掛かり | 判断 |
|---|---|
| 隣り合うデータを比較・交換 | バブルソート |
| 一定間隔で取り出した部分列を整列 | シェルソート |
| 最小値・最大値を探す | 選択ソート |
| 整列済み部分の適切な位置に追加 | 挿入ソート |
| 基準値・ピボットで二つに分割 | クイックソート |
| 順序木から最大値・最小値を取り出す | ヒープソート |

特にクイックソートでは、**「基準値を選ぶ → 小さい側と大きい側に分ける → 分けたグループで同じ処理を行う」**という流れが強い判断材料になります。

## 科目Bではどうつながる？

科目Bでは、ソートの名前を選ぶだけでなく、疑似言語を見て配列の値がどう変わるかを追う問題につながります。

そのときも、まずは次のように処理の種類を見抜きます。

```text
隣接要素を順番に比較している
→ バブルソートの可能性が高い

一定間隔ごとに要素を取り出している
→ シェルソートの可能性が高い

未整列部分から最小値の位置を探している
→ 選択ソートの可能性が高い

前方の整列済み部分へ値を差し込んでいる
→ 挿入ソートの可能性が高い

基準値との大小で範囲を分けている
→ クイックソートの可能性が高い

木構造を使って最大値・最小値を取り出している
→ ヒープソートの可能性が高い
```

アルゴリズム名が分かると、**「次にどの値が動きそうか」**を予想しやすくなり、トレースもしやすくなります。

## どんな場面で使う？

ソートは、データを一定の順序に並べ、その後の検索や集計をしやすくするときに使います。

例えば、

- 数値を小さい順に並べる
- 名前を五十音順に並べる
- 日付を古い順・新しい順に並べる

といった処理です。

FEでは、実務でどのアルゴリズムを採用するかよりも、**処理手順を見てアルゴリズム名を判定する力**がまず重要です。

## よくある誤解・混同

### 「交換する」と書いてあればバブルソート

選択ソートでも要素の交換は行います。

バブルソートの決め手は、**隣り合う要素を比較すること**です。

### 「最小値を前へ移す」と「正しい位置へ挿入する」を混同する

```text
残り全体から最小値を探す
→ 選択ソート

一つの値を整列済み部分へ差し込む
→ 挿入ソート
```

と切り分けます。

### 一定間隔で分けるのはクイックソート？

違います。

```text
一定間隔で取り出して部分列を整列
→ シェルソート

基準値で大小に分ける
→ クイックソート
```

どちらも「分ける」処理がありますが、**間隔で分けるか、値の大小で分けるか**が違います。

### 順序木から最小値を取り出すのは選択ソート？

違います。

```text
未整列部分を直接調べて最小値を探す
→ 選択ソート

順序木・ヒープを使って最小値や最大値を取り出す
→ ヒープソート
```

「最小値を取り出す」という結果だけで決めず、**木構造を使っているか**を確認します。

### 「繰り返す」と書いてあればクイックソート

クイックソート以外のソートも処理を繰り返します。

クイックソートの決め手は、**基準値（ピボット）を選び、小さい側と大きい側へ分割すること**です。

### クイックソートは「高速なソート」という説明だけで選ぶ

名前に「クイック」とありますが、試験での決め手は速さではありません。

**基準値（ピボット）を選び、データを二つのグループに分割すること**が本質です。

### 基準値そのものが最終的な中央の値だと思う

ピボットは、データを分割するための基準として選ぶ値です。必ず中央値を選ぶという意味ではありません。

## まとめ（試験直前用）

- 隣同士を比較・交換 → **バブルソート**
- 一定間隔の部分列を整列 → **シェルソート**
- 最小値を探して前へ → **選択ソート**
- 整列済み部分の正しい位置へ入れる → **挿入ソート**
- 基準値（ピボット）で小さい側・大きい側に分割 → **クイックソート**
- 順序木から最大値・最小値を取り出す → **ヒープソート**
- 「交換」「繰り返す」だけでは決めず、**最初に何をしているか・何を使って分けるか**を見る
- 科目Bでは、この判断を使って**次にどの値が動くか**を予想する
