## まず結論

コードは、商品・部品・部署などを識別しやすくするために付ける記号や番号です。

基本情報技術者試験では、**コードの付け方が何を表しているか**を見れば、選択肢を切り分けられます。

| コード | 判断ワード | 例 |
|---|---|---|
| シーケンスコード | 連番・順番 | 0001、0002、0003 |
| デシマルコード | 10進数・階層分類 | 100→110→111 |
| ニモニックコード | 意味を連想できる | JP（日本）、PM（プロジェクトマネージャ） |
| ブロックコード | 区分ごとに番号範囲 | 営業部1000番台、企画部2000番台 |

> **連番ならシーケンス、階層ならデシマル、連想ならニモニック、番号範囲ならブロック。**

## 直感的な説明

会社で部品を管理する場面を考えます。

同じ部品でも、目的によってコードの付け方は変わります。

- 登録した順に `0001`、`0002` と付けたい → **シーケンス**
- 機械部品→締結部品→ボルトのように分類したい → **デシマル**
- `BLT` を見てボルトを連想できるようにしたい → **ニモニック**
- 機械部品は1000番台、電気部品は2000番台にしたい → **ブロック**

つまり、どの方式が常に優れているという話ではなく、**何をコードから読み取りたいか**が違います。

## 定義・仕組み

### シーケンスコード：登録順に番号を付ける

```text
1件目 → 0001
2件目 → 0002
3件目 → 0003
```

番号を重複させずに管理しやすい方法です。ただし、番号自体から部品の種類などは通常分かりません。

### デシマルコード：10進数で階層的に分類する

```text
100  技術分野
 └ 110  機械
    └ 111  機械設計
```

大分類から小分類へ、段階的に分類を細かくする方法です。

**「分類を掘り下げる」「10進分類」**という表現が判断の手掛かりになります。

※数字の例は説明用です。実際の桁の割り当て方はコード体系によって異なります。

### ニモニックコード：意味を連想できる記号を使う

```text
日本 → JP
アメリカ → US
プロジェクトマネージャ → PM
```

英字などの略号を使い、コードから対象を思い出しやすくします。

**Mnemonic** は「記憶を助ける」という意味です。英語の意味からも推測しやすい用語です。

なお、すべての英字コードがニモニックコードとは限りません。**コードの値と対象の意味に結び付きがあるか**で判断します。

### ブロックコード：区分ごとに番号の範囲を割り当てる

```text
1000～1999 → 営業部
2000～2999 → 企画部
3000～3999 → 開発部
```

部署や商品群などのグループごとに、使用できる番号の範囲を決めます。

**「1000番台」「区分ごとの番号範囲」**という表現が判断の手掛かりです。

## 科目Aでどう出る？

例えば、次のように問われます。

> コードの値からデータの対象物が連想できるものはどれか。

この場合、**「連想できる」**が決め手です。

正解は **ニモニックコード** です。

### 選択肢を切る順番

1. **値から意味が分かるか？** → ニモニックコード
2. **番号が順番に増えるか？** → シーケンスコード
3. **分類が階層的になっているか？** → デシマルコード
4. **グループごとに番号の範囲があるか？** → ブロックコード

## 科目Bでどう使う？

科目Bで識別コードを扱うプログラムを読む場合にも、コードの付け方を知っていると意図を推測しやすくなります。

例えば、次のPythonコードです。

```python
department_code = 2150

if 1000 <= department_code <= 1999:
    print("営業部")
elif 2000 <= department_code <= 2999:
    print("企画部")
else:
    print("その他")
```

出力は `企画部` です。

この例では、番号の範囲から部署を判定しています。**ブロックコードの考え方**です。

## よくある誤解・混同

### デシマルコードとブロックコードは同じ？

どちらも数字で分類できますが、着目点が異なります。

| 比較 | デシマルコード | ブロックコード |
|---|---|---|
| 中心となる考え方 | 階層的に分類する | 区分ごとに番号範囲を確保する |
| 判断ワード | 大分類・中分類・小分類 | 1000番台・2000番台 |
| 例 | 100→110→111 | 営業部1000～1999 |

**数字が使われているだけでは判断できません。** 分類の階層を表すのか、番号範囲を割り当てるのかを確認します。

### ニモニックコードは数字を使わない？

必ずしもそうとは限りません。重要なのは文字の種類ではなく、**コードから対象を連想できること**です。

### シーケンスコードとブロックコードは同じ？

シーケンスコードは順番に番号を付ける方式です。一方、ブロックコードは区分ごとに番号の範囲を割り当てます。ブロック内で連番を使う場合もあるため、**どの規則を問われているか**を読み取ります。

## 確認問題（FE試験対策）

ある会社では、機械部品に1000～1999、電気部品に2000～2999の番号を割り当てている。このコード方式として最も適切なものはどれか。

- ア. シーケンスコード
- イ. デシマルコード
- ウ. ニモニックコード
- エ. ブロックコード

- デシマル：階層的な分類

## まとめ（試験直前用）

- **連番** → シーケンスコード
- **階層分類** → デシマルコード
- **意味を連想** → ニモニックコード
- **番号範囲** → ブロックコード
- デシマルとブロックは「階層か、範囲か」で区別する
