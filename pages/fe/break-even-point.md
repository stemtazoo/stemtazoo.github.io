## まず結論

損益分岐点とは、**売上高と費用が等しくなり、利益がちょうど0になる地点**です。

基本情報技術者試験では、まず次の関係を押さえます。

```text
損益分岐点
→ 利益 = 0

したがって

売上高 = 固定費 + 変動費
```

損益分岐点売上高は、次の式でも求められます。

```text
損益分岐点売上高
= 固定費 ÷ (1 - 変動費率)
```

試験では式だけを暗記するより、**固定費や変動費率が下がれば、損益分岐点も下がる**と理解しておくと選択肢を切りやすくなります。

## 直感的な説明

例えば、お店を開くとします。

売上が0円でも、家賃などの固定費はかかります。商品が売れると、仕入れなどの変動費も増えます。

```text
売上が少ない
→ 費用を回収できない
→ 赤字

売上が増える
→ 費用をちょうど回収
→ 利益0 ← 損益分岐点

さらに売上が増える
→ 費用を上回る
→ 黒字
```

つまり損益分岐点は、**赤字から黒字へ切り替わる境目**です。

## 定義・仕組み

### 固定費

固定費は、売上高や販売量が変化しても、一定の範囲では大きく変わらない費用です。

例として、家賃や一定額の設備費などがあります。

### 変動費

変動費は、売上高や販売量に応じて増減する費用です。

例えば、商品の仕入費や材料費などです。

### 変動費率

変動費率は、売上高に対して変動費がどれくらいを占めるかを表します。

```text
変動費率 = 変動費 ÷ 売上高
```

売上高100万円、変動費60万円なら、変動費率は60%です。

### 損益分岐点で何が起きている？

利益は、

```text
利益 = 売上高 - 固定費 - 変動費
```

で考えられます。

損益分岐点では利益が0なので、

```text
0 = 売上高 - 固定費 - 変動費
```

したがって、

```text
売上高 = 固定費 + 変動費
```

となります。

ここが最も重要な意味です。

### 損益分岐点売上高の公式

変動費を、

```text
変動費 = 売上高 × 変動費率
```

とすると、

```text
売上高
= 固定費 + 売上高 × 変動費率
```

なので、

```text
損益分岐点売上高
= 固定費 ÷ (1 - 変動費率)
```

となります。

なお、`1 - 変動費率` は売上高のうち固定費の回収や利益に回せる割合です。

## 科目Aでどう出る？

科目Aでは、損益分岐点の意味や、固定費・変動費率が変化したときに損益分岐点がどう動くかを問われます。

### 固定費が変化する場合

変動費率が同じなら、

```text
固定費 ↓
→ 回収すべき固定費が減る
→ 損益分岐点 ↓

固定費 ↑
→ 回収すべき固定費が増える
→ 損益分岐点 ↑
```

### 変動費率が変化する場合

固定費が同じなら、

```text
変動費率 ↓
→ 売上から残る割合が増える
→ 固定費を早く回収できる
→ 損益分岐点 ↓
```

逆に変動費率が上がると、損益分岐点は上がります。

### 数値で確認する

固定費を100万円として比べます。

| 変動費率 | 損益分岐点売上高 |
|---:|---:|
| 20% | 125万円 |
| 50% | 200万円 |
| 80% | 500万円 |

変動費率が上がるほど、損益分岐点は大きくなります。

また、この表から分かるように、**変動費率と損益分岐点が単純に正比例するわけではありません**。

## どんな場面で使う？

損益分岐点分析は、どれだけ売れば赤字を脱して利益が出るのかを考えるときに使います。

例えば、

- 固定費を削減したら必要な売上はいくらになるか
- 材料費が上がったら損益分岐点はどう変わるか
- 販売価格を変更すると採算がどう変わるか

といった判断に利用できます。

FEでは実務上の細かな会計処理より、**売上・固定費・変動費・利益の関係**を読み取れることが重要です。

## よくある誤解・混同

### 変動費率が下がると損益分岐点が上がる

逆です。

変動費率が下がると、売上高から変動費を差し引いた後に残る割合が増えます。

そのため固定費を早く回収でき、損益分岐点は下がります。

### 固定費が下がると損益分岐点が上がる

これも逆です。

回収しなければならない固定費が減るので、より少ない売上で利益0に到達できます。

### 変動費率と損益分岐点は正比例する

損益分岐点売上高は、

```text
固定費 ÷ (1 - 変動費率)
```

なので、単純な正比例ではありません。

### 損益分岐点では売上高と固定費が等しい

変動費が0でない限り、これは誤りです。

損益分岐点では、

```text
売上高 = 固定費 + 変動費
```

です。

- [IPA：試験要綱・シラバスについて](https://www.ipa.go.jp/shiken/syllabus/gaiyou.html)

損益分岐点は、企業活動や会計・財務に関する知識とつながるテーマです。

試験対策では複雑な管理会計へ広げすぎず、

```text
利益0
→ 売上高 = 固定費 + 変動費

固定費 ↓
→ 損益分岐点 ↓

変動費率 ↓
→ 損益分岐点 ↓
```

という関係を優先して理解します。

## まとめ（試験直前用）

- 損益分岐点は、利益が0になる売上高
- 損益分岐点では「売上高 = 固定費 + 変動費」
- 損益分岐点売上高は「固定費 ÷ (1 - 変動費率)」
- 固定費が下がると、損益分岐点も下がる
- 変動費率が下がると、損益分岐点も下がる
- 変動費率と損益分岐点は単純な正比例ではない
- 公式を忘れたら「費用負担が軽くなるほど、黒字化に必要な売上も小さくなる」と考える
