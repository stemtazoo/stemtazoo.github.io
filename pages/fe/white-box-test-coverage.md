## まず結論

ホワイトボックステストの網羅基準では、**プログラム内部の処理や判定条件をどこまで通すか**を決めます。

基本情報技術者試験では、まず次の4つを切り分けられるようにすると強いです。

```text
すべての命令を少なくとも1回実行
→ 命令網羅

判定結果を真・偽の両方にする
→ 分岐網羅

各条件を真・偽の両方にする
→ 条件網羅

条件の真偽の全組合せを試す
→ 複合条件網羅
```

特に重要なのは、

```text
分岐網羅
→ 判定式「全体」の真・偽を見る

条件網羅
→ 判定式の中の「個々の条件」の真・偽を見る
```

という違いです。

## 直感的な説明

例えば、次の判定があるとします。

```text
A OR B
```

この判定結果は、

```text
真
または
偽
```

のどちらかになります。

分岐網羅では、AやBを個別に全部試すことが目的ではありません。

```text
A OR B 全体が真になるケース
A OR B 全体が偽になるケース
```

の両方を通せば、分岐網羅を満たします。

一方、条件網羅では、

```text
Aが真
Aが偽
Bが真
Bが偽
```

をそれぞれ少なくとも1回出す必要があります。

つまり、

```text
分岐網羅
→ 結果を見る

条件網羅
→ 中身を見る
```

と考えると分かりやすいです。

## 定義・仕組み

ホワイトボックステストは、プログラム内部の構造やロジックを意識して行うテストです。

代表的な網羅基準には、次のものがあります。

### 命令網羅

命令網羅は、**プログラム中のすべての命令を少なくとも1回は実行する**考え方です。

例えば、

```text
if 条件:
    命令A
命令B
```

がある場合、命令Aと命令Bの両方が一度は実行されるようにテストします。

ただし、条件の真・偽の両方を必ず試すとは限りません。

### 分岐網羅

分岐網羅は、**判定結果の真と偽を少なくとも1回ずつ実行する**考え方です。

例えば、

```text
if A OR B:
    命令
```

なら、

```text
A OR B = 真
A OR B = 偽
```

の両方を通します。

「判定条件網羅」や「判定網羅」と呼ばれることもあります。

### 条件網羅

条件網羅は、**判定式を構成する個々の条件が、それぞれ真と偽を少なくとも1回ずつ取るようにする**考え方です。

例えば、

```text
A OR B
```

なら、

```text
A = 真
A = 偽

B = 真
B = 偽
```

が必要です。

ただし、この条件を満たしても、判定式全体が真・偽の両方になるとは限りません。

### 複合条件網羅

複合条件網羅は、**個々の条件の真偽の組合せをすべて試す**考え方です。

AとBの2条件なら、

```text
A=偽, B=偽
A=偽, B=真
A=真, B=偽
A=真, B=真
```

の4通りをすべて試します。

条件数が増えるほど、必要なテストケース数も増えます。

## 科目Aでどう出る？

科目Aでは、論理式とテストケースの組合せから、どのケースが網羅基準を満たすかを判断する問題が出ます。

### OR条件を例にする

判定式が、

```text
A OR B
```

なら、真理値表は次のとおりです。

| A | B | A OR B |
|---|---|---|
| 偽 | 偽 | 偽 |
| 偽 | 真 | 真 |
| 真 | 偽 | 真 |
| 真 | 真 | 真 |

### 分岐網羅なら何を見る？

分岐網羅では、

```text
A OR B = 偽
A OR B = 真
```

の両方が必要です。

例えば、

```text
A=偽, B=偽
→ 偽

A=真, B=真
→ 真
```

の2ケースがあれば、判定全体の真・偽を両方通せます。

### 条件網羅なら何を見る？

条件網羅では、AとBそれぞれが真・偽になるかを見ます。

例えば、

```text
A=偽, B=真
A=真, B=偽
```

なら、

```text
A
→ 偽と真

B
→ 真と偽
```

の両方を満たします。

ただし、この2ケースでは、

```text
偽 OR 真 = 真
真 OR 偽 = 真
```

なので、判定結果はどちらも真です。

つまり、**条件網羅を満たしていても分岐網羅を満たさない場合があります。**

ここが重要なひっかけです。

## どんな場面で使う？

ホワイトボックステストの網羅基準は、プログラム内部のロジックをどこまでテストしたかを確認するときに使います。

例えば、

- if文の真・偽を両方試したか
- 各条件が真・偽になったか
- すべての命令を実行したか
- 条件の組合せを十分試したか

などを確認します。

網羅度を高めるほど、見落としを減らしやすくなりますが、テストケース数も増えるため、目的に応じて基準を選びます。

## よくある誤解・混同

### 分岐網羅と条件網羅は同じ？

違います。

```text
分岐網羅
→ 判定式全体の真・偽

条件網羅
→ 個々の条件の真・偽
```

です。

### AとBをそれぞれ真・偽にすれば分岐網羅？

必ずしもそうではありません。

例えば、

```text
A=偽, B=真
A=真, B=偽
```

では、AもBも真・偽になります。

しかし、

```text
偽 OR 真 = 真
真 OR 偽 = 真
```

なので、判定結果はどちらも真です。

この場合、条件網羅は満たしますが、分岐網羅は満たしません。

### 分岐網羅では全組合せが必要？

必要ありません。

全組合せを試すのは複合条件網羅です。

AとBの2条件なら、

```text
偽・偽
偽・真
真・偽
真・真
```

の4通りすべてを試すのが複合条件網羅です。

### 命令網羅ができれば分岐網羅もできる？

必ずしもできません。

ある分岐の一方だけを通っても、すべての命令を実行できる場合があります。

したがって、

```text
命令を全部通した
≠
分岐の真・偽を両方通した
```

です。

## 確認問題（基本情報技術者試験対策）

判定式が `A OR B` である。分岐網羅を満たすテストケースの組合せとして、最も適切なものはどれか。

- ア. A=偽, B=真 の1ケースだけ
- イ. A=偽, B=真 と A=真, B=偽
- ウ. A=偽, B=偽 と A=真, B=真
- エ. A=偽, B=真 と A=真, B=偽 と A=真, B=真

<details markdown="1">
<summary>▶ クリックして答えと解説を見る（ここを開く）</summary>

**正解：ウ**

分岐網羅では、判定式 `A OR B` 全体が真になる場合と偽になる場合を少なくとも1回ずつ通す必要があります。

```text
A=偽, B=偽
→ 偽

A=真, B=真
→ 真
```

となるため、分岐の真・偽を両方通せます。

</details>

## まとめ（試験直前用）

- 命令網羅：すべての命令を少なくとも1回実行
- 分岐網羅：判定式全体を真・偽の両方にする
- 条件網羅：個々の条件を真・偽の両方にする
- 複合条件網羅：条件の真偽の全組合せを試す
- **分岐網羅は「判定全体」、条件網羅は「個々の条件」を見る**
- 条件網羅を満たしても、分岐網羅を満たすとは限らない
- **A OR B なら真理値表を書いて考えると安全**
