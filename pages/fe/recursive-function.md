## まず結論

**再帰関数**は、関数の中で自分自身を呼び出す関数です。

試験では、次の3点を確認します。

```text
自分自身を呼び出す
→ 再帰関数

再帰を止める条件
→ 終了条件

引数が終了条件へ近づく
→ 正常に終了できる
```

再帰問題は、終了条件まで式を展開してから戻り値を計算します。

## 直感的な説明

再帰は、階段を一段ずつ下りるイメージです。

```text
5段目
↓
4段目
↓
3段目
↓
2段目
↓
1段目で停止
```

一番下まで進んだら、結果を逆向きに戻しながら計算します。

例えば、次の関数を考えます。

```text
f(n):
  n ≦ 1 なら1を返す
  それ以外なら n + f(n - 1) を返す
```

`f(5)`は次のように展開できます。

```text
f(5)
= 5 + f(4)
= 5 + 4 + f(3)
= 5 + 4 + 3 + f(2)
= 5 + 4 + 3 + 2 + f(1)
= 5 + 4 + 3 + 2 + 1
= 15
```

## 定義・仕組み

### 再帰関数に必要な二つの部分

再帰関数には、基本的に次の二つが必要です。

#### 終了条件

```text
n ≦ 1 なら1を返す
```

これ以上、自分自身を呼び出さない条件です。

#### 再帰処理

```text
n + f(n - 1)
```

問題を少し小さくして、自分自身をもう一度呼び出します。

```text
終了条件
→ 再帰を止める

再帰処理
→ 問題を小さくして続ける
```

### 呼出しと戻り値の流れ

再帰関数では、まず呼出しが深く進みます。

```text
f(5)
→ f(4)
→ f(3)
→ f(2)
→ f(1)
```

`f(1)`で終了条件に到達すると、結果が逆向きに戻ります。

```text
f(1) = 1
f(2) = 2 + 1 = 3
f(3) = 3 + 3 = 6
f(4) = 4 + 6 = 10
f(5) = 5 + 10 = 15
```

### スタックとの関係

関数を呼び出すたびに、処理途中の情報がスタックへ積まれます。

```text
呼出し
→ 後から呼んだ関数が上に積まれる

戻り
→ 後から呼んだ関数から先に戻る
```

これは、スタックの後入れ先出し（LIFO）という性質です。

## 科目Aでどう出る？

科目Aでは、次の内容が問われます。

- 再帰関数の定義
- 終了条件
- 引数の変化
- 戻り値の計算
- 無限再帰になる条件

解く順番は次のとおりです。

```text
1. 終了条件を探す
2. 引数がどう変化するか確認する
3. 終了条件まで展開する
4. 戻り値を逆順に計算する
```

### 合計と階乗の切り分け

演算子を必ず確認します。

```text
n + f(n - 1)
→ 1からnまでの合計

n × f(n - 1)
→ 階乗
```

例えば、

```text
5 + 4 + 3 + 2 + 1
→ 15

5 × 4 × 3 × 2 × 1
→ 120
```

となります。

## 科目Bでどう使う？

科目Bでは、再帰関数の擬似言語を追跡するときに使います。

確認するポイントは次のとおりです。

- どの条件で再帰が止まるか
- 引数が呼出しごとにどう変わるか
- 呼出しが何段まで深くなるか
- 戻り値がどの順番で計算されるか

表にすると追跡しやすくなります。

| 呼出し | 引数 | 次の処理 |
|---|---:|---|
| `f(5)` | 5 | `5 + f(4)` |
| `f(4)` | 4 | `4 + f(3)` |
| `f(3)` | 3 | `3 + f(2)` |
| `f(2)` | 2 | `2 + f(1)` |
| `f(1)` | 1 | `1を返す` |

終了条件へ到達したら、下から上へ戻り値を計算します。

## よくある誤解・混同

### `f(1)`でも再帰呼出しを続ける

終了条件が`n ≦ 1`なら、`f(1)`はその場で終了します。

```text
f(1) = 1
```

であり、`1 + f(0)`ではありません。

### 終了条件を確認しない

再帰関数では、最初に終了条件を探します。

```text
終了条件
引数の変化
終了条件へ近づくか
```

この3点を確認します。

### 合計と階乗を混同する

`+`と`×`を読み違えないことが重要です。

### 再帰関数は必ず無限に続く

終了条件があり、引数がその条件へ近づけば終了します。

```text
f(n - 1)
→ nが小さくなる
→ 終了条件へ近づく
```

一方、引数が変わらなかったり、終了条件から遠ざかったりすると無限再帰になります。

## まとめ（試験直前用）

- 自分自身を呼び出す関数が再帰関数
- 再帰を止める条件が終了条件
- 引数が終了条件へ近づくか確認する
- 終了条件まで展開し、逆順に戻り値を計算する
- `+`なら合計、`×`なら階乗になりやすい

一言で覚えるなら、

> **再帰問題は、終了条件まで展開してから戻り値を計算する。**
