## まず結論

ガントチャートとは、**作業項目を縦軸、時間を横軸に取り、各作業の開始・終了や期間を横棒で表す工程管理図表**です。

基本情報技術者試験では、次の表現が出たらガントチャートを疑います。

```text
作業開始・終了
予定と実績
時間軸
横棒
```

覚える一文はこれです。

> **開始・終了を横棒で見る → ガントチャート**

## 直感的な説明

ガントチャートは、**「いつ、どの作業を行うのか」を横棒で並べた予定表**と考えると分かりやすいです。

例えば、次のように表します。

```text
          1週  2週  3週  4週  5週
要件定義  ████
設計          ███████
実装              ████████
テスト                    ████
```

横棒を見るだけで、

- いつ作業が始まるか
- いつ終わるか
- どの作業が同時に進んでいるか
- 予定より遅れていないか

を把握できます。

## 定義・仕組み

ガントチャートでは、基本的に次のように読みます。

| 要素 | 意味 |
|---|---|
| 縦軸 | 作業項目・工程 |
| 横軸 | 日・週・月などの時間 |
| 横棒 | 作業期間 |
| 棒の左端 | 作業開始 |
| 棒の右端 | 作業終了 |
| 予定と実績の2本の棒 | 計画との差を確認 |

例えば、計画と実績を並べると、進捗の遅れを視覚的に確認できます。

```text
計画  ███████
実績    ███████
       ↑
    開始が遅れている
```

このように、ガントチャートは**時間軸上で作業の予定と実績を見比べる**ことに向いています。

一方で、作業同士の細かな依存関係やクリティカルパスを分析するには、[アローダイアグラム](/fe/arrow-diagram/)の方が適しています。

## 科目Aでどう出る？

科目Aでは、ガントチャートの特徴を、ほかの工程管理手法と比較して選ばせる問題が出ます。

### 判断の軸

まず、問題文が何を見たいのかを確認します。

```text
作業開始・終了の予定と実績
→ ガントチャート

重要な節目・期日
→ マイルストーン

作業の順序・依存関係・余裕日数
→ アローダイアグラム

進捗とコストを定量管理
→ EVM
```

### 比較表

| 用語 | 何を見る？ | 判断キーワード |
|---|---|---|
| ガントチャート | 作業期間・開始・終了 | 横棒、時間軸、予定と実績 |
| マイルストーン | 重要な節目 | 期日、完了点、重要イベント |
| アローダイアグラム | 作業順序・依存関係 | 矢印、所要日数、余裕日数、クリティカルパス |
| EVM | 進捗とコスト | PV、EV、AC、費用、進捗 |

試験中は、次のように切ると迷いにくいです。

> **「いつやるか」ならガント、「どの順番か」ならアロー**

EVMについては、[EVMとは？EV・PV・ACで進捗とコストを判断する方法](/fe/evm/)で整理しています。

## どんな場面で使う？

### プロジェクトのスケジュール確認

各作業の開始日と終了日を並べることで、全体の日程を確認できます。

```text
要件定義
↓
設計
↓
実装
↓
テスト
```

といった工程を、時間軸に沿って見せられます。

### 予定と実績の比較

計画した開始・終了と、実際の開始・終了を並べれば、遅延が分かります。

```text
予定：████████
実績：  ████████
```

実績の棒が右にずれていれば、開始や終了が遅れている可能性があります。

### 並行作業の把握

複数の作業が同時に進んでいるかどうかも、横棒の重なりから確認できます。

```text
作業A  ███████
作業B     ███████
作業C         ████
```

## よくある誤解・混同

### 誤解1：ガントチャートでクリティカルパスを求める

ガントチャートでも作業の期間は見えますが、**作業の依存関係や最長経路を分析するのはアローダイアグラムの方が適しています。**

```text
期間を見る
→ ガントチャート

依存関係・最長経路を見る
→ アローダイアグラム
```

### 誤解2：マイルストーンと同じ

マイルストーンは、作業期間そのものではなく**重要な節目や期日**を表します。

```text
要件定義完了
設計完了
リリース日
```

のような重要なポイントです。

ガントチャートは、各作業がどの期間に実施されるかを横棒で表します。

### 誤解3：EVMと同じ

違います。

```text
ガントチャート
→ 作業期間と進捗を時間軸で見る

EVM
→ 進捗とコストを数値で管理する
```

ガントチャートでは、PV・EV・ACのような指標を使ってコストを管理するわけではありません。

### 誤解4：横棒が長いほど重要な作業

横棒の長さは、基本的に**作業期間の長さ**を表します。

重要度を表しているわけではありません。

```text
棒が長い
→ 長期間の作業

棒が短い
→ 短期間の作業
```

## まとめ（試験直前用）

- ガントチャートは、作業項目を縦軸、時間を横軸に取る
- 各作業の開始・終了・期間を横棒で表す
- 予定と実績を並べて進捗を確認できる
- 並行している作業も視覚的に分かる
- 重要な節目はマイルストーン
- 作業順序・依存関係・余裕日数はアローダイアグラム
- 進捗とコストを定量管理するのはEVM

覚える一文はこれです。

> **開始・終了を横棒で見る → ガントチャート**
