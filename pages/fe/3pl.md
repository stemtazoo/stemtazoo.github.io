## まず結論

**3PL（Third Party Logistics：サードパーティ・ロジスティクス）**は、荷主企業に代わって、第三者の事業者が**物流戦略の企画や物流システムの構築・運営を包括的に受託する**形態です。

基本情報技術者試験では、次の言葉を手掛かりにします。

~~~text
物流を外部へ任せる
＋
物流の企画・改善まで担う
↓
3PL
~~~

単に「荷物を運ぶ会社」と覚えるのではなく、**物流をまとめて任される**ところがポイントです。

## 直感的な説明

あるメーカーが物流を自社で管理するとします。

~~~text
メーカー
├─ 運送会社を手配
├─ 倉庫を管理
├─ 在庫を管理
├─ 流通加工を管理
└─ 物流全体を改善
~~~

これらを個別に管理するのではなく、物流の専門事業者にまとめて任せるのが3PLのイメージです。

~~~text
荷主企業
   ↓
物流をまとめて任せる
   ↓
3PL事業者
├─ 輸送
├─ 保管
├─ 流通加工
└─ 物流の企画・改善
~~~

「物流作業の一部を外注する」だけでなく、**物流全体をどう効率化するかという企画まで受託する**点を押さえます。

## 定義・仕組み

国土交通省は3PLについて、荷主企業に代わって物流事業者などが効率的な物流戦略の企画立案や物流システムの構築を包括的に受託し、実施するものとして説明しています。

3PLでは、荷主企業と3PL事業者の役割を次のように考えます。

~~~text
荷主企業
→ 商品や事業そのものに集中

3PL事業者
→ 物流の企画
→ 輸送
→ 保管
→ 流通加工
→ 物流システムの運営・改善
~~~

実際のサービス範囲は契約によって異なりますが、試験では**「物流＋企画を第三者へ包括的に任せる」**という軸で判断します。

## 科目Aでどう出る？

3PLは、SCMやEMSなど似た用語と並べて出題されることがあります。

| 用語 | 何をする？ | 判断の手掛かり |
|---|---|---|
| **3PL** | 物流を包括的に受託 | 物流、アウトソーシング、物流企画 |
| **SCM** | 供給連鎖全体を最適化 | 購買、生産、販売、物流、企業間、全体最適 |
| **EMS** | 電子機器などの製造を受託 | 設計、資材調達、生産、電子・電機 |
| 物流管理 | 物流活動を総合的に管理 | 調達、保管、輸送、在庫などの管理 |

### 3PLとSCM

最も混同しやすい組合せです。

~~~text
SCM
→ サプライチェーン全体を最適化する考え方

3PL
→ 荷主から物流業務を包括的に受託する形態
~~~

「購買・生産・販売・物流を企業間で全体最適」という説明ならSCMを疑います。

「荷主に代わって物流を受託し、物流企画も行う」なら3PLです。

### 3PLとEMS

どちらも外部企業への委託が関係しますが、**何を任せるか**が違います。

~~~text
3PL
→ 物流

EMS
→ 電子機器などの設計・調達・生産
~~~

「アウトソーシング」という言葉だけで判断せず、対象を確認します。

## どんな場面で使う？

荷主企業が物流を自社だけで運営すると、倉庫、輸送、在庫管理などの設備・人材・ノウハウが必要になります。

3PLを利用すると、物流の専門事業者の設備やノウハウを活用しながら、物流全体の効率化を図ることができます。

~~~text
荷主企業
↓
物流を専門事業者へ包括的に委託
↓
物流コストや業務の改善を目指す
↓
荷主は本来の事業へ集中しやすくなる
~~~

試験ではメリットの細かな暗記より、**荷主と物流事業者の役割分担**を理解しておくことが重要です。

## よくある誤解・混同

### 誤解1：3PLは単なる運送会社

3PLのポイントは運送だけではありません。

物流戦略の企画、保管、流通加工、配送管理などを含め、物流を包括的に受託する点が重要です。

### 誤解2：物流が出てきたら全部3PL

違います。

~~~text
物流を含む供給連鎖全体の最適化
→ SCM

物流そのものを第三者へ包括的に委託
→ 3PL
~~~

「物流」という単語ではなく、**誰が何をするのか**を見ます。

### 誤解3：外部委託なら3PL

違います。

電子機器の設計や製造を外部企業が受託するならEMSなど、対象によって用語が変わります。

~~~text
何を外部に任せる？

物流
→ 3PL

電子機器などの製造
→ EMS
~~~

### 誤解4：3PLでは物流企画を荷主だけが行う

3PLでは、物流事業者側が荷主に代わって物流戦略の企画立案や物流システムの構築まで包括的に受託することがあります。

**物流企画まで代行する**という表現は、試験で3PLを見抜く強い手掛かりです。

## まとめ（試験直前用）

- **3PL** → 荷主に代わって物流を包括的に受託し、物流企画まで担う
- **SCM** → 購買・生産・販売・物流など供給連鎖全体を最適化する
- **EMS** → 電子機器などの設計・調達・生産を受託する

迷ったら、

~~~text
何を任せる？

物流＋物流企画
→ 3PL

電子機器の設計・生産
→ EMS

何を全体最適する？

企業をまたぐ供給連鎖
→ SCM
~~~

と切り分けます。
