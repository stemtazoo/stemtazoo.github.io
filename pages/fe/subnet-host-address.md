## まず結論

IPv4のサブネットでは、通常、ホスト部が**すべて0**のアドレスはネットワークアドレス、**すべて1**のアドレスはブロードキャストアドレスです。

FEの科目Aでは、PCに割り当てられないIPアドレスを問われたら、まずこの2つを探します。

~~~text
ホスト部が全部0
→ ネットワークアドレス

ホスト部が全部1
→ ブロードキャストアドレス

その間
→ ホストに割り当て可能
~~~

## 直感的な説明

サブネットを「住所の区画」と考えると分かりやすくなります。

例えば、あるサブネットが末尾 **16〜31** の範囲なら、

**最初と最後は特別な用途、PCが使えるのはその間**と考えると判断しやすくなります。

## 定義・仕組み

IPv4アドレスは、サブネットマスクによって**ネットワーク部**と**ホスト部**に分けられます。

例えば、

~~~text
IPアドレス       200.170.70.16
サブネットマスク 255.255.255.240
~~~

とします。

255.255.255.240 の最後の8ビットは、

~~~text
240 = 11110000
~~~

なので、ネットワーク部は28ビット、ホスト部は4ビットです。

~~~text
255.255.255.240 = /28
ホスト部 = 4ビット
~~~

### ホスト部4ビットなら16個

4ビットで表せる組合せは 2の4乗、つまり16個です。

~~~text
0〜15
16〜31
32〜47
48〜63
64〜79
...
~~~

16〜31の区画なら、

~~~text
16 = ネットワークアドレス
17〜30 = ホストに割り当て可能
31 = ブロードキャストアドレス
~~~

となります。

2進数で見ると、

~~~text
16 → 00010000
          0000 ← ホスト部が全部0

31 → 00011111
          1111 ← ホスト部が全部1
~~~

です。

## 科目Aでどう出る？

科目Aでは、IPアドレスとサブネットマスクから「ホストに割り当てられないアドレス」を選ばせる形が典型です。

毎回すべてを2進数へ変換しても解けますが、**ブロックサイズ**を使うと速く判断できます。

<div class="subnet-steps">
<div class="subnet-step"><strong>① ブロックサイズ</strong><br>256 − 240 = 16</div>
<div class="subnet-step"><strong>② 区画を探す</strong><br>0, 16, 32, 48 ...</div>
<div class="subnet-step"><strong>③ 両端を見る</strong><br>16 と 31 は割当不可</div>
</div>

サブネットマスクの対象オクテットが240なら、

~~~text
256 - 240 = 16
~~~

なので16刻みです。

ネットワークアドレスが末尾16なら、次のネットワークアドレスは32です。

~~~text
現在のネットワーク：16
次のネットワーク：32

ブロードキャスト
= 次のネットワーク - 1
= 31
~~~

### 試験中の最短手順

~~~text
① 256 - サブネットマスクの値
   → ブロックサイズ

② ネットワークアドレスから次の区切りを探す

③ 最初
   → ネットワークアドレス

④ 次の区切り - 1
   → ブロードキャストアドレス

⑤ その間
   → PCに割り当て可能
~~~

### 2つのIPアドレスが同じサブネットかを判断する

**2つのIPアドレスに同じサブネットマスクを適用し、ネットワークアドレスが一致するなら同じサブネット**です。

例えば、マスクが `255.255.255.240`（`/28`）のとき、次の2台を比べます。

- `192.168.10.19`
- `192.168.10.27`

この例では先頭3オクテットが共通なので、末尾の範囲を調べれば十分です。

~~~text
256 - 240 = 16 → 16個刻み

末尾  0〜15  ：192.168.10.0/28
末尾 16〜31  ：192.168.10.16/28 ← 19 と 27 はここ
末尾 32〜47  ：192.168.10.32/28
~~~

**19も27も16〜31に入るため、同じサブネット**です。一方、末尾31と32は数値が隣同士でも異なるサブネットです。

| 末尾の値 | ネットワークアドレス | 同じサブネット？ |
|---|---|---|
| 19 と 27 | 両方 `192.168.10.16` | 同じ |
| 14 と 19 | `192.168.10.0` と `192.168.10.16` | 異なる |
| 31 と 32 | `192.168.10.16` と `192.168.10.32` | 異なる |

仕組みを確かめたいときは**IPアドレスとサブネットマスクのAND演算**を使います。末尾19と27の場合は次のとおりです。

~~~text
19  = 00010011
27  = 00011011
240 = 11110000
      --------
AND = 00010000  （両方とも16）
~~~

この**16個刻みの計算法は、今回のように先頭3オクテットが共通で、マスクが /28 の場合の近道**です。別のマスクや第3オクテットまで変化する場合は、対象のビットを含めてネットワークアドレスを求めます。詳しくは[CIDRとネットワーク・ブロードキャストアドレス](/fe/cidr-network-broadcast-address/)で確認できます。

なお、**同じサブネットに属すること**と、**個々のIPアドレスをPCに割り当てられること**は別の判定です。例えば `192.168.10.31` は `192.168.10.16/28` に属しますが、通常はブロードキャストアドレスなのでPCには割り当てません。

#### 確認問題（オリジナル）

2台の機器に同じサブネットマスク `255.255.255.240` を設定しました。次のうち**同じサブネットに属する**組合せはどれでしょうか。

- A：`10.20.5.15` と `10.20.5.18`
- B：`10.20.5.34` と `10.20.5.46`
- C：`10.20.5.47` と `10.20.5.48`

<details markdown="1">
<summary>答えと解説を見る</summary>

**正解：B**

`/28` は16個刻みで、末尾32〜47が同じサブネットです。したがって34と46は、どちらも `10.20.5.32/28` に属します。

Aは0〜15と16〜31、Cは32〜47と48〜63に分かれます。**数値が近いかどうかではなく、同じ区間に入るか**を確認しましょう。

</details>

## どんな場面で使う？

サブネット化では、一つのIPv4ネットワークを複数の小さなネットワークに分割します。

FEでは実際のネットワーク設計よりも、

- サブネットマスクからホスト部のビット数を読む
- アドレス範囲を求める
- ネットワークアドレスとブロードキャストアドレスを除外する

という計算・判断が重要です。

このテーマは基本情報技術者試験のネットワーク分野に関係します。公式の出題範囲やシラバスは、[IPA：基本情報技術者試験](https://www.ipa.go.jp/shiken/kubun/fe.html) から確認できます。

## よくある誤解・混同

### 誤解1：ネットワークアドレスだけ割り当て不可

ブロードキャストアドレスも通常のホストには割り当てません。

~~~text
最初 → ネットワークアドレス
最後 → ブロードキャストアドレス
~~~

**両端を除く**と覚えます。

### 誤解2：/28ならホストを16台使える

ホスト部は4ビットなのでアドレス総数は16個ですが、通常のサブネットではネットワークアドレスとブロードキャストアドレスを除きます。

~~~text
16個 - 2個 = 14個
~~~

したがって、通常のホストとして使えるのは14個です。

### 誤解3：255.255.255.240の「240」をそのまま範囲に使う

240はサブネットマスクの値です。アドレスの区切りを素早く求めるときは、

~~~text
256 - 240 = 16
~~~

として、**16刻み**だと判断します。

### 誤解4：全部2進数にしないと解けない

2進数は仕組みを理解するうえで重要ですが、試験ではブロックサイズを使うと速く解ける場合があります。

~~~text
仕組みを理解する
→ 2進数

素早く範囲を求める
→ ブロックサイズ
~~~

両方を使い分けると安心です。

## まとめ（試験直前用）

- ホスト部が**全部0** → ネットワークアドレス
- ホスト部が**全部1** → ブロードキャストアドレス
- PCに割り当てるのは通常、その**間のアドレス**
- 255.255.255.240 なら 256 - 240 = 16 で16刻み
- /28 は16アドレス、通常のホスト利用は14アドレス
- **2つのIPアドレスが同じサブネットか**は、マスクを適用したネットワークアドレスの一致で判断する
