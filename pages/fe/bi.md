## まず結論

BI（Business Intelligence）とは、**企業内外に蓄積されたデータを集め、加工・分析して、経営や業務の意思決定に役立てる考え方や仕組み**です。

基本情報技術者試験では、次のキーワードがそろったらBIを第一候補にします。

```text
データを蓄積
＋
加工・分析
＋
意思決定を支援
→ BI
```

一言で覚えるなら、

> **データを見える形にして、判断を助けるのがBI。**

です。

## 直感的な説明

会社には、売上、在庫、顧客、広告、会計など、たくさんのデータがあります。

しかし、データがあるだけでは、すぐに経営判断へ使えるとは限りません。

```text
売上データ ─┐
在庫データ ─┤
顧客データ ─┼→ 集計・加工・分析 → グラフ・指標 → 意思決定
広告データ ─┘
```

BIは、このように複数のデータを分析し、ダッシュボードやレポートなどで分かりやすく見せ、

- どの商品が売れているか
- どの地域の利益率が高いか
- 在庫が過剰になっていないか
- 売上が落ちている原因は何か

といった判断をしやすくします。

## 定義・仕組み

BIは、Business Intelligence の略です。

BIでは、企業内外のデータを集め、必要に応じて整理・加工・分析し、意思決定に使いやすい情報へ変換します。

典型的な流れは次のとおりです。

1. 業務システムなどからデータを集める
2. データを整理・統合する
3. 集計・分析する
4. レポートやダッシュボードとして可視化する
5. 経営や業務の判断に活用する

ここで重要なのは、BIそのものを「データを保存する箱」と考えないことです。

データを蓄積する基盤としてはデータウェアハウスが使われることがあり、そこにたまったデータを分析して意思決定へつなげるのがBIの役割です。

```text
データウェアハウス
→ データを整理・統合して蓄積する

データマイニング
→ データから規則性や知識を見つける

BI
→ 分析結果を意思決定に活用する
```

このテーマは、基本情報技術者試験の経営戦略や情報活用に関係する内容です。公式の出題範囲やシラバスは、[IPA：基本情報技術者試験](https://www.ipa.go.jp/shiken/kubun/fe.html) から確認できます。

## 科目Aでどう出る？

科目Aでは、BIと似た経営・業務改善用語を見分ける問題として出やすいです。

判断するときは、**何をしているのか**に注目します。

| 用語 | 中心となる役割 | 判断キーワード |
|---|---|---|
| BI | データを分析して意思決定を支援する | 蓄積、加工、分析、経営判断 |
| BPR | 業務プロセスを抜本的に再設計する | 抜本的、再構築、改革 |
| BPM | 業務プロセスを継続的に改善する | 可視化、改善サイクル、継続改善 |
| EAI | 異なるシステム同士を連携する | システム統合、データ連携 |

試験中は、次の動詞で切ると覚えやすいです。

```text
分析して判断を助ける
→ BI

抜本的に作り直す
→ BPR

継続的に改善する
→ BPM

システムをつなぐ
→ EAI
```

## どんな場面で使う？

BIは、データを使って状況を把握し、次の判断をするときに使われます。

- 経営ダッシュボードで売上や利益を確認する
- 部門ごとのKPIを比較する
- 商品別・地域別の売上を分析する
- 在庫や販売実績の傾向を確認する
- 経営会議用のレポートを作る

つまり、BIの中心は **「分析結果を意思決定につなげること」** です。

データを保存すること自体や、業務プロセスを作り直すことが目的ではありません。

## よくある誤解・混同

### BIとデータウェアハウスは同じではない

データウェアハウスは、複数のシステムからデータを集めて整理・統合し、分析用に蓄積する基盤です。

BIは、そのデータを集計・分析・可視化して意思決定に活用する考え方です。

```text
ためる
→ データウェアハウス

分析して判断に使う
→ BI
```

データがどのように集約され、分析の土台になるのかまで理解したい場合は、[データウェアハウスとは？](/fe/data-warehouse/)を合わせて読むと、BIまでの流れがつながります。

### BIとデータマイニングは同じではない

データマイニングは、大量のデータから規則性や傾向、新しい知識を見つける手法です。

BIは、データ分析全体を通して意思決定を支援する、より広い考え方です。

```text
規則性を見つける
→ データマイニング

分析結果を意思決定へつなげる
→ BI
```

データからどのように新しい規則性を見つけるのかまで知りたい場合は、[データマイニングとは？](/fe/data-mining/)も見ると理解が深まります。

### BIとBPRを混同する

BPRは、既存の業務プロセスを前提にせず、仕事の流れそのものを抜本的に見直す考え方です。

BIは、業務プロセスを作り直すことが中心ではありません。

```text
データ分析で判断を助ける
→ BI

業務を根本から再設計する
→ BPR
```

### BIとBPMを混同する

BPMは、業務プロセスを可視化し、改善を継続する考え方です。

BIは、業務プロセスそのものの改善サイクルではなく、データ分析による意思決定支援が中心です。

### BIとEAIを混同する

EAIは、企業内の異なるシステムを連携させ、データや処理をつなぐ仕組みです。

```text
システムをつなぐ
→ EAI

データを分析して判断を助ける
→ BI
```

## まとめ（試験直前用）

- BIは、企業内外のデータを加工・分析して意思決定を支援する
- 「蓄積」「加工」「分析」「経営判断」がそろったらBIを疑う
- BPRは抜本的な業務再設計、BPMは継続改善、EAIはシステム連携
- データウェアハウスはデータをためる基盤、BIはそのデータを判断に活用する
- データマイニングは規則性を見つける手法、BIは分析結果を意思決定につなげる

> **分析して判断を助ける＝BI。**
