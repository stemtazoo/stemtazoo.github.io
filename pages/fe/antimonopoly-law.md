## まず結論

**独占禁止法（私的独占の禁止及び公正取引の確保に関する法律）**は、**公正かつ自由な競争を促進する**ための法律です。

FE試験で「独占禁止法の目的」を問われたら、まず**競争を不当に妨げる行為を防ぐ**という視点で判断します。

```text
公正・自由な競争を守る
        ↓
独占禁止法
```

## 直感的な説明

例えば、同じ商品を売る会社A・B・Cがあるとします。

```text
通常の競争
A社：980円
B社：950円
C社：920円
→ 価格や品質を工夫して競争する

会社同士が相談して価格を決める
A社：1,200円
B社：1,200円
C社：1,200円
→ 価格競争が妨げられる（カルテルの例）
```

会社同士が競争せず、相談して価格を決めると、消費者が不利益を受けるおそれがあります。こうした**不当な競争制限を防ぐ**ことが独占禁止法の重要な役割です。

## 定義・仕組み

独占禁止法は、主に次のような行為を規制します。

| 用語 | 判断のポイント |
|---|---|
| **私的独占** | 他の事業者を排除・支配するなどして、市場の競争を実質的に制限する |
| **不当な取引制限** | 競争事業者が共同で価格や数量などを決め、競争を実質的に制限する |
| **不公正な取引方法** | 公正な競争を阻害するおそれのある取引方法 |
| **企業結合の規制** | 合併・株式取得などによって競争が実質的に制限されることを防ぐ |

### カルテルと談合

- **カルテル**：競争する会社同士が価格や生産数量などを取り決める行為
- **入札談合**：入札参加者が事前に落札者や落札価格などを相談して決める行為

いずれも競争を不当に制限する問題として覚えます。

ただし、**大きな会社であることや、市場シェアが高いこと自体が直ちに違法という意味ではありません**。競争を制限する行為や状態など、法律上の要件が問題になります。

## 科目Aでどう出る？

FE試験では、法律名と目的を組み合わせて判断する問題があります。

| 選択肢にある言葉 | 対応する法律 |
|---|---|
| **公正かつ自由な競争** | **独占禁止法** |
| 国際的な平和・安全、輸出入の管理 | 外国為替及び外国貿易法（外為法） |
| 製造物の欠陥、損害賠償責任 | 製造物責任法（PL法） |
| 発明の保護、特許権 | 特許法 |

この4つは**守る対象が違う**ため、選択肢の中心となる言葉を探せば切り分けられます。

```text
競争を守る → 独占禁止法
安全保障に関わる対外取引 → 外為法
欠陥製品による損害 → PL法
発明を保護する → 特許法
```

## どんな場面で使う？

例えば、IT企業が他社とソフトウェアの販売価格を取り決めたり、入札参加企業同士が落札予定者を決めたりする場面です。

システム開発・調達・販売でも、**取引先や競合他社との取り決めが公正な競争を妨げないか**という観点が必要になります。

## よくある誤解・混同

### 独占禁止法は「独占状態」をすべて禁止する？

いいえ。**独占的な地位にあるだけで必ず違法とは限りません**。私的独占などの禁止要件に当てはまるかを区別します。

### PL法も事業者を規制するから独占禁止法と同じ？

違います。PL法は**製造物の欠陥によって生じた損害の賠償責任**が中心です。独占禁止法は**市場での公正な競争**が中心です。

### 特許法は独占禁止法と矛盾する？

特許法は発明の保護と利用を図る法律です。特許権による一定の独占的な権利が認められることと、競争を不当に制限する行為が無制限に認められることは別です。

## まとめ（試験直前用）

- **独占禁止法 → 公正かつ自由な競争**
- **カルテル・談合 → 競争事業者による不当な取り決め**
- **外為法・PL法・特許法 → 守る対象で切り分ける**

> 法律名だけでなく、**何を守るための法律か**で選ぶ。
