## まず結論

**パンくずリスト（Breadcrumb Navigation）は、Webサイトのトップページなどから現在のページまでの階層上の位置を示すナビゲーションです。**

FE科目Aでは、**「現在のページがサイト内のどこにあるかを、上位のページから順に示す」**という説明が判断の手掛かりになります。

例えば次の表示です。

```text
ホーム ＞ FE対策 ＞ テクノロジ系 ＞ ネットワーク
```

これは「実際にクリックしてきた順番」とは限りません。多くのパンくずリストは**サイト内の階層構造**を示します。

## 直感的な説明

大きな図書館で本を探すとき、「入口 → 2階 → 技術書 → プログラミング」と案内されると、今いる場所や戻る方向が分かります。

Webサイトでも、記事を読んでいる途中に、上位のカテゴリを確認したくなることがあります。

```text
ホーム
  └─ 学習サイト
      └─ プログラミング
          └─ Python入門  ← 現在のページ
```

この階層を横一列に並べたものがパンくずリストです。

```text
ホーム ＞ 学習サイト ＞ プログラミング ＞ Python入門
```

通常、途中の「ホーム」「学習サイト」「プログラミング」は上位ページへ移動するリンクになっています。

**「今どこにいる？」と「上の階層へどう戻る？」を助ける表示**と考えましょう。

## 定義・仕組み

### パンくずリストの構造

パンくずリストは、ページの本文より上などに置かれることが多く、上位階層から現在のページへ向かって並びます。

| 表示部分 | 役割 |
|---|---|
| ホーム | サイトの入口 |
| FE対策 | 上位のカテゴリ |
| テクノロジ系 | さらに細かいカテゴリ |
| ネットワーク | 現在のページ |

各項目の間に「＞」や「/」などの区切りを使うことがあります。区切り記号そのものが重要なのではなく、**階層関係を見えるようにすること**が重要です。

### 閲覧履歴ではない

たとえば検索エンジンから直接「Python入門」を開いたとします。

```text
実際のアクセス：
検索エンジン → Python入門

表示されるパンくず：
ホーム ＞ 学習サイト ＞ プログラミング ＞ Python入門
```

アクセス時にホームやカテゴリを経由していなくても、階層は表示できます。

**履歴（History）と階層（Hierarchy）を混同しない**ことが科目Aの重要ポイントです。

### サイトマップ・ナビゲーションバーとの違い

| UIの名前 | 主な役割 | 判断の目印 |
|---|---|---|
| **パンくずリスト** | 現在ページの階層上の位置を示す | ホームから現在地へ |
| サイトマップ | サイト全体のページ構成を一覧で示す | サイト全体の案内図 |
| ナビゲーションバー | 主なページや機能に移動する | メニュー・移動先 |
| スクロールバー | 長い画面の表示範囲を移動する | 上下・左右のスクロール |

サイトマップにもリンクがあり、ナビゲーションバーからもページを移動できます。しかし、**サイト全体を一覧するか、主な移動先を示すか、現在地を示すか**という目的が異なります。

## 科目Aでどう出る？

選択肢を読むときは、**どの範囲を案内する表示か**に着目します。

- **トップページから現在のページまでの階層** → パンくずリスト
- **サイトにどんなページがあるかを一覧する** → サイトマップ
- **共通のメニューから別ページへ移動する** → ナビゲーションバー
- **画面に収まらない内容を上下・左右に動かす** → スクロールバー

特に「トップページからの経路」という表現は、**サイト構造上の経路**の意味で考えます。実際に閲覧した順番を記録したブラウザの履歴とは区別しましょう。

## どんな場面で使う？

多数の記事がカテゴリごとに整理された学習サイトや、商品カテゴリが多い通販サイトなどで役立ちます。

例えば「ホーム ＞ 家電 ＞ パソコン ＞ ノートパソコン」と示せば、利用者は今見ている商品の分類を理解し、パソコン全体のカテゴリへ戻ることもできます。

ただし、どのサイトでも必ずパンくずリストが必要というわけではありません。ページ数が少ない単純なサイトでは、主なメニューだけで十分な場合もあります。

また、パンくずリストだけを設置しても分かりやすいサイトになるとは限らず、カテゴリの構造やリンク先が適切であることも重要です。

## よくある誤解・混同

### パンくずリストはブラウザの「戻る」と同じ？

違います。ブラウザの「戻る」は閲覧履歴に沿って移動します。パンくずリストは通常、Webサイト内の階層に沿って上位ページへ移動します。

### パンくずリストはサイトマップの別名？

違います。パンくずリストは**現在のページに至る階層の一部**を、サイトマップは**サイト全体の構成**を示します。

### パンくずリストはクリックできなければ意味がない？

上位ページへのリンクがあると便利です。現在のページはリンクにせず表示する場合もあります。必ず全項目をリンクにしなければならないわけではありません。

### 「＞」の形で表示しなければならない？

いいえ。区切り記号は「/」などでも構いません。重要なのは、順序と階層が利用者に伝わることです。

### アクセシビリティ上の工夫は？

Webの実装では、パンくずリストを名前付きのナビゲーション領域として扱い、現在ページがリンクなら `aria-current="page"` で示す方法があります。これは読み上げ支援技術などでも現在地が分かるようにするためです。詳しくは[W3Cのパンくずリストのパターン](https://www.w3.org/WAI/ARIA/apg/patterns/breadcrumb/)を参照してください。

## 確認問題（科目A・オリジナル）

あるオンライン学習サービスでは、検索エンジンから記事を直接開いた利用者にも、記事の上部に次のような案内を表示している。

```text
トップ ＞ 資格対策 ＞ データベース ＞ 正規化
```

この表示の説明として、最も適切なものはどれか。

- ア：直前に閲覧したページを時刻順に保存して表示している。
- イ：サイトの全ページを網羅した一覧表を表示している。
- ウ：現在のページがサイトのどの階層にあるかを表示している。
- エ：画面に収まらない本文を縦方向に動かすための操作部品である。

**正解：ウ**

- ア：誤り。閲覧履歴ではなく、サイト内の階層を示しています。
- イ：誤り。サイト全体の一覧はサイトマップの役割です。
- ウ：正しい。上位ページから現在のページまでの位置が分かります。
- エ：誤り。本文の表示範囲を動かすのはスクロールバーです。

**判断のコツ：** 「現在地の階層」「サイト全体の一覧」「メニュー」「スクロール」の役割を区別します。

## まとめ（試験直前用）

- **パンくずリストは、トップページなどから現在のページまでの階層を示す。**
- **閲覧履歴とは限らず、サイト内の位置を示す**ことが大切。
- サイトマップはサイト全体の一覧、ナビゲーションバーは主な移動先、スクロールバーは表示範囲の移動。
- パンくずリストの途中の項目は、上位ページへのリンクになることが多い。
