## まず結論

集合演算の問題は、**記号を「または・かつ・入らない」と日本語へ置き換え、使える法則がないか確認する**と解きやすくなります。

基本情報技術者試験では、次の対応を判断軸にします。

| 図・式の意味 | 集合演算 |
|---|---|
| AまたはBに入る | 和集合 `A ∪ B` |
| AとBの両方に入る | 積集合 `A ∩ B` |
| Aに入らない | 補集合 `Ā` |
| 共通する集合をくくる | 分配法則 |
| 並び順を入れ替える | 交換法則 |

まず覚えたい分配法則は、次の2つです。

```text
A ∪ (B ∩ C) = (A ∪ B) ∩ (A ∪ C)

A ∩ (B ∪ C) = (A ∩ B) ∪ (A ∩ C)
```

試験直前には、次の一文を覚えておくと便利です。

> **共通する集合があれば外へくくる。`∩` と `∪` は分配できる。**

## 直感的な説明

ベン図は、「条件に当てはまるものを、円の中へ分けて置いた図」です。

例えば、次の3集合を考えます。

```text
A：Pythonを使う人
B：データ分析をする人
C：機械学習を学ぶ人
```

AとBの両方に入る人は、二つの円が重なった部分です。

```text
Aにも入る
かつ
Bにも入る
→ A ∩ B
```

AまたはBのどちらかに入る人は、AとBの円全体を合わせた部分です。

```text
Aに入る
または
Bに入る
→ A ∪ B
```

分配法則も、日本語へ置き換えると理解しやすくなります。

```text
(A ∩ C) ∪ (B ∩ C)
```

は、

```text
AかつC
または
BかつC
```

です。

どちらにも `C` が共通しているため、

```text
AまたはB
かつ
C
```

とまとめられます。

```text
(A ∩ C) ∪ (B ∩ C)
= (A ∪ B) ∩ C
```

これは普通の計算で、共通するものをくくる考え方と似ています。

## 定義・仕組み

### 和集合

和集合は、どちらか一方、または両方に入る要素の集合です。

```text
A ∪ B
= AまたはBに入る
```

論理演算では、ORに近い考え方です。

### 積集合

積集合は、両方に入る要素の集合です。

```text
A ∩ B
= AとBの両方に入る
```

論理演算では、ANDに近い考え方です。

### 補集合

補集合は、対象の集合に入らない要素の集合です。

```text
Ā
= Aに入らない
```

論理演算では、NOTに近い考え方です。

### 交換法則

和集合と積集合は、集合の並び順を入れ替えても結果が変わりません。

```text
A ∪ B = B ∪ A
A ∩ B = B ∩ A
```

分配法則の形を探すときに、並び順を入れ替えると見つけやすくなります。

### 分配法則

集合演算には、次の2つの分配法則があります。

```text
A ∪ (B ∩ C)
= (A ∪ B) ∩ (A ∪ C)
```

```text
A ∩ (B ∪ C)
= (A ∩ B) ∪ (A ∩ C)
```

2つ目を逆向きに使うと、共通する集合をくくれます。

```text
(A ∩ C) ∪ (B ∩ C)
= C ∩ (A ∪ B)
```

交換法則を使えば、

```text
C ∩ (A ∪ B)
= (A ∪ B) ∩ C
```

です。

したがって、

```text
(A ∩ C) ∪ (B ∩ C)
= (A ∪ B) ∩ C
```

が常に成立します。

### 3集合の小領域

A・B・Cの3集合では、重なり部分を次のように読むと整理しやすくなります。

| 条件 | 式 |
|---|---|
| A・B・Cすべてに入る | `A ∩ B ∩ C` |
| AとBに入り、Cには入らない | `A ∩ B ∩ C̄` |
| BとCに入り、Aには入らない | `Ā ∩ B ∩ C` |
| Aだけに入る | `A ∩ B̄ ∩ C̄` |

### ド・モルガンの法則

補集合が式全体に掛かるときは、ド・モルガンの法則が使えます。

```text
(A ∪ B)̄ = Ā ∩ B̄
(A ∩ B)̄ = Ā ∪ B̄
```

覚え方は、**補集合を中へ入れると、`∪` と `∩` が入れ替わる**です。

## 科目Aでどう出る？

科目Aでは、次のような形で出題されます。

- 網掛け部分に対応する集合式を選ぶ
- 左辺と右辺が常に等しい式を選ぶ
- 分配法則やド・モルガンの法則を使う
- 複雑な集合式を簡単化する

### まず法則の形を探す

等式を選ぶ問題では、すべての選択肢をベン図にする前に、次を確認します。

```text
1. 共通する集合がないか
2. 分配法則の形になっていないか
3. 集合の順番を入れ替えれば同じ形にならないか
4. 補集合があるならド・モルガンを使えないか
```

例えば、

```text
(A ∩ C) ∪ (B ∩ C)
```

では、`C` が共通しています。

```text
(A ∩ C) ∪ (B ∩ C)
= C ∩ (A ∪ B)
= (A ∪ B) ∩ C
```

となります。

### 日本語へ置き換える

式が見慣れない場合は、日本語へ置き換えます。

```text
(A ∩ C) ∪ (B ∩ C)

AかつC
または
BかつC
```

共通する `C` をまとめると、

```text
AまたはB
かつ
C
```

なので、

```text
(A ∪ B) ∩ C
```

です。

### ベン図で確認する

法則が思い出せない場合や、式変形に自信がない場合は、ベン図で左右を確認します。

```text
法則の形が見える
→ 式変形で解く

法則の形が見えない
→ ベン図で確認する
```

### 網掛け部分を式にする

網掛けを式へ変換する問題では、次の手順で考えます。

```text
1. 網掛けが何か所あるか確認する
2. 各領域についてA・B・Cへの所属を確認する
3. 同じ領域の条件を∩で結ぶ
4. 離れた領域同士を∪で結ぶ
```

## どんな場面で使う？

集合演算は、条件を組み合わせる場面で使います。

例えば、データベース検索では次のように対応します。

```text
東京都在住 AND 20代
→ 共通する条件
→ 積集合
```

```text
東京都在住 OR 大阪府在住
→ どちらかの条件
→ 和集合
```

プログラムの条件式や論理回路でも、同じ考え方が使われます。

| 集合演算 | 論理演算 |
|---|---|
| `∩` | AND |
| `∪` | OR |
| 補集合 | NOT |

分配法則も、論理式の簡単化や検索条件の整理に使えます。

```text
(A AND C) OR (B AND C)
= (A OR B) AND C
```

## よくある誤解・混同

### 分配法則は片方しかない

集合演算の分配法則は2つあります。

```text
A ∪ (B ∩ C)
= (A ∪ B) ∩ (A ∪ C)
```

```text
A ∩ (B ∪ C)
= (A ∩ B) ∪ (A ∩ C)
```

### 集合の順番を変えると別の式になる

和集合と積集合では、順番を入れ替えても同じです。

```text
A ∪ B = B ∪ A
A ∩ B = B ∩ A
```

### ベン図を描かなければ解けない

ベン図は確実な確認方法ですが、分配法則や交換法則の形が見える場合は、式変形の方が速く解けます。

### `∩` と `∪` を普通の掛け算・足し算と同じだと思う

似た形の法則はありますが、完全に同じ計算ではありません。

```text
∩ → かつ
∪ → または
```

と読んで意味を確認します。

### 補集合の横線の範囲を見ない

次の式は意味が異なります。

```text
Ā ∩ B
(A ∩ B)̄
```

横線がどこまで掛かっているかを確認します。

## まとめ（試験直前用）

- `∪` は和集合で「または」
- `∩` は積集合で「かつ」
- 補集合は「その集合に入らない」
- `A ∪ B = B ∪ A`、`A ∩ B = B ∩ A`
- 共通する集合があれば、分配法則でくくる
- `A ∩ (B ∪ C) = (A ∩ B) ∪ (A ∩ C)`
- `A ∪ (B ∩ C) = (A ∪ B) ∩ (A ∪ C)`
- 法則の形が見えるなら式変形、見えないならベン図で確認する
- ド・モルガンの法則では、補集合を中へ入れると `∪` と `∩` が入れ替わる

> **式を日本語で読み、共通部分を探すと、集合の問題はかなり簡単になる。**
