## まず結論

画像データは、大きく **ラスタデータ** と **ベクタデータ** に分けて考えられます。

| | ラスタデータ | ベクタデータ |
|---|---|---|
| 基本的な表現 | 画素（ピクセル）の集まり | 座標・線・曲線・図形などの情報 |
| 拡大 | 画素が目立ち、粗くなりやすい | 図形を再計算して描けるため拡大に強い |
| 得意な画像 | 写真、複雑な色の変化 | ロゴ、アイコン、図、イラスト |
| 代表的な形式 | JPEG、PNG、GIFなど | SVGなど |

試験では、まず **ラスタ＝点（画素）を並べる、ベクタ＝線や図形の情報で表す** と押さえます。

## 直感的な説明

### ラスタは「方眼紙を塗る」

ラスタデータは、細かなマス目を一つずつ塗って絵を作るイメージです。一つ一つのマスが **画素（ピクセル）** に相当します。

拡大すると、そのマス自体も大きく見えるため、輪郭がギザギザしたり粗く見えたりします。

### ベクタは「CADで線や円を描く」

ベクタデータは、完成した画面を点の集合として覚えるのではなく、「ここからここまで直線」「中心はここ、半径はこれだけの円」のように、**図形を構成する情報**を持つイメージです。

CADで線や円を座標・寸法によって扱う感覚に近いと考えると分かりやすいです。表示サイズを変えたときは、その図形情報から描画し直せるため、一般に拡大しても輪郭が粗くなりにくいという特徴があります。

## 定義・仕組み

### ラスタデータ

ラスタデータは、画像を格子状の画素に分け、各画素の色や明るさを記録します。写真のように、場所ごとに細かく色が変化する画像を表現するのに適しています。

代表例として **JPEG、PNG、GIF** などがあります。

ただし、JPEGやPNGというファイル形式の違いと、「ラスタかベクタか」という画像表現の分類は別の観点です。

### ベクタデータ

ベクタデータは、画像を構成する線、曲線、図形などを座標やパラメータで表します。

例えば円なら、中心座標、半径、線の太さ、塗りの色などの情報を使って描画できます。そのため、ロゴやアイコン、模式図など、輪郭のはっきりした図形に適しています。

## SVGとは？

**SVG（Scalable Vector Graphics）**は、Webなどで広く使われるベクタグラフィックス形式です。

名前の **Scalable** が示すように、サイズを変更しても図形情報から描画できることが大きな特徴です。

- Scalable：大きさを変えて表示しやすい
- Vector：図形情報で表現
- Graphics：画像・図形

SVGでは、XMLを基盤とした記述によって、円、長方形、線、パス、文字などの図形を表現できます。

例えば円なら、SVGでは中心位置と半径などを指定して図形として記述できます。これは「円が描かれた画素を全部保存する」というラスタ画像とは考え方が異なります。

### SVGが向いているもの

ロゴ、アイコン、模式図、グラフ、シンプルなイラストのような、図形として表現しやすい画像に向いています。

一方、写真のように非常に複雑な色の変化を持つ画像は、一般にJPEGなどのラスタ形式の方が扱いやすい場合があります。

なお、SVGファイルの中にラスタ画像を埋め込むこともできます。その部分までベクタ化されるわけではないため、**「拡張子がSVGなら、中のすべてが必ずベクタデータ」と単純化しすぎない**ようにします。

## 科目Aでどう出る？

問題文では、「何で画像を表現しているか」と「拡大するとどうなるか」を見ます。

| 問題文の表現 | 判断 |
|---|---|
| 画素の集合として画像を表現 | ラスタデータ |
| 拡大すると画素が目立つ | ラスタデータ |
| 座標や線、曲線などで表現 | ベクタデータ |
| 拡大・縮小に強い | ベクタデータ |
| 写真の表現に適する | ラスタデータ |
| ロゴや図形に適する | ベクタデータ |
| Scalable Vector Graphics | SVG |
| JPEG・PNG | 主にラスタ画像形式 |

特に **画素→ラスタ、座標・線・図形→ベクタ** という判断軸を最初に使うと選択肢を切りやすくなります。

画像表現をソフトウェアの用途につなげるなら[ドローソフトとペイントソフト](/fe/draw-software/)、画像を作る工程の中で整理するなら[CG技術の全体像](/fe/computer-graphics-overview/)で確認できます。

## どんな場面で使う？

### 写真

デジタルカメラなどの写真では、各位置の細かな色の違いを表す必要があります。そのため、多数の画素で表現するラスタ形式が適しています。

### ロゴやアイコン

同じロゴをスマートフォンの小さな画面から大きなディスプレイまで表示する場合は、サイズを変えても輪郭を保ちやすいベクタ形式が便利です。SVGはその代表例です。

## よくある誤解・混同

### ラスタは拡大できない

拡大そのものはできます。ただし、元画像の画素数を超えて大きく表示すると、画素が目立ったり補間によってぼやけたりして、画質が低下しやすくなります。

### ベクタ画像には画素が存在しない

ベクタデータは図形情報として保持されますが、ディスプレイに表示するときは最終的に画面の画素へ描画されます。「保存・表現方法として画素の集合ではない」と理解するのが適切です。

### JPEGとPNGはベクタ形式

JPEGとPNGは代表的なラスタ画像形式です。**JPEG / PNG → ラスタ、SVG → ベクタを表現できる代表的形式**と整理します。

### SVGなら写真にも必ず向いている

SVGは図形を記述するのが得意ですが、写真のように非常に複雑な色変化をすべて図形として表現すると、効率が悪くなる場合があります。用途によってラスタとベクタを使い分けます。

### SVGなら中身は必ず100%ベクタ

SVGにはラスタ画像を埋め込むこともできます。SVGという形式の中にラスタ画像が含まれている場合、その画像部分はラスタ特有の制約を受けます。

## まとめ（試験直前用）

- **ラスタ**：画像を画素の集合として表す
- **ベクタ**：座標、線、曲線、図形などの情報で表す
- ラスタは写真に向き、拡大すると画素が目立ちやすい
- ベクタはロゴや図形に向き、拡大・縮小に強い
- JPEG・PNG・GIFは代表的なラスタ画像形式
- **SVG = Scalable Vector Graphics**で、代表的なベクタグラフィックス形式
- SVGはXMLを基盤として図形を記述できる
- SVGにラスタ画像を埋め込むこともできるため、SVG内のすべてが必ずベクタとは限らない
