## まず結論

**郵便番号の正規表現は、入力が「数字3桁＋4桁」などの形式を満たすかを確認するためのもの**です。郵便番号の実在性や住所との対応は、形式だけでは確認できません。

Pythonでハイフンあり・なしの両方を許すなら、`re.fullmatch(r"[0-9]{3}-?[0-9]{4}", value)` を使えます。判断のポイントは、**桁数・使用文字・ハイフンの条件・文字列全体への一致**です。

## 直感的な説明

入力フォームで、次の文字列を受け取ったとします。

| 入力 | 今回の形式に一致するか | 理由 |
|---|---|---|
| `123-4567` | 一致する | 数字3桁、ハイフン、数字4桁 |
| `1234567` | 一致する | ハイフンを省略してよい |
| `12-34567` | 一致しない | ハイフンの前後の桁数が違う |
| `123-45678` | 一致しない | 数字が1桁多い |
| `１２３-４５６７` | 一致しない | 今回は半角のASCII数字だけを許す |
| `〒123-4567` | 一致しない | 郵便番号以外の文字が含まれる |

この表は**入力形式の判定例**です。一致した文字列が実際に使われている郵便番号かどうかは、別に確認します。

## 定義・仕組み

### 郵便番号のパターンを読む

`[0-9]{3}-?[0-9]{4}` は、次の順序を表します。

| 部分 | 意味 |
|---|---|
| `[0-9]` | ASCII数字の0〜9のいずれか1文字 |
| `{3}` | 直前のパターンをちょうど3回 |
| `-?` | ハイフンが0回または1回 |
| `{4}` | 直前のパターンをちょうど4回 |

ハイフンを必須にするなら `[0-9]{3}-[0-9]{4}`、許さないなら `[0-9]{7}` とします。どの形式を受け付けるかは入力フォームの要件で決めます。

### Pythonで文字列全体を検証する

```python
import re

pattern = r"[0-9]{3}-?[0-9]{4}"

for value in ["123-4567", "1234567", "12-34567", "〒123-4567"]:
    valid = re.fullmatch(pattern, value) is not None
    print(value, valid)
```

出力は次のとおりです。

```text
123-4567 True
1234567 True
12-34567 False
〒123-4567 False
```

`re.search` は文字列の一部に一致すればよいため、`〒123-4567` の中から郵便番号風の部分を見つけられます。**入力全体の検証には `re.fullmatch`、文章からの抽出には `re.search`**という目的の違いがあります。

### 電話番号との違い

郵便番号は7桁を基本に形式を確認できます。一方、電話番号は番号の種類によって桁数や区切り方が異なるため、同じパターンを流用できません。

例えば `090-1234-5678` のような形式だけを受け付けるなら、3桁・4桁・4桁という条件が必要です。ただし、その形式だけで国内の電話番号全体を検証できるわけではありません。電話番号でも実在性や利用者との対応は別の確認事項です。

## どんな場面で使う？

- 入力フォームで桁数やハイフンの位置を確認する。
- データ前処理で形式の異なる値を見つける。
- 形式を確認した後、ハイフンなしの7桁などに表記を統一する。

郵便番号は計算する数値ではなく、**先頭の0も意味を持つ識別子**です。文字列として扱えば、整数への変換で先頭の0が失われることを避けられます。

## よくある誤解・混同

### `+` と `*` は同じ？

`+` は直前のパターンの**1回以上**、`*` は**0回以上**の繰り返しです。

例えば `[0-9]+` は数字が少なくとも1文字必要ですが、`[0-9]*` は空文字列にも一致します。郵便番号の桁数を固定するなら `{3}` や `{4}` を使います。

### `\d` は半角数字だけ？

Pythonの文字列パターンでは、`\d` は通常、全角数字などのUnicodeの十進数字にも一致します。半角のASCII数字だけを許したい今回の例では `[0-9]` を使っています。

### `^` と `$` があれば必ず完全一致？

Pythonの `$` は末尾の改行の直前にも一致し、複数行モードでは `^` と `$` の意味も変わります。文字列全体の検証が目的なら、`re.fullmatch` を使うと意図が明確です。

### 形式に一致すれば実在する郵便番号？

一致しても実在性や住所との対応は保証できません。実在する郵便番号の確認には、郵便番号データとの照合などが必要です。

正規表現は文字の範囲や桁数などの制約を表せますが、外部の郵便番号データを参照しているわけではありません。

## まとめ（試験直前用）

- 郵便番号は桁数・使用文字・ハイフンの条件で形式を確認する。
- Pythonの `re.fullmatch` は文字列全体への一致を判定する。
- `+` は1回以上、`*` は0回以上、`?` は0回または1回。
- ASCII数字だけを許す場合は `[0-9]` を使う。
- 形式への一致と、郵便番号の実在性・住所との対応は別。
