## まず結論

CNNの学習で「構成要素の役割」「特徴マップの形」「数値計算」のどこを確認したいかを選ぶためのマップです。CNN自体の定義は[CNNの基本](/gk/cnn/)で確認できます。

| 知りたいこと | 確認する先 | 注目する点 |
| --- | --- | --- |
| CNNを他のモデルと区別したい | [CNN](/gk/cnn/) | 局所受容野・重み共有 |
| フィルタを動かすと何が出るか | [畳み込み](/gk/convolution/) | 掛け算と総和・特徴マップ |
| フィルタ数と出力チャネルの関係 | [畳み込みの特徴マップ](/gk/convolution/) | 位置ごとの計算とチャネル数を分ける |
| 局所領域をどう縮約するか | [プーリング](/gk/pooling/) | Max／Averageと学習パラメータ |
| 出力サイズ・パラメータ数を計算したい | [CNN計算問題まとめ](/gk/cnn-calculation-cheatsheet/) | フィルタ・チャネル・ストライド・パディング |
| 分類・検出・領域分割を見分けたい | [画像タスク総まとめ](/gk/image-tasks-summary/) | 最後に何を出力するか |

## 構成要素をどこで使う？

| 処理の場面 | 確認する役割 | 固定の必須部品？ |
| --- | --- | --- |
| 局所特徴を抽出する | 畳み込みのフィルタ | CNNの中心となる処理 |
| 非線形性を加える | 活性化関数 | 具体的な関数や配置は設計による |
| 空間サイズを縮める | プーリング、ストライド付き畳み込みなど | プーリングが必須とは限らない |
| タスクに応じた出力を作る | 分類・検出・画素分類などの出力側 | 全結合層が必須とは限らない |

役割の一覧であり、すべてのCNNがこの順序・部品数を使うという固定レシピではありません。

## G検定ひっかけポイント

- 同じフィルタを空間上の複数位置で使う → 重み共有。すべての層の重みが同じという意味ではない。
- 通常のMax／Average Pooling → 学習される重みはない。畳み込みの学習対象とは分ける。
- 出力が特徴マップ → 直ちに最終タスクが分類とは決まらない。
- フィルタ数・チャネル・出力サイズの数値が出た → 基本定義を繰り返すより、[計算の手順](/gk/cnn-calculation-cheatsheet/)を確認する。

## まとめ（試験直前用）

- モデルの定義はCNN、局所演算は畳み込みで確認する
- 縮約処理はプーリング、形状・重みの計算は計算まとめへ進む
- 最終出力の違いは画像タスクのマップで確認する
