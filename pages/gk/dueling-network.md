## まず結論

- **Dueling Network**は、Q値を求めるネットワークを**状態価値 V(s)** と **アドバンテージ A(s,a)** の2系列に分けるDQNの改良手法です。
- G検定では「**状態そのものの良さ**」と「**その状態で特定の行動を選ぶ有利さ**」を分けて考える点が重要です。
- **報酬を予測する手法ではありません。**

## 直感的な説明

Dueling Networkは、行動を評価するときに、

> 今いる場所そのものは良い状態か？

と

> その状態で、この行動は他の行動より有利か？

を分けて考えます。

- **V(s)**：状態そのものの良さ
- **A(s,a)**：その状態で行動aを選ぶ相対的な有利さ

この2つから**行動価値 Q(s,a)**を構成します。

## 定義・仕組み

### 状態価値 V(s)

状態sにいること自体が、将来どれくらい良いかを表します。

### アドバンテージ A(s,a)

状態sで行動aを選ぶことが、他の行動と比べてどれくらい有利かを表します。

### Q値への統合

考え方としては、

> **Q値 ＝ 状態価値 ＋ 行動のアドバンテージ**

です。

ただしVとAは、そのままでは組合せ方に一意性がありません。そのため実際のDueling Networkでは、Aの平均などを差し引いてからVと統合する形が使われます。

G検定では数式を暗記するより、**「VとAを別々に推定してQを作る」**と押さえれば十分です。

## いつ使う？（得意・不得意）

### 得意

- どの行動を選んでも結果が大きく変わらない状態が多い問題
- 状態そのものの価値を効率よく学びたい場合
- DQN系の価値推定を改善したい場合

### 注意点

- 報酬そのものをネットワークが出力するわけではない
- Q値の過大評価を直接抑える手法は**Double DQN**
- 探索を主目的とする手法は**Noisy Nets**など

## G検定ひっかけポイント

### 報酬との違い

- **報酬** → 環境から受け取る信号
- **V / A / Q** → 将来の報酬を踏まえて学習する価値の推定

したがって、

- ❌ アドバンテージ＝報酬
- ❌ Q値＝その時点でもらう即時報酬

ではありません。

### 他のDQN改良との切り分け

- 「V(s) と A(s,a) を分ける」→ **Dueling Network**
- 「行動選択と評価を分ける」→ **Double DQN**
- 「重み・バイアスにノイズ」→ **Noisy Nets**
- 「重要な経験を優先」→ **Prioritized Experience Replay**

関連： [DQN](/gk/dqn/) / [DQN改良手法まとめ](/gk/dqn-advanced/) / [Rainbow](/gk/rainbow/)

## まとめ（試験直前用）

- Dueling Network＝**V(s) と A(s,a) を分けて推定**
- 2つを統合して**Q値**を構成する
- 報酬を予測する手法ではない
- Double DQNとは改善するポイントが違う
- 「状態価値＋アドバンテージ」が見えたらDueling Network
