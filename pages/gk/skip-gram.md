## まず結論

**Skip-gram**は、**中心の単語から周囲の単語を予測するWord2Vecの学習方式**です。

G検定では、次の方向で切ります。

```text
中心 → 周囲
= Skip-gram
```

## 直感的な説明

中心語が「犬」なら、その近くに現れそうな語を予測するイメージです。

```text
犬
↓
散歩 / 好き / 飼う / 猫 ...
```

CBOWとは入力と予測対象が逆です。

```text
CBOW      周囲 → 中心
Skip-gram 中心 → 周囲
```

## 定義・仕組み

Skip-gramはWord2Vecの代表的な学習方式の1つです。

- 入力：中心語
- 予測：周囲の文脈語
- 学習結果：単語の静的な分散表現

周辺語との共起関係を大量に学ぶことで、似た文脈に現れる単語が近いベクトルを持つようになります。

RNNのように系列を1ステップずつ状態として処理する仕組みではありません。

## いつ使う？（得意・不得意）

Skip-gramは、単語埋め込みを学ぶ代表的な方法として使われます。

一般に、低頻度語の表現を得るうえでCBOWより有利になることがあると説明されますが、設定やデータに依存します。G検定では、まず**中心→周囲**という予測方向を確実に押さえます。

## G検定ひっかけポイント

- ❌「周囲の単語から中心語を予測」
  - それはCBOWです。
- ❌「RNNの学習方法」
  - Skip-gramはWord2Vecの学習方式です。
- ❌「教師強制を使う時系列モデル」
  - Teacher Forcingとは別概念です。

**判断基準**

- 「中心語から周囲語」→ Skip-gram
- 「周囲語から中心語」→ CBOW
- 「単語埋め込みを学ぶ」→ Word2Vec系

## まとめ（試験直前用）

- Skip-gram＝Word2Vecの学習方式
- **中心 → 周囲**を予測
- 学習結果は静的な単語埋め込み
- RNNやTeacher Forcingとは別物
- CBOWとは予測方向で切る
