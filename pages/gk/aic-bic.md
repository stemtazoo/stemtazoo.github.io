## まず結論

AICとBICは、どちらも**当てはまりとモデルの複雑さを両方見て候補モデルを選ぶ情報量基準**です。

共通点は、

* **小さいほどよい**
* パラメータが増えるとペナルティが増える
* Accuracyのような分類精度ではなく、モデル選択に使う

違いは主に**複雑さへのペナルティ項**です。

> **AIC：`2k`**  
> **BIC：`k log n`**

G検定では、**`n` が出たらBIC**と覚えると切りやすいです。

## 直感的な説明

AICとBICは、どちらも

> 当てはまりが良いだけで、むやみに複雑なモデルを選ばない

ための仕組みです。

ただしBICは標本数 `n` をペナルティに含むため、一般的な標本数ではAICより**複雑なモデルに厳しくなりやすい**という違いがあります。

「AICは柔軟、BICは厳格」とだけ暗記するより、**なぜ違うのか＝式のペナルティ項が違う**と理解すると安全です。

## 定義・仕組み

式を並べると違いが見えます。

```text
AIC = -2 log L + 2k
BIC = -2 log L + k log n
```

* `L`：尤度
* `k`：パラメータ数
* `n`：標本数

| 観点 | AIC | BIC |
|---|---|---|
| 当てはまり | 尤度 `L` | 尤度 `L` |
| 複雑さペナルティ | `2k` | `k log n` |
| 標本数 `n` | 式に直接入らない | 入る |
| 判断 | 小さい方 | 小さい方 |

どちらも**同じデータ・同じ目的変数に当てた候補モデル同士で比較する**のが基本です。

## いつ使う？（得意・不得意）

AIC・BICは、複数の統計モデル候補から選ぶときに使います。

* 当てはまりだけで複雑なモデルを選びたくない
* パラメータ数の違う候補を比較したい
* モデル選択を相対的に行いたい

一方で、次の用途とは別です。

* Accuracy / Precision / Recall → 分類性能を見る
* RMSE / MAE → 回帰の予測誤差を見る
* AIC / BIC → **モデル選択の基準**

## G検定ひっかけポイント

よくあるひっかけは次の通りです。

* ❌「AIC・BICは大きいほどよい」 → どちらも小さいほどよい
* ❌「BICだけが尤度を使う」 → どちらも尤度を使う
* ❌「AICだけが複雑さを罰する」 → どちらも罰する
* ❌「BICは常にAICより大きい」 → 値そのものの大小を一般化しない
* ❌「AIC/BICで異なるデータセットの性能を単純比較できる」 → 基本は同じデータ上の候補比較

### 正誤を切る判断基準

* **`2k`** → AIC
* **`k log n`** → BIC
* **`n` が式に入る** → BIC
* **小さい方を選ぶ** → 両方
* **モデル選択** → AIC / BIC

## まとめ（試験直前用）

* AIC / BIC＝**モデル選択の情報量基準**
* どちらも当てはまり＋複雑さを見る
* **小さいほどよい**
* AIC：`2k`
* BIC：`k log n` → `n` が見分けポイント
