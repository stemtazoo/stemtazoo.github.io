## まず結論

セキュリティ関連組織は、**対象と活動の組合せ**で比較します。「支援」「対応」という一語だけでは組織を特定できません。2025年7月1日に国家サイバー統括室（NCO）が発足しており、NISCは過去の名称として区別します。

## 直感的な説明

自社で不審な通信が見つかったとき、自社のCSIRTが対応を進めながら、外部の専門組織の支援を受けることがあります。支援、調整、調査には重なりがあり、どれか一つの組織だけが行う活動ではありません。

## 定義・仕組み

| 組織・取組み | 対象と活動 | 個別に学ぶ先 |
|---|---|---|
| NCO | 政府のサイバー施策の企画・総合調整、行政機関への監視・分析や監査等 | [NCO](/sg/nco/) |
| NISC（旧称） | 改組前の内閣サイバーセキュリティセンター | [過去の問題文でのNISC](/sg/nisc/) |
| IPA | 対策の普及啓発、人材育成、情報提供、技術的な支援 | [IPA](/sg/ipa/) |
| J-CSIP | IPAをハブに参加組織間で攻撃情報を共有 | [J-CSIP](/sg/j-csip/) |
| J-CRAT | 標的型攻撃の相談、分析、助言等による支援 | [J-CRAT](/sg/j-crat/) |
| JPCERT/CC | インシデント対応の調整・支援、注意喚起等 | [JPCERT/CC](/sg/jpcert-cc/) |
| 組織内CSIRT | 自組織のインシデントの受付・調査・対応と外部連携 | [CSIRT](/sg/csirt/) |

## どんな場面で使う？

同じ企業の事故でも、質問によって答える主体が変わります。

| 問われている活動 | 判断する主体・取組み |
|---|---|
| 社内の影響を整理し、封じ込めや復旧を調整する | 自社CSIRT |
| 国内外の関係組織とインシデント対応を調整する | JPCERT/CC |
| 標的型攻撃についてIPAの分析・助言を受ける | J-CRAT |
| 得られた攻撃情報を参加組織の対策に役立てる | J-CSIP |
| 政府全体の施策の企画・総合調整を行う | NCO |

上の行は、すべての企業が同じ順番で相談するという固定フローではありません。自組織の対応と外部支援は並行できます。

## よくある誤解・混同

「CSIRTは外部と調整しない」「IPAやJPCERT/CCは分析をしない」は誤りです。活動に重なりがあるため、**自組織の責任か、組織をまたぐ調整か、特定の支援事業か**まで読みます。

NCOを「現場に関係せず方針だけを作る機関」とするのも不正確です。行政機関への監視・分析等も担います。NISCを含む過去問は当時の名称を読み、現行の組織説明にはNCOを使います。

## まとめ（試験直前用）

- まず対象を「自組織」「参加組織」「関係組織間」「政府全体」で確認する。
- 次に、情報共有、分析支援、対応調整、施策の企画等の活動を読む。
- NISCとNCOは時点を区別する。
- 各組織の役割を排他的な上下関係として覚えない。
